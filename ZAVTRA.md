## Следующий шаг — с чего начать

Начинаем с быстрых побед (2 часа каждая):

1. **Пост-сабмишн сообщение** — после отправки задания студент видит "закрыли / почему важно / завтра"
2. **Нарративная строка** — под каждым блоком Sprint одна строка "почему это сегодня"
3. **Методология в промпте Gemini** — добавить принципы педагога в teacher.html

Потом:

4. **Онбординг студента** — 3 экрана при первом входе (полдня)
5. **Fortschritt живой** — 🟢/🟡/🔴 слова, список фидбек-фраз (1 день)
6. **Профиль студента в teacher.html** — новый студент без кода (1 день)
7. **Скилл /generate-sprint** — генерация по методологии (1 день)
8. **Google Sheets** — данные для всех устройств (2 дня)
9. **Telegram уведомления** — петля педагог ↔ студент (1 день)

## Ключевые решения (навсегда)

- **Mittelpunkt — только на живых встречах**, ДЗ из учебника не даём
- **6 слов в день** → Sprechen + Schreiben → недельный счётчик
- **AI — только черновик**, студент видит только финал от педагога
- **Один каркас** для всех студентов — данные разные, код один
- **Методология в продукте** — speaking sprint, спиральный повтор, 3 уровня по Krashen/Ellis
- **Петля закрыта** — студент отправил → педагог получил → ответил → студент увидел
