## Следующий шаг — с чего начать

**Два приоритета (в любом порядке):**

### 1. Входящий опросник нового студента
Когда студент первый раз заходит в кабинет — он проходит опросник.
Педагог видит заполненный профиль и сразу понимает с кем работает.

**Что спрашиваем:**
- Почему учите немецкий? (работа / переезд / учёба / семья / другое)
- Где живёте сейчас? Планируете переезд?
- Когда последний раз учили немецкий?
- Что даётся труднее всего? (говорить / писать / грамматика / слушать)
- Сколько времени в день готовы заниматься?
- Есть ли дедлайн? (экзамен, дата переезда)
- Как вас зовут, как вам удобно общаться?

**Как работает:**
- Студент видит опросник один раз при первом входе (как онбординг)
- Ответы сохраняются в Firebase: `students/{id}/survey`
- Педагог видит ответы в teacher.html во вкладке студента

**Ключевые файлы:**
- `tg-app/app.js` — логика онбординга (уже есть 3-экранный онбординг, расширить)
- `tg-app/teacher.html` — раздел "Профиль" с ответами студента
- `tg-app/students.js` — структура данных студента

### 2. Методология → в генерацию заданий
Файлы `methodology_library/` содержат полную методологию педагога.
Сейчас они лежат мёртвым грузом. Нужно подключить их к генерации заданий через Gemini.

**Что сделать:**
- Создать скилл `/generate-sprint` — принимает: студент + слова + тема + грамматика
- Читает из `methodology_library/`: speaking_sprint_system.md, skill_speaking.md, skill_writing.md, psychological_techniques.md
- Генерирует полный день по методологии: все уровни Sprechen + Schreiben + пост-сабмишн
- Prompt для Gemini в teacher.html использует эту методологию как систему

**Ключевые файлы:**

## Ключевые решения (навсегда)

- **Firebase** — хранилище (не GitHub API, не localStorage)
- **Telegram бот** — уведомления студенту и педагогу
- **Один каркас** для всех студентов — данные в Firebase, код один
- **AI — только черновик**, студент видит только финал от педагога
- **Методология в продукте** — speaking sprint, спиральный повтор, 3 уровня
- **Новый студент** — через форму в teacher.html, без деплоя кода
