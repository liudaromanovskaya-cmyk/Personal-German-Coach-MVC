## Ключевые решения (навсегда)

- **Mittelpunkt — только на живых встречах**, ДЗ из учебника не даём
- **6 слов в день** → Sprechen + Schreiben → все в недельный счётчик
- **Фидбек = Двойник + Похвала + Якорь-метафора + Вопрос-активация**
- **AI — только черновик**, студент видит только финальный фидбек от преподавателя
- **Не перебивать студента** — слушать до конца, фидбек только письменно после
- **Недельный ритм**: Пн–Пт спринт → Сб повторение слабых → Вс эмоциональная история → Пн новые слова
