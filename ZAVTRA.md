### Подключить Cloudinary для хранения аудио

**Зачем:** весь код записи голоса готов, не работает только загрузка файла. Одна настройка — и аудио работает.

**Что сделать:**
1. Открыть [cloudinary.com](https://cloudinary.com) → Sign Up (бесплатно, только email)
2. После входа: Settings → Upload → Add upload preset
   - Signing mode: **Unsigned**
   - Folder: `audio`
   - Нажать Save
3. Запомнить два значения: **Cloud name** (на главной странице) + **Upload preset name**
4. Написать мне эти два значения → я обновлю одну функцию в firebase.js → готово

**Что получишь сразу:**
- Студент нажимает 🎙 → говорит → загружается → ты слышишь в Eingänge
- Кнопка "Транскрибировать (Whisper)" → точный текст
- Кнопка "Анализировать" → Gemini разбирает грамматику + лексику + native check
- Анализ автоматически в поле фидбека → ты редактируешь → отправляешь

## Следующий шаг — с чего начать

### 1. Входящий опросник нового студента (ГЛАВНЫЙ ПРИОРИТЕТ)
**Важно:** это НЕ 4 простых вопроса. Это диагностический профиль по методологии.

**7 блоков:**
1. Контекст жизни — почему немецкий, где живёт, работа, дедлайн
2. Время и ограничения — когда может заниматься, где нельзя (работа, дети)
3. Что сейчас делает — учебники, подкасты, сколько input vs output
4. Главная боль — говорение под давлением / грамматика / словарный запас / аудирование
5. Психология — нервничает когда не находит слово? Ждёт идеального предложения?
6. Что пробовала — что работало, что нет
7. Образ результата — как выглядит "я знаю немецкий" конкретно для неё

**Формат:** разговорный поток, 5-7 экранов, один вопрос на экран, кнопки + короткий текст.
Сохраняется в Firebase: `students/{id}/survey`
Педагог видит в teacher.html — раздел "Профиль студента" во вкладке студента.

**Ключевые файлы:**
- `tg-app/app.js` — добавить онбординг-поток (проверять наличие survey при первом входе)
- `tg-app/teacher.html` — раздел "Профиль" с ответами студента
