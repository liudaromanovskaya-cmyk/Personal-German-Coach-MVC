## Открытые вопросы — обсудили сегодня

### Хранилище данных
- Нужно общее хранилище (не localStorage) — чтобы данные были на всех устройствах
- Варианты обсудили: Google Sheets, Airtable, Telegram Bot, Notion, Supabase, GitHub API
- **Решение: GitHub API** — проще всего, всё уже есть, ничего нового учить не надо
- После этого: новый студент без кода заработает сам

### Fortschritt — что ещё запланировали
- Месячный срез — для обоих: студент видит рост, педагог видит провалы
- Шаблон-опросник: что хорошо / что можно лучше / чего не хватает / связь с целью
- Недельный срез (суббота/воскресенье) — цифры автоматически + текст от педагога

### Ритм педагога
- ДЗ готовится каждый день (не на неделю вперёд)
- Маркеры языка обновляются раз в 2-3 дня — два поля в той же форме
- Цель: минимум ручной работы — максимум автоматики

## Ключевые решения (навсегда)

- **Mittelpunkt — только на живых встречах**, ДЗ из учебника не даём
- **6 слов в день** → Sprechen + Schreiben → недельный счётчик
- **AI — только черновик**, студент видит только финал от педагога
- **Один каркас** для всех студентов — данные разные, код один
- **Методология в продукте** — speaking sprint, спиральный повтор, 3 уровня по Krashen/Ellis
- **Петля закрыта** — студент отправил → педагог получил → ответил → студент увидел
- **Маркеры языка** — не цифры, а живые ощущения педагога в его стиле
- **Хранилище** — GitHub API (не Google Sheets, не Airtable)
