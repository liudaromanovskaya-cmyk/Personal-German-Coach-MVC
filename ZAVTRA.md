## Ключевые решения (зафиксировано навсегда)

### По Ольге
- **Mittelpunkt — только на живых встречах.** ДЗ из учебника больше не даём
- **Слова с урока → Sprint.** /words olga → Claude генерирует чанки + задания 3 уровней
- **Говорение + Письмо параллельно.** Одни слова, два формата, разные задания
- **Не перебивать студента.** Исправления только в фидбеке, письменно
- **Фидбек = Двойник + Похвала + Якорь-метафора + Вопрос-активация**
- **Слова из фидбека → следующий Sprint** (цикл не прерывается)
- **Воскресная история** — все слова недели → аудио-история с юмором и эмоцией
- **Все слова → карточки в библиотеке лексики**

### Про стиль преподавателя
- Замечает за собой: перебивает студента во время говорения
- Правило: слушать до конца, фидбек только после и письменно
- Это поднимает результат — аффективный фильтр (Krashen) опускается

### P1 (следующий этап)

**Недельный ритм Sprint (зафиксировано)**
- Пн–Пт: 6 слов в день → Sprint (Sprechen + Schreiben) → все слова идут в недельный счётчик
- Суббота: повторение всех слов недели (формат — придумать)
- Воскресенье: что-то эмоционально сильное и запоминающееся из всех слов — закрепление
- Понедельник: новая неделя, новые 6 слов

**Счётчик слов недели + воскресная история**
- [ ] Счётчик недели — студент видит все слова Пн–Пт накопительно (6×5 = до 30 слов)
- [ ] Прогресс по дням — сколько дней сделано из 5
- [ ] Суббота — формат повторения (придумать: карточки? диктант? пересказ?)
- [ ] Воскресенье — эмоциональная история из всех слов недели (преподаватель или AI черновик)
- [ ] Студент видит: сколько слов проработано, какие грамматические теги чаще всего встречались

**Статистика грамматики**
- [ ] Показывать какие грамматические темы были в фокусе (reflexiv, Präpositionalverb и т.д.)
- [ ] Частота использования каждой темы по спринтам
- [ ] Студент видит свою "грамматическую карту" — что чаще всего практиковал

**Остальное**
- [ ] Библиотека прошлых Sprint'ов (все слова, все задания)
- [ ] Самооценка настроения + адаптация (😰 → только уровень 1)

- [ ] Schreiben Niveau 3 в fallback-режиме (без sprint) — ещё не добавлен
- [ ] Миксование слов: 30% прошлых + 30% Sprechen + 30% Schreiben + 10% тематических
- [ ] "Bearbeiten" исчезает в конце дня (после получения фидбека — уже не редактировать)
