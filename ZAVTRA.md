## ⚡ УМНАЯ РАБОТА СО СЛОВАМИ (новая идея 17 апреля)

### A. Формат слов с грамматикой (уже делается сегодня)
**Файл:** `tg-app/teacher.html` — промпт `quickFill`
- Глагол → всегда с управлением: `warten auf + Akk`, `helfen + Dat`
- Существительное → всегда с родом и множественным: `die Verbindung, -en`
- Правило мн.ч. сокращённо: `-`, `-e`, `¨e`, `-er`, `-en`, `-s`

### B. Мини-история перед словами (уже делается сегодня)
**Файл:** `tg-app/app.js` — гармошка над словами в кабинете студента
AI генерирует короткий текст (6–8 предложений) где живут все слова из списка.
Студент читает → потом слова → потом задания. Krashen i+1: сначала input, потом output.
Firebase: `teacher/{sid}/today/lesetext`

### C. Фильтр новых слов из большого списка (следующая сессия)
**Файл:** `tg-app/teacher.html` — функция `quickFill`
Когда педагог вставляет 30–40 слов:
1. Система проверяет Firebase архив: какие слова Ольга уже видела
2. НОВЫЕ (никогда не встречались) → приоритет, идут в Niveau 1
3. ИЗВЕСТНЫЕ → используются только в примерах для новых слов
4. Результат: педагог видит "8 новых / 22 для контекста" перед заполнением
Firebase: `progress/{sid}/wordHistory/{wordKey} → { firstSeen, lastSeen, count }`

## 🧠 СИСТЕМА «ОШИБКА → АВТОМАТИЗАЦИЯ» (следующий приоритет)

### 6. Авто-тегирование ошибок через AI
**Файл:** `tg-app/teacher.html` — функция `analyzeWithGemini`
AI уже анализирует транскрипцию. Добавить в промпт: вернуть теги ошибок в конце ответа:
`ERRORS: Verbzweit, mit_Dativ`
После отправки фидбека → теги автоматически пишутся в Firebase:
`progress/{studentId}/errors/{topic} → { count, lastDate, status }`

### 7. Firebase структура для ошибок и drills
Новая ветка в Firebase:
```
progress/{studentId}/errors/{topic}: { count, lastDate, status: red/yellow/green }
progress/{studentId}/drills/{topic}: { attempts:[{date,timeMs,correct}], streak, automatized }
```
Статус: 🔴 ошибка в последних 2 фидбеках / 🟡 была но не последняя / 🟢 5 правильных drill-ответов в разные дни

### 8. Tap-drill в кабинете студента
**Файл:** `tg-app/app.js`
После сдачи Niveau 1 → появляется 2-минутный drill по текущим ошибкам студента.
Формат: 3 кнопки выбора (не текстовый ввод — работает на телефоне).
Таймер считается, но студент его НЕ видит — только педагог.
Решить: где живёт drill — после сдачи / отдельная вкладка / задание от педагога.

### 9. Traffic light в панели педагога
**Файл:** `tg-app/teacher.html` — расширить `loadDashboard()`
Рядом с именем студента: `Verbzweit 🔴 Dativ 🟡 Artikel 🟢 Nebensatz 🔴`
Читается за 5 секунд — сразу ясно на что обратить внимание.

### 10. Zusatzaufgaben — ссылки и Roter Faden
**Файл:** `tg-app/teacher.html` + `tg-app/app.js`
В teacher.html добавить два опциональных поля к заданию дня:
- `roterfaden`: строка — "Mittelpunkt B2 · Lektion 5B" (просто текст, показывается в шапке спринта)
- `extras`: массив [{type, title, url, note}] — ссылки на подкаст/YouTube/статью
Оба поля опциональные — не заполнила → не показывается.
Firebase: `teacher/{sid}/today/roterfaden` и `teacher/{sid}/today/extras`

## 📋 СЛЕДУЮЩИЙ УРОВЕНЬ (после завтра)

### 11. Spaced Repetition — SM-2 алгоритм
Сейчас педагог в голове помнит какие слова повторять. При 10 студентах невозможно.
Алгоритм должен сам выбирать слова на сегодня и показывать педагогу в "На повторение".
Основа для этого уже есть (`wordSchedule` в Firebase).

### 12. Firebase как единственный источник данных
`students.js` → оставить только как шаблон-болванку для нового студента.
Живые данные (задание, слова, прогресс) — только из Firebase.
Сейчас три источника (students.js + Firebase + localStorage) — это риск потери данных.

### 13. Методология в интерфейс
- Error Noticing в грамматике: "найдите ошибку в этом предложении"
- Consciousness-Raising: "выведите правило из этих примеров сами"
- Пока мудсельектор даёт 😰 → Input i+1 (более лёгкий текст)
