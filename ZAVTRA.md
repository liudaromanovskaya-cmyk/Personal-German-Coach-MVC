### Профиль студента — каркас + шаблон
- Один каркас кабинета, контент разный для каждого студента
- Новый студент → педагог заполняет профиль в форме → кабинет готов

- Базовые вещи общие для всех одного уровня → индивидуальные поверх

### Шаблоны заданий по уровням

- B2→C1: свой шаблон (Артём)
- Каждый шаблон → промпт для Gemini

## Ключевые решения (навсегда)

- **Mittelpunkt — только на живых встречах**, ДЗ из учебника не даём
- **6 слов в день** → Sprechen + Schreiben → все в недельный счётчик
- **Фидбек = Двойник + Похвала + Якорь-метафора + Вопрос-активация**
- **AI — только черновик**, студент видит только финальный фидбек от преподавателя
- **Не перебивать студента** — слушать до конца, фидбек только письменно после
- **Недельный ритм**: Пн–Пт спринт → Сб повторение слабых → Вс эмоциональная история → Пн новые слова
- **Панель педагога**: ты вводишь слова + тему → AI генерирует контент → ты правишь → сохраняешь
- **Один каркас кабинета** для всех студентов, данные разные — не делать отдельный кабинет на каждого
- **Методология в промптах**: methodology_library/ должна читаться Gemini при генерации заданий
