**Что делаем:**

- После — сразу задание дня. Никакого лишнего.
- **Сложность:** ~2 часа
- **Файл:** `tg-app/app.js` — функция `showOnboarding()` (уже есть заготовка, нужно наполнить)

## 🔥 СЛЕДУЮЩИЙ ПРИОРИТЕТ — Умная работа со словами

### C. Фильтр новых vs известных слов
**Файл:** `tg-app/teacher.html` — функция `quickFill`
**Проблема:** у педагога за 2 встречи накапливается 30–40 слов. Нужно автоматически понять что новое, что уже видела Ольга.
**Решение:**
1. При вставке большого списка → система проверяет Firebase архив всех предыдущих спринтов
2. НОВЫЕ (никогда не встречались) → приоритет, идут в Niveau 1 (6 штук)
3. ИЗВЕСТНЫЕ (были в прошлых спринтах) → только в примерах/чанках для новых слов
4. Педагог видит: "🆕 8 новых / 🔄 22 для контекста"
Firebase: `progress/{sid}/wordHistory/{wordKey} → { firstSeen, lastSeen, timesInSprint }`

### D. Повторение слов из архива (SM-2)
**Файл:** `tg-app/teacher.html` — блок "На повторение сегодня"
**Проблема:** 2 встречи × 10–40 слов = 80+ слов в месяц. Без системы 70% забывается за 2 недели.
**Решение:** SM-2 алгоритм. Педагог открывает teacher.html → видит:
```
📅 На повторение сегодня:
   warten auf + Akk  · 10 дней назад · Ольга: 🟡
   die Verbindung    · 7 дней назад  · Ольга: 🔴
```
Нажимает → слова автоматически добавляются в следующий спринт как повторение.
Firebase: `progress/{sid}/wordSchedule/{wordKey} → { nextReview, interval, easeFactor }`

Статус: 🔴 ошибка в последних 2 фидбеках / 🟡 была но не последняя / 🟢 5 правильных drill-ответов в разные дни

### 8. Tap-drill в кабинете студента

## 📋 СЛЕДУЮЩИЙ УРОВЕНЬ (после завтра)

### 11. Spaced Repetition — SM-2 алгоритм
Сейчас педагог в голове помнит какие слова повторять. При 10 студентах невозможно.
Алгоритм должен сам выбирать слова на сегодня и показывать педагогу в "На повторение".
Основа для этого уже есть (`wordSchedule` в Firebase).

### 12. Firebase как единственный источник данных
`students.js` → оставить только как шаблон-болванку для нового студента.
Живые данные (задание, слова, прогресс) — только из Firebase.
Сейчас три источника (students.js + Firebase + localStorage) — это риск потери данных.

### 13. Методология в интерфейс
- Error Noticing в грамматике: "найдите ошибку в этом предложении"
- Consciousness-Raising: "выведите правило из этих примеров сами"
- Пока мудсельектор даёт 😰 → Input i+1 (более лёгкий текст)
