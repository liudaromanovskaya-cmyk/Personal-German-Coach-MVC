## БЛОК 1 — Критично (без этого продукт не работает)

### 1.1 Google Sheets — данные для всех устройств
*Проблема:* teacher.html сохраняет в localStorage одного браузера. Ольга на своём устройстве ничего не видит.
*Решение:* Данные из teacher.html → Google Sheets → кабинет студента читает оттуда.
*Усилие:* 🔴 2 дня

### 1.2 Telegram уведомления — петля педагог ↔ студент
*Проблема:* Студент отправил задание — педагог не знает. Петля разорвана.
*Решение:* При отправке задания → бот пишет педагогу в Telegram с текстом и именем студента. Педагог отвечает боту → студент видит фидбек в кабинете.
*Усилие:* 🔴 1 день

## БЛОК 2 — Важно (делает продукт понятным)

### 2.1 Пост-сабмишн сообщение
*Проблема:* После отправки задания — тишина. Петля не закрывается.
*Решение:* Сразу после отправки студент видит:
- "Сегодня закрыли: [что]"
- "Почему важно: [связь с грамматикой/встречей]"
- "Завтра: [одна фраза-предвкушение]"
Педагог заполняет в teacher.html, тон — зрелый наставнический, без "Молодец!".
*Усилие:* 🟢 2 часа

### 2.2 Нарративная строка — "почему это сегодня"
*Проблема:* Задания выглядят случайными. Нет ощущения маршрута.
*Решение:* Одна строка под каждым блоком Sprint:
- "Эти слова — фундамент для Präpositionalverben на встрече в пятницу"
- "Schreiben сейчас — потому что твой текст покажет мне где Verbklammer"
Данные берутся из полей "контекст" в teacher.html.
*Усилие:* 🟢 2 часа

### 2.3 Онбординг студента — 3 экрана
*Проблема:* Первый вход — студент не понимает зачем Schreiben, что значат уровни, как работает продукт.
*Решение:* При первом входе 3 простых экрана:
1. "Вот твой маршрут к B2 — мы здесь"
2. "Вот как работает Sprint: говоришь → пишешь → получаешь фидбек"
3. "Начнём?"
Показывается только один раз, потом исчезает.
*Усилие:* 🟡 полдня

### 2.4 Методология в промпте Gemini
*Проблема:* Gemini генерирует шаблонные задания без твоей методики.
*Решение:* Промпт читает твои принципы: не исправлять во время говорения, зрелый тон, 3 уровня по Krashen/Ellis, формула пост-сабмишн. Gemini генерирует строго по методологии.
*Усилие:* 🟢 2 часа

## БЛОК 3 — Усиление (делает продукт живым)

### 3.1 Fortschritt — живой прогресс (как у Busuu, лучше)
*Проблема:* Вкладка есть, данных нет.
*Решение:*
- 🟢 Уже мои — слова которые студент использовал в свободной речи
- 🟡 В процессе — использовал, но нестабильно
- 🔴 Нужно внимание — не появляются в речи
- Список конкретных слов, не проценты
- "2 недели назад — так, сейчас — вот так" — динамика
- Список фидбек-фраз: "ты сказала / немец скажет / дата"
*Усилие:* 🟡 1 день

### 3.2 Профиль студента в teacher.html
*Проблема:* Новый студент — нужно лезть в код students.js.
*Решение:* Раздел "Профиль" в форме педагога:
- Имя, уровень, цель, дата экзамена
- Вехи маршрута (3 шага)
- Учебник, стиль работы
Заполнил один раз → кабинет готов.
*Усилие:* 🟡 1 день

### 3.3 Скилл по методологии (Claude Skill)
*Проблема:* methodology_library/ существует, но не используется при генерации.
*Решение:* Отдельный скилл `/generate-sprint` — принимает: студент + слова + тема + грамматика → генерирует полный день по методологии педагога (все уровни Sprechen + Schreiben + пост-сабмишн). Использует methodology_library как базу знаний.
*Усилие:* 🟡 1 день

## БЛОК 4 — Недельный ритм (следующий уровень)

### 4.1 Суббота — умный разбор недели
Слабые слова в фокус, хорошие — отдыхают. Автоматически из данных недели.

### 4.2 Воскресенье — эмоциональная история
Все слова недели в одном тексте/диалоге. Студент читает и слышит их в живом контексте.

### 4.3 Спиральный повтор
Пн–Пт: 6 слов/день → Сб: разбор → Вс: история → Пн: 30% старых + 70% новых.

## Ключевые решения (не менять)

- **AI — только черновик.** Студент никогда не видит сырой AI-ответ.
- **Один каркас кабинета** для всех студентов — данные разные, код один.
- **Фидбек = Двойник + Якорь + Предвкушение** — без пафосной похвалы.
- **Методология в продукте** — speaking sprint, спиральный повтор, 3 уровня.
- **Петля закрыта** — студент отправил → педагог получил → ответил → студент увидел.
