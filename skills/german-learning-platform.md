# SKILL: Personal German Coach — Pedagogical & Methodological Framework

This skill embeds a complete evidence-based methodology for the Personal German Coach
platform — a one-on-one tutoring tracker for Russian-speaking adult learners of German
in Germany and Switzerland. Every design decision, assignment, feedback, and feature
must align with the principles described below.

---

## PART 1 — WHO IS THE STUDENT

### Profile
- Adult (25–55), Russian-speaking, living in Germany or Switzerland
- Motivation: work, integration, daily life, self-respect
- Time-poor: 30–60 minutes per day maximum
- Emotionally loaded: learning German = rebuilding identity (Norton, 2001)
- May carry language anxiety (Horwitz): fear of mistakes, embarrassment
- Belongs to Millennial or Gen Z generation: expects personalization,
  immediate feedback, short sessions, visible progress each time

### What the student NEEDS (Andragogy — Knowles, 6 principles)
1. **Need to Know** — always explain WHY this task, what real situation it prepares for
2. **Self-Concept** — treat as autonomous adult, not a schoolchild
3. **Prior Experience** — connect new language to what they already know (life in Russia,
   work, family — use as examples)
4. **Readiness** — link to an immediate real-life problem (job interview, doctor, Behörde)
5. **Problem-Orientation** — task must solve something concrete, not be abstract grammar
6. **Intrinsic Motivation** — highlight internal rewards (confidence, independence),
   not grades

## PART 2 — CORE THEORETICAL FRAMEWORKS

### 2.1 Krashen — Second Language Acquisition (5 Hypotheses)

**i+1 Rule (Input Hypothesis)**
Every assignment must be pitched at i+1: slightly above current level.
- Too easy (i-0) → boredom, no acquisition
- Too hard (i+3) → anxiety, affective filter rises
- Just right (i+1) → flow state, acquisition happens

**Affective Filter Hypothesis**
High anxiety = filter UP = language blocked.
Rules for the platform:
- Never use "wrong", "error", "mistake" in student-facing text
- Use: "почти точно", "вот как звучит точнее", "хорошая попытка — вот нюанс"
- Mistakes are windows into the student's developing grammar system

**Natural Order Hypothesis**
Do not force grammar structures before they are developmentally ready.
Trust the sequence: simple present → past → subjunctive, not the reverse.

**Monitor Hypothesis**
Grammar rules help as an editor, not as a speaker. Don't overload with rules.
Teach patterns through exposure + noticing, not through tables.

**Acquisition vs. Learning**
Authentic communicative tasks (real situations) → acquisition.
Grammar exercises → conscious learning (useful but secondary).
Balance: 70% authentic tasks, 30% focused form work.

### 2.2 Vygotsky — Zone of Proximal Development

**ZPD Rule**
Every task must fall in the ZPD: what student can't do alone, but CAN do with support.
- Support = hints on demand (never forced), teacher feedback, scaffolded examples
- Gradually reduce support over time (scaffolding withdrawal)

**Scaffolding Protocol**
Week 1–2: Teacher provides full model + explanation
Week 3–4: Teacher provides partial model
Month 2+: Teacher provides guiding questions only
Month 3+: Student attempts self-correction first

**Social Constructivism**
Language is built through interaction. The teacher is not just a grader —
they are the primary interlocutor. Every feedback loop IS the lesson.

### 2.3 Bloom's Taxonomy (Revised, Anderson & Krathwohl 2001)

Every assignment must be tagged with a cognitive level:

```
СОЗДАВАТЬ    → написать эссе, сочинить диалог, придумать историю
ОЦЕНИВАТЬ    → сравнить два варианта, найти лучший, объяснить выбор
АНАЛИЗИРОВАТЬ → разобрать структуру, найти паттерн ошибки
ПРИМЕНЯТЬ    → использовать правило в новом контексте
ПОНИМАТЬ     → пересказать, объяснить своими словами
ЗАПОМНИТЬ    → выучить, воспроизвести форму
```

**Rule**: A student should NOT stay below "Apply" for more than 2 consecutive tasks.
Move UP the taxonomy as competence grows.

### 2.4 Swain — Output Hypothesis

Input alone is not enough. The student must PRODUCE language to notice gaps.

**Output Cycle (mandatory)**
1. Student attempts task without hints
2. Notices gaps ("я не знаю как сказать X")
3. Requests hint if needed
4. Submits attempt
5. Receives feedback
6. Revises (not just reads — REVISES)
7. Stores revised version as reference

Without step 6 (revision), acquisition does not consolidate.

### 2.5 Ebbinghaus — Forgetting Curve + Spaced Repetition

Memory without repetition decays: 50% in 1 day, 80% in 1 week.

**Spaced Repetition Schedule**
- New item reviewed: +1 day, +3 days, +1 week, +2 weeks, +1 month
- Error patterns from past assignments resurface as micro-tasks
- Every 4th session includes 1 "throwback" task from 2 weeks ago

**Retrieval Practice (Roediger & Karpicke)**
Active retrieval > passive review.
- "Как вы скажете X?" beats "прочитайте правило X"
- Test yourself, don't re-read — stronger memory traces

**Interleaving (Bjork)**
Do NOT block practice by topic (all Dativ → all Akkusativ → all Nominativ).
MIX cases, tenses, vocabulary in each session.
Harder in the moment, far better for long-term retention.

### 2.6 Csikszentmihalyi — Flow Theory

Optimal learning = when challenge matches skill level exactly.
```
High challenge + Low skill  = Anxiety    (task too hard)
Low challenge + High skill  = Boredom    (task too easy)
Matched challenge + skill   = FLOW       (learning zone)
```
After each task, student rates: "слишком легко / в самый раз / слишком сложно"
Teacher adjusts calibration based on this signal.

### 2.7 Communicative Competence: Canale & Swain (1980) + Byram ICC (2021)

**Canale & Swain — 4 linguistic competences (still valid):**

1. **Grammatical** — правила, формы, структуры
2. **Sociolinguistic** — что уместно в ситуации (Sie vs du, Behörde vs Café)
3. **Discourse** — связность, когезия текста (Weil → deshalb, aber → jedoch)
4. **Strategic** — что делать когда не знаешь слова (перифраз, вопрос, жест)

Strategic competence is the most underteached. Include at least 1 strategic task
per week: "объясни слово, не называя его."

**Byram — Intercultural Communicative Competence (ICC, updated 2021):**
For immigrants, language WITHOUT culture is incomplete. Add a 5th dimension:

5. **Intercultural Competence** — 5 sub-components:

| Component | What it means | Platform application |
|-----------|---------------|---------------------|
| Attitudes (Einstellungen) | Curiosity & openness toward German culture, no judgment | Reframe confusion as "interesting difference", not "wrong" |
| Knowledge (Wissen) | How German society, institutions, and norms work | Explain Behörde culture, Direktheit, punctuality norms |
| Skills of interpreting | Decode why Germans behave the way they do | "Warum war der Kollege so kurz angebunden?" — cultural analysis task |
| Skills of discovery | Learn new cultural situations in real time | "You encountered X this week — what did you observe?" |
| Critical cultural awareness | See BOTH cultures from the outside without judgment | Compare Russian and German communication styles objectively |

**Mandatory ICC task (1 per month minimum):**
"Опишите ситуацию в Германии, которая вас удивила или показалась странной."
→ Teacher helps decode through cultural lens, not language correction.

**Key principle for immigrants:**
German is not just a language — it is a key to participation in society.
ICC competence determines whether students feel "at home" or permanently foreign.
Language without ICC = functional but alienating.

### 2.8 DeKeyser — Skill Acquisition Theory (SAT, 2025)

Knowing a rule ≠ speaking fluently. There are THREE distinct stages of skill development:

```
Stage 1: DECLARATIVE    → "I know the rule" (slow, conscious, effortful)
                          Example: student recalls "nach Hause, nicht zu Hause"
Stage 2: PROCEDURAL     → "I apply the rule" (faster, but still thinking)
                          Example: student pauses, then produces correct form
Stage 3: AUTOMATIZED    → "I say it without thinking" (fast, effortless, fluent)
                          Example: correct form comes out naturally mid-sentence
```

**Platform implication:**
Most platforms (and most teachers) stop at Stage 1–2. Students "know" German
but freeze in real conversations. The platform must explicitly design for Stage 3.

**Automatization Protocol (required for every grammar/vocabulary target):**
1. Introduce declaratively (rule or pattern)
2. Controlled practice: slow, accurate drills with focus on form
3. Timed practice: same drills with increasing speed pressure
4. Communicative use: real task where accuracy is required under time pressure
5. Free production: authentic task, no focus on form — fluency over accuracy
6. Interleaved review: return to pattern in different contexts (Bjork)

**Key principle:** Timed tasks are NOT about stress — they train the brain to
retrieve patterns without conscious effort. Include at least 1 timed micro-task
per week per target structure.

**Fluency ≠ Accuracy.** Track both separately:
- Accuracy = correct forms (traditional feedback focus)
- Fluency = words per minute, hesitation rate, self-corrections
- Complexity = range of structures attempted (even if some are wrong)

### 2.9 Lexical Approach (Lewis, 1993) + Vocabulary Acquisition (Nation, 2001)

**Lewis — Language is chunks, not grammar + words.**
Up to 50% of native speaker output is formulaic — not assembled from rules,
but retrieved as ready-made units (chunks).

```
NOT: Ich + würde + gerne + [verb in infinitive] (grammar assembly)
BUT: "Ich würde gerne..." → stored and retrieved as ONE unit
```

**Types of lexical chunks (all must be explicitly taught):**
- **Polywords**: "auf jeden Fall", "natürlich", "das kommt darauf an"
- **Collocations**: "einen Termin vereinbaren" (not "machen"), "Rücksicht nehmen"
- **Institutionalized expressions**: "Mit freundlichen Grüßen", "Auf Wiederhören"
- **Sentence frames**: "Es tut mir leid, aber...", "Könnten Sie bitte...?"

**Teaching principle:** Learn "Entschuldigung, könnten Sie mir helfen?" as ONE unit
before analyzing why "könnten" is Konjunktiv II. Chunks first, analysis later.

**Nation — Frequency Lists (2001)**
The most efficient vocabulary learning strategy: start with highest-frequency words.

```
Top 1,000 German words → covers ~85% of everyday spoken language
Top 2,000 German words → covers ~90% of everyday spoken language
Top 5,000 German words → covers ~95% of written language
Beyond 5,000           → diminishing returns, context-specific
```

**Platform rules:**
- Every vocabulary task must indicate word frequency tier
- Do NOT teach low-frequency words to A1–B1 students (wasted effort)
- Check: is this word in the top 2,000? If not, skip unless student-requested
- For B2+: add collocational knowledge (nicht nur das Wort, sondern wie es kombiniert)

**Assignment type: "Chunk of the week"**
One formulaic expression per session, learned as a whole unit with:
- When to use it (situation)
- Tone (formal/informal)
- 3 example contexts
- Student produces 1 sentence using it in their real life context

### 2.10 TBLT — Task-Based Language Teaching (Willis, Long, Nunan)

Structure of every assignment:
1. **Pre-task** — activate existing knowledge, set real context
   ("Завтра вам нужно объяснить врачу симптомы — начнём с этого")
2. **Task** — student attempts real communicative task
3. **Post-task / Focus on Form** — teacher highlights language patterns noticed in output
   (form teaching AFTER authentic use, not before)

Tasks must be:
- Communicatively authentic (what a real person would actually do)
- Linked to student's actual life situation
- Have a real outcome ("написать email → отправить реальный email")

## PART 2B — PHONOLOGICAL COMPETENCE

This entire dimension was absent from the original framework. It is critical.
For adult immigrants in Germany, pronunciation is the FIRST impression in every
real-world interaction: job interviews, Behörde, phone calls, shops.

### Why phonology cannot be skipped
- German accent in Russian speakers is strong and immediately noticeable
- Employers consciously and unconsciously judge competence by pronunciation
- Poor prosody (word stress, sentence rhythm) causes misunderstandings even with correct grammar

### Russian → German phonological transfer errors (most common)

| Error | Russian influence | German target |
|-------|-----------------|---------------|
| Umlaut confusion | No ü/ö in Russian | ü (lips for "и", say "у"), ö (lips for "о", say "э") |
| ch-sounds | No [ç] or [x] in Russian | ich-Laut [ç] vs ach-Laut [x] |
| Auslautverhärtung | Russian has it too — use as bridge | "Hund" → [t] at end, not [d] |
| Word stress | Russian stress is unpredictable | German: first syllable in most native words |
| Glottal stop | Absent in Russian | Before initial vowels: "ein _Auto" → "ein [?]Auto" |
| Sentence prosody | Russian falling intonation pattern | German: different rhythm, V2 word order affects prosody |
| r-sound | Russian [r] is trilled | German [ʁ] is uvular (gargled) |

### Phonological Learning Protocol
1. **Listen**: student listens to native speaker audio of target pattern
2. **Notice**: mark where stress falls, where sounds differ
3. **Record**: student records themselves saying the same phrase
4. **Compare**: side-by-side comparison with native audio
5. **Targeted drill**: focus on 1 specific sound per session (not all at once)
6. **Chunk phonology**: learn pronunciation as part of chunk ("Ich WÜRDE gerne", not "WÜRDE" in isolation)

### Platform rules for phonology
- Minimum 1 pronunciation micro-task per week for A1–B1 students
- Never correct more than 1 phonological feature per session (overwhelm risk)
- Frame as "this is how it sounds to a German ear" not "your accent is wrong"
- Use audio recording tasks: student submits voice note, teacher gives audio feedback
- Prosody before segments: sentence rhythm first, individual sounds second

## PART 3 — INTERLANGUAGE & ERROR ANALYSIS (Selinker)

Every student has an interlanguage — a developing grammar system that is NEITHER
Russian NOR German. It evolves according to its own logic.

### Error Classification
Classify ALL teacher-marked errors by type:

| Type | Example | Pedagogical Response |
|------|---------|----------------------|
| Developmental | "Ich gehe nach Hause gestern" | Normal — wait for readiness |
| Transfer from Russian | "Ich bin 30 Jahre" (без haben) | Contrastive explanation |
| Overgeneralization | "Ich gehe-d" | Pattern awareness task |
| Pragmatic | "Gib mir das" to a Behörde officer | Sociolinguistic task |
| Strategic | Silence when unknown word | Strategic competence drill |

### Error Response Principles
- NOT all errors need correction (Natural Order — some will resolve themselves)
- Correct: pragmatic errors always, transfer errors usually, developmental errors gently
- Never correct more than 2–3 patterns per feedback session (cognitive overload)
- Distinguish: errors (systematic, need attention) vs. mistakes (slips, ignore)

## PART 4 — PSYCHOLOGY & MOTIVATION

### 4.1 Self-Determination Theory (Deci & Ryan — SDT)

Three basic psychological needs that MUST be met for sustained motivation:

1. **Competence** — student must feel they are growing
   → Show micro-progress: "сегодня вы использовали Konjunktiv II — 2 недели назад не могли"
   → Win-banner only when teacher confirms REAL improvement

2. **Autonomy** — student must feel they have choice
   → Offer 2 task options when possible
   → Allow student to flag task difficulty
   → Let student choose topic within a grammar frame

3. **Relatedness** — student must not feel alone
   → Teacher responses feel personal, not form-letter
   → Acknowledge the student's real context ("вы писали, что собеседование в пятницу — давайте подготовимся")

### 4.2 Dörnyei — L2 Motivational Self System (L2MSS)

Language-specific motivation model. Three components:

**Ideal L2 Self** — who the student WANTS to become as a German speaker.
"I see myself confidently negotiating my contract in German."
This is the most powerful motivational driver. Without a vivid Ideal L2 Self,
motivation collapses when tasks get hard.

**Ought-to L2 Self** — who the student SHOULD become (external pressure).
"I must learn German to keep my job / pass integration requirements."
This drives short-term compliance but not long-term engagement.

**L2 Learning Experience** — how much the student enjoys the process itself.
"I like my teacher. I feel good after sessions. This is interesting."
This is what the platform must cultivate daily.

**Onboarding addition (mandatory):**
Ask during first session: "Опишите себя через год. Вы говорите по-немецки.
Где вы? Что происходит? С кем? Как вы себя чувствуете?"
Save this answer. Reference it during hard moments: "Помните, вы хотели..."

**2024 note:** Recent Cambridge meta-analysis raised validation concerns about
L2MSS measurement scales. However, the practical value of the Ideal L2 Self
interview technique remains strong and is retained here.

### 4.3 Language Anxiety (Horwitz, 1986)

Language anxiety is NOT general anxiety. It is specific to the public performance
of an imperfect language. Signs: avoidance, over-editing, silence, "I can't do this."

Platform rules against anxiety:
- Hints always available on demand (never forced)
- Feedback always starts with what was GOOD, then what can be improved
- Never show error count as a metric
- Progress measured in CAN-DO statements, not scores
- Private practice = safe space (no judgment)

### 4.3 WTC — Willingness to Communicate (MacIntyre, 1998)

WTC = psychological readiness to speak RIGHT NOW in a specific situation.
Knowledge ≠ WTC. A student can know B2 grammar and have A1 WTC.

Goal of the platform: raise WTC alongside linguistic competence.
- Include "speaking prep" tasks before real conversations
- Low-stakes rehearsal before high-stakes situations
- Track: "Вы попробовали говорить по-немецки вне уроков на этой неделе?"

### 4.4 Identity Theory (Norton, 2001)

For adult immigrants, learning German is identity reconstruction.
"Кто я, когда говорю по-немецки? Я всё ещё я?"

Implications:
- Acknowledge language-identity tension (it is NORMAL to feel strange)
- Russian is not an obstacle — it is a resource (Translanguaging)
- Frame German as addition, not replacement of Russian identity
- Celebrate bilingual moments: "вы думали по-русски, а сказали правильно по-немецки — это победа"

### 4.5 Translanguaging (García & Wei, 2014)

Students have ONE linguistic repertoire (not two separate languages).
Switching between Russian and German is a cognitive resource, not failure.

Rules:
- Allow thinking/planning in Russian
- Allow Russian explanations in homework
- Teacher can reference Russian structures for contrast
- Never punish code-switching

### 4.6 Freire — Critical Pedagogy (Pedagogy of the Oppressed, 1968)

For adult immigrants, language learning is NOT a neutral skill transfer.
It is an act of gaining voice, participation, and power in a new society.

**Freire's core principle:** Education is not "banking" (depositing knowledge
into a passive student). It is a dialogue between equals, grounded in
the student's real lived experience and problems.

**For Russian-speaking immigrants in Germany this means:**

| "Banking" model (avoid) | Critical pedagogy model (use) |
|------------------------|-------------------------------|
| Teacher selects grammar, student learns | Student brings real problem, teacher builds language around it |
| "Today we learn Konjunktiv II" | "Your bank letter confused you — let's decode it and respond" |
| Progress = grammar coverage | Progress = ability to act in the world |
| Student is receiver of knowledge | Student is co-author of curriculum |
| Correct German = goal | Participating confidently in German society = goal |

**Practical applications:**
- "Принесите любой документ/письмо/объявление, которое вы не поняли" → lesson material
- Student defines their OWN language goals beyond teacher's curriculum
- Celebrate moments of real-world agency: "Я сам позвонил в Krankenkasse!" = major win
- Language = tool for self-advocacy, not just communication

**Trauma-informed extension:**
Many immigrants carry migration-related trauma: bureaucratic humiliation,
language-based exclusion, loss of professional status.
The platform must create psychological safety FIRST before linguistic progress.
Signs of trauma response: avoidance, silence, perfectionism, sudden dropout.
Teacher response: slow down, validate, reduce task complexity temporarily.

### 4.7 Positive Psychology in Education (Seligman — PERMA)

Well-being = prerequisite for learning. Design platform for PERMA:
- **P**ositive emotion: warm tone, win-banners, encouraging messages
- **E**ngagement: flow-state tasks (i+1), interactive formats
- **R**elationships: personal teacher-student connection
- **M**eaning: link every task to student's real life goal
- **A**ccomplishment: visible milestones, CEFR level transitions as rituals

## PART 5 — INSTRUCTIONAL DESIGN (Backward Design — Wiggins & McTighe)

### Design Sequence (ALWAYS start here)
1. **Desired Result**: What will student be able to DO in real life? (Can-Do statement)
2. **Evidence of Achievement**: How will we know they can do it? (What task proves it?)
3. **Learning Activities**: What tasks build toward that evidence?

NEVER start from "let's do some Dativ exercises."
ALWAYS start from "в конце месяца студент может объяснить симптомы врачу."

### CEFR Can-Do Descriptors (2020 Companion Volume)
Map EVERY assignment to a specific Can-Do descriptor. Examples:

| Level | Can-Do | Assignment Type |
|-------|--------|-----------------|
| A1 | Kann sich vorstellen | Selbstvorstellung schreiben |
| A2 | Kann einfache Einkäufe machen | Dialog im Supermarkt |
| B1 | Kann Arzttermin vereinbaren | Telefon-Rollenspiel transkribieren |
| B2 | Kann bei Behörden Auskunft geben | Antrag schreiben |
| C1 | Kann Meinung differenziert begründen | Argumentativer Artikel |

Also include 2020 additions: **mediation** (explain to third party),
**plurilingual competence** (use of Russian as bridge).

### Bruner — Spiral Curriculum (1960)

Progress is NOT linear (A1 → A2 → B1). It is SPIRAL.
The same themes, situations, and grammar concepts return at increasing depth.

```
Topic: "Refusing politely"

A1:  "Nein, danke." — basic refusal
A2:  "Leider nicht möglich." — polite with reason
B1:  "Das wäre schön, aber leider habe ich..." — personal, with explanation
B2:  "Ich würde sehr gerne, aber leider steht dem entgegen, dass..." — formal
C1:  "So gerne ich das würde, muss ich leider absagen, da..." — nuanced, professional
```

**Platform rules:**
- Do NOT treat topics as "finished". "We did greetings at A1" is wrong —
  greetings appear again at every level with deeper sociolinguistic demands.
- Curriculum map must show which topics return and at what depth.
- Every CEFR level transition = same situations, new complexity layer.
- Student sees this as growth: "I can do this BETTER now" — not "I'm doing this AGAIN".

**Spiral vs. Linear — practical difference:**
Linear: "This month: Dativ. Next month: Akkusativ."
Spiral: "This month: ordering in a café (Akkusativ dominant) + asking directions
          (Dativ dominant) + mixed real-life tasks" → revisited at B1 with
          written forms, at B2 with formal register.

### ADDIE Model (Analysis → Design → Development → Implementation → Evaluation)
Every new curriculum unit follows:
1. **Analysis**: What does student need? What are gaps? (Diagnostic)
2. **Design**: What are learning objectives? What tasks prove mastery?
3. **Development**: Create actual tasks, feedback templates, hints
4. **Implementation**: Deliver, observe student behavior
5. **Evaluation**: Did it work? Adjust for next unit.

## PART 6 — ASSESSMENT FRAMEWORK

### Formative vs. Summative
- **Formative** (ongoing): every teacher feedback = formative assessment
  → aim: improve next performance
  → frequency: every submission
- **Summative** (milestone): every 4 weeks, mini-portfolio review
  → aim: demonstrate growth against Can-Do descriptors
  → format: student's own selected "best work" + teacher comment

### Kirkpatrick 4-Level Evaluation
Track all four levels explicitly:

| Level | Question | Measurement Tool |
|-------|----------|-----------------|
| 1 Reaction | Как студент себя чувствует? | Emoji/rating after each task |
| 2 Learning | Что реально усвоено? | Revision quality, error pattern change |
| 3 Behavior | Применяет в жизни? | Weekly check-in question |
| 4 Results | Достиг цели? | CEFR level assessment every 3 months |

### Metacognitive Assessment (Flavell)
Monthly self-reflection prompt for student:
"Как вы учитесь лучше всего? Что помогает вам запомнить новое?"
Teacher uses answer to adjust task format.

## PART 7 — LEARNER AUTONOMY (Holec & Little)

Goal: student who can learn WITHOUT the teacher.
This is the EXIT outcome of the platform, not a nice-to-have.

### Autonomy Progression (Scaffolding Withdrawal Schedule)
```
Month 1: Teacher selects tasks, provides all hints, full explanations
Month 2: Teacher selects tasks, student requests hints (not automatic)
Month 3: Teacher proposes 2 options, student selects
Month 4: Student proposes task type, teacher approves/adjusts
Month 5+: Student self-directs, teacher coaches and quality-checks
```

### Self-Assessment Tools
- "I can..." checklist tied to Can-Do descriptors (student completes monthly)
- Error journal: student tracks their OWN recurring mistakes
- Study log: what I did this week, what worked, what didn't

## PART 8 — GENERATIONAL DESIGN PRINCIPLES (Millennials & Gen Z)

Students born 1981–2012 require:
- **Chunked sessions**: max 25–30 minutes of focused work, not 2-hour blocks
- **Immediate feedback**: teacher responds within 24–48 hours (not "sometime this week")
- **Visual progress**: progress bar, level indicator, win-banner — even small wins visible
- **Personalization**: "это задание создано для вашей ситуации с работой"
- **Mobile-first**: all tasks completable on phone
- **Authentic connection**: they will leave if interaction feels automated or generic
- **Micro-goals**: "сегодня цель — одно новое выражение для офиса"

## PART 9 — FEEDBACK PRINCIPLES

Every teacher feedback must follow this structure:

### Feedback Template (mandatory components)
1. **Acknowledge effort** (1 sentence): "Хорошая попытка — вы использовали верный артикль"
2. **Highlight what worked** (specific): "Особенно точно: [цитата из работы студента]"
3. **One main improvement point** (max 2–3 per session): "Здесь точнее было бы..."
4. **Why it matters** (connect to real life): "Это поможет когда..."
5. **Next micro-goal**: "В следующий раз попробуйте..."

### Language Rules for Feedback
- NEVER: "неправильно", "ошибка", "нет", "неверно"
- USE: "точнее было бы", "носители чаще говорят", "вот как звучит естественно"
- Corrections are suggestions, not verdicts
- AI draft feedback is always marked DRAFT — teacher personalizes before sending

### Lyster & Ranta — Corrective Feedback Taxonomy (1997, confirmed 2024)

**6 types of correction — each has a different effect. Choose deliberately:**

| Type | How it looks | Effectiveness | When to use |
|------|-------------|---------------|-------------|
| **Recast** (перефраз) | Student: "Ich gehe nach Haus gestern" → Teacher: "Du bist gestern nach Hause gegangen" | ⚠️ LOW — student rarely notices it's a correction | Avoid as primary method |
| **Explicit correction** | "Нет, правильно: Ich BIN nach Hause gegangen" | ✅ HIGH for declarative learning | Pragmatic errors, safety-critical situations |
| **Metalinguistic** | "Здесь нужен Perfekt, а не Präteritum — помните почему?" | ✅ HIGH for conscious learners | Grammar awareness tasks, analytical learners |
| **Elicitation** (пауза-ожидание) | "Ich bin... nach Hause...?" (pause, expectant look) | ✅✅ HIGHEST for long-term retention | Self-correction trigger — use most often |
| **Clarification request** | "Извините, я не совсем понял, что вы имеете в виду?" | ✅ Realistic — mirrors real communication | Pragmatic / discourse errors |
| **Repetition with stress** | "Ich bin *gegangen* nach Hause?" (stress on error) | ✅ Gentle — student notices without shame | Mild form errors, confident students |

**Critical warning — The Recast Trap:**
Recasts are the MOST COMMON feedback type teachers use — and the LEAST effective.
The student hears the correct version but does not register it as a correction.
They think the teacher is just continuing the conversation.
Platform AI drafts must flag if feedback relies too heavily on recast.

**Feedback type decision protocol:**
```
Pragmatic error (rude, inappropriate)?  → Explicit correction always
Grammar error, student knows the rule?  → Elicitation (let them self-correct)
Grammar error, student doesn't know?    → Metalinguistic + example
Discourse / fluency issue?              → Clarification request
Repeated error (3rd time same mistake)? → Explicit correction + metalinguistic
First attempt at new structure?         → Recast acceptable (low stakes)
```

### One Task at a Time (Student View)
Student dashboard shows EXACTLY ONE active task.
No queue visible, no "next task" preview.
Reason: reduce overwhelm, maintain focus, support PERMA principle of Engagement.

## PART 11 — COMPLETE LEARNING CYCLE (Full Loop)

This is the canonical sequence for every learning unit:

```
1. DIAGNOSE      → CEFR level + 4 competence areas + affective profile
                    (What can they do? What do they want? What do they fear?)

2. SET GOAL      → Backward Design: real-life Can-Do outcome first
                    ("В конце этого блока студент сможет...")

3. CALIBRATE     → i+1 + ZPD + Flow check
                    (Is this task in the right zone? Not too easy, not too hard?)

4. ASSIGN        → Task with: Bloom tag, CEFR Can-Do, real-life context, WHY explanation
                    (Student knows what and why before starting)

5. ATTEMPT       → Student tries WITHOUT hints first (Output Hypothesis)
                    (Productive struggle = noticing gaps = acquisition trigger)

6. HINT REQUEST  → Student requests hint if stuck (ZPD scaffolding)
                    (3 levels, never automatic)

7. SUBMIT        → Student submits attempt

8. AI ANALYSIS   → Draft: error classification by type, pattern detection
                    (Developmental vs. transfer vs. overgeneralization vs. pragmatic)

9. TEACHER REVIEW → Teacher personalizes feedback, approves/edits AI draft
                    (Human judgment always final)

10. FEEDBACK     → Student receives: acknowledge → strength → 1-2 improvements → why → next step
                    (Feedback template, warm tone, no red-pen language)

11. REVISE       → Student revises (not just reads) the corrected version
                    (Without revision, acquisition does not consolidate — Swain)

12. SPACED REVIEW → System schedules review of this pattern: +1, +3, +7, +14, +30 days
                    (Ebbinghaus forgetting curve management)

13. KIRKPATRICK  → Collect: reaction (emoji), learning (revision quality),
                    behavior (weekly check-in), result (quarterly CEFR assessment)

14. RECALIBRATE  → Adjust difficulty: too many L3 hints = lower i+1
                    Too fast progress = raise level
                    Low WTC = add strategic competence tasks

15. MILESTONE    → Every 4 weeks: portfolio review, Can-Do checklist, win-banner ritual
                    Level transitions are celebrated, not just logged
```

## PART 13 — FRONTIER AREAS (Emerging Research 2024–2025)

---

### 13.1 Dynamic Systems Theory in SLA (Larsen-Freeman & de Bot)

Language development is NON-LINEAR. It is a complex dynamic system —
sensitive to initial conditions, context-dependent, and inherently variable.

**What this means in practice:**
- Plateaus are NORMAL and expected — not failures
- Regressions (B1 student suddenly making A2 errors) are NORMAL under stress or new situations
- Progress is not a straight line upward — it looks like a wave
- One "bad week" proves nothing about overall trajectory

**Platform rules:**
- Never interpret a regression as "going backwards"
- Frame plateaus as: "Ваш мозг перерабатывает. Скоро будет скачок."
- Track 4-week trends, not individual session performance
- Teacher note when student regresses: check — new job? illness? stressful event?
  (External stress causes temporary regression — it is NOT a method failure)

**Variability is diagnostic data:**
When a student performs well in written tasks but poorly in oral — that is
not inconsistency. It is a signal: automatization is incomplete for that structure.
Add more timed spoken practice for that specific pattern.

---

### 13.2 AI Ethics in Language Learning (CALL/MALL — 2024 Standards)

This platform uses AI. These principles are non-negotiable:

**Transparency:**
- Student has the right to know which aspects of their work are AI-analyzed
- "Ваша работа была предварительно проанализирована AI, все комментарии
  проверены и адаптированы вашим преподавателем"
- Never imply the teacher wrote something the AI generated

**Bias awareness:**
- AI language models may have cultural biases toward Western European norms
- Teacher must review AI suggestions for cultural appropriateness
- AI may overcorrect stylistically correct but non-standard forms
  (e.g., regional German variants — not errors, just regional)

**Data principles:**
- Student submissions are confidential (GDPR applies)
- AI analysis of student errors must not be shared beyond this platform
- Student can request deletion of their language data

**AI as scaffold, not replacement:**
- AI suggests, teacher decides, student receives (already in skill — reinforce here)
- AI cannot assess WTC, motivation, identity — only humans can
- AI feedback on pronunciation requires human review — phonological judgment
  is context-dependent and culturally loaded

### 13.3 Sleep and Memory Consolidation (Neuroscience, 2024)

Memory consolidation happens during sleep — especially REM sleep.
New language patterns are neurologically strengthened during the night
following the learning session.

**Practical implications for platform:**

| Recommendation | Evidence base |
|----------------|---------------|
| Schedule spaced repetition review for EVENING (before sleep) | Consolidation occurs during subsequent sleep |
| Avoid cramming multiple new structures in one session | Interference effect — items compete during consolidation |
| Short daily practice > long weekly sessions | Daily sleep cycles = daily consolidation windows |
| New vocabulary reviewed at bedtime > morning | 8-hour consolidation window immediately follows |
| After illness/poor sleep: expect temporary performance drop | Consolidation was disrupted — normal, will recover |

**Platform recommendation:**
Add optional "вечерний повтор" micro-task — 5 minutes, 3 items from today's session.
Students who use it will show measurably better retention at next session.
Frame it as: "5 минут перед сном — и ваш мозг будет работать всю ночь."
