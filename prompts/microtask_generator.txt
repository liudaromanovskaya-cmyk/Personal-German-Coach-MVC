=== АДАПТАЦИЯ ПО СТИЛЮ ОБУЧЕНИЯ ===

**Visual (Визуальный стиль):**
- Задания со схемами, таблицами, майндмапами
- "Нарисуйте схему падежей / составьте таблицу"
- Цветовое кодирование: подчеркните артикли одним цветом, глаголы — другим
- Флеш-карточки с картинками

**Auditory (Аудиальный стиль):**
- Запись аудио ответов
- Повторение вслух / shadowing (повторение за диктором)
- Прослушать + пересказать
- Создать rap/стихотворение со словами

**Kinesthetic (Кинестетический стиль):**
- Ролевые игры и диалоги
- "Разыграйте ситуацию" / "Запишите видео"
- Написать от руки (физическое действие)
- Сделать что-то реальное: позвонить, написать реальный email

**Analytical (Аналитический стиль):**
- Объяснение правил своими словами
- Разбор ошибок с правилами
- Сравнение структур (немецкий vs русский)
- Создание собственных правил / шпаргалок

=== ПРИМЕР ВЫВОДА (для Visual + Kasus + IT) ===

**Микро-задание 1: Таблица падежей в IT-контексте**
- Тип: Grammar
- Время: 8 мин
- Адаптация для Visual: создайте цветную таблицу — это закрепляет визуально
- Инструкция: Нарисуйте таблицу 4×4 (падежи × артикли). Впишите 3 IT-слова в каждый падеж: das System → Nom. das System / Akk. das System / Dat. dem System / Gen. des Systems. Раскрасьте: Nom = синий, Akk = зелёный, Dat = оранжевый, Gen = красный.
- Что загрузить: фото таблицы
- Связь с ошибкой: тренирует Kasus в знакомом лексическом поле

**Микро-задание 2: Shadowing — Meeting Podcast**
- Тип: Listening + Speaking
- Время: 10 мин
- Адаптация для Visual: смотрите видео с субтитрами (читайте + слушайте)

- Что загрузить: аудиозапись (30–60 сек)
- Связь с ошибкой: натуральные конструкции для Meeting + произношение
