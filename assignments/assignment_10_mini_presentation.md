# Задание 10: Mini-Präsentation (Мини-презентация)

**Тип:** Mini Presentation
**Уровень CEFR:** B1–C1
**Длительность:** 15–20 минут (подготовка + запись)
**Навыки:** Говорение, Структура речи, Профессиональная лексика, Убедительность

---

## Цель задания

Научиться структурированно и убедительно говорить по-немецки на профессиональные или личные темы. Преодолеть страх монолога.

---

## Темы на выбор (преподаватель назначает одну)

### Профессиональные темы (B1–B2):

**A. IT:** Stellen Sie ein Technologieprojekt vor, an dem Sie gearbeitet haben (oder ein fiktives). Was ist das Ziel? Welche Technologien? Welche Herausforderungen?

**B. Medizin/Pflege:** Beschreiben Sie einen typischen Arbeitstag. Was sind die Herausforderungen? Was motiviert Sie?

**C. Management:** Präsentieren Sie eine Idee für eine Prozessverbesserung in Ihrem Unternehmen. Problem → Lösung → Vorteile.

**D. Allgemein:** Präsentieren Sie Ihre Stadt / Ihr Heimatland für deutsche Kollegen. Was sollten sie wissen?

### Темы для интеграции (A2–B1):

**E.** Mein Weg nach Deutschland — warum ich hier bin und was ich gelernt habe.

**F.** Ein deutsches Fest oder Brauch, das/den ich kennengelernt habe (Weihnachtsmarkt, Oktoberfest, Karneval...).

---

## Структура мини-презентации (4 части)

```
1. EINLEITUNG (Введение) — 20–30 секунд
   - Begrüßung: "Guten Tag, mein Name ist..."
   - Thema ankündigen: "Heute möchte ich über... sprechen."
   - Struktur: "Ich werde zunächst... dann... und abschließend..."

2. HAUPTTEIL 1 — Das Problem / Der Hintergrund (1 мин)
   - Was ist die Situation?
   - Warum ist das wichtig?

3. HAUPTTEIL 2 — Meine Erfahrung / Lösung / Details (1–1.5 мин)
   - Was haben Sie gemacht / erlebt?
   - Konkrete Beispiele

4. SCHLUSS (Заключение) — 20–30 секунд
   - Zusammenfassung: "Zusammenfassend möchte ich sagen..."
   - Persönliche Botschaft / Empfehlung
   - "Vielen Dank für Ihre Aufmerksamkeit. Haben Sie Fragen?"
```

**Общая длина:** 2,5–4 минуты

---

## Полезные фразы для презентации

| Функция | Фраза |
|---|---|
| Начало | Guten Tag, mein Name ist... Heute spreche ich über... |
| Übergang | Als nächstes möchte ich... / Kommen wir nun zu... |
| Beispiel | Ein konkretes Beispiel dafür ist... / Zum Beispiel... |
| Betonung | Besonders wichtig ist... / Das Entscheidende ist... |
| Einschränkung | Allerdings... / Auf der anderen Seite... |
| Schluss | Zusammenfassend kann ich sagen... / Fazit: ... |
| Danke | Vielen Dank für Ihre Aufmerksamkeit! |

---

## Шаги выполнения

**Шаг 1 — Подготовка (5 мин)**
- Выберите тему
- Набросайте ключевые слова (не писать весь текст!)
- Выпишите 5–8 ключевых профессиональных слов

**Шаг 2 — Первая попытка (без остановок)**
- Запишите первую версию — говорите непрерывно
- Разрешены паузы, но не останавливайте запись из-за ошибок

**Шаг 3 — Анализ себя**
- Прослушайте запись
- Отметьте: где запнулись? Какие слова не нашли?

**Шаг 4 — Финальная запись**
- Запишите ещё раз (опционально, если хотите улучшить)
- Загрузите в платформу

**Шаг 5 — Рефлексия (2–3 предложения письменно)**
- Was war einfach? Was war schwierig?
- Welche Wörter haben Sie nicht gefunden?

---

## Пример структуры (B1, тема C — Управление)

> **Einleitung:**
> Guten Tag! Mein Name ist Elena. Heute möchte ich eine Idee zur Verbesserung unserer Teambesprechungen vorstellen.
>
> **Problem:**
> Im Moment dauern unsere Meetings oft über eine Stunde, ohne klare Ergebnisse. Das kostet Zeit und Energie.
>
> **Lösung:**
> Ich schlage vor, das Stand-up-Format einzuführen: 15 Minuten täglich, drei Fragen: Was habe ich gestern gemacht? Was mache ich heute? Gibt es Hindernisse?
>
> **Vorteile:**
> Kürzere Meetings, klare Verantwortlichkeiten, bessere Kommunikation im Team.
>
> **Schluss:**
> Ich bin überzeugt, dass dieses Format uns helfen wird, produktiver zu arbeiten. Vielen Dank!

## Чек-лист для проверки (преподаватель)

- [ ] Чёткая структура (4 части)?
- [ ] Тема раскрыта полностью?
- [ ] Профессиональная лексика использована (мин. 5 слов)?
- [ ] Связующие слова (Übergänge) присутствуют?
- [ ] Темп речи: не слишком быстро / медленно?
- [ ] Понятное произношение?
- [ ] Студент говорил свободно, без заучивания наизусть?
- [ ] Соответствие времени (2,5–4 мин)?

**AI DRAFT-комментарий** по транскрипту создаётся автоматически. Финальная оценка — преподаватель.

## Критерии оценки (0–10 баллов)

| Критерий | Баллов |
|---|---|
| Выполнение задачи (тема раскрыта) | 2 |
| Структура презентации | 2 |
| Лексика (профессиональная и связующая) | 2 |
| Грамматика | 2 |
| Произношение и беглость | 2 |

## 30-минутный вариант

Подготовить слайды (Google Slides или просто текстовый план) → записать презентацию с показом экрана (скринкаст) → загрузить видео. Добавить раздел "Fragen und Antworten" — ответить на 2 воображаемых вопроса.
