# Задание 14: Nominalisierung / Verbalisierung (B2)

**Тип:** Грамматика — Номинализация и вербализация
**Уровень CEFR:** B2
**Источник:** Grammatik Aktiv B2–C1, Übungsgrammatik Mittelstufe
**Длительность:** 25–35 минут
**Навыки:** Академический стиль, Письмо, Словообразование

---

## Что и зачем

Nominalisierung — «перевод» глагола или прилагательного в существительное — признак образованной письменной речи. Официальные документы, новости, деловые письма пишутся через номинализации. Без этого навыка текст звучит «по-детски».

*Разговорно:* Wir haben beschlossen, dass wir das Projekt finanzieren.
*Официально:* Die Entscheidung zur Finanzierung des Projekts wurde getroffen.

---

## Раздел 1: Глагол → Существительное (образование)

**Образуйте существительное от глагола. Укажите артикль и тип словообразования.**

| Глагол | Существительное | Артикль | Суффикс |
|---|---|---|---|
| entscheiden | Entscheidung | die | -ung |
| entwickeln | | | |
| vorstellen | | | |
| verlängern | | | |
| beginnen | | | |
| analysieren | | | |
| zustimmen | | | |
| beschleunigen | | | |
| verhandeln | | | |
| lösen | | | |

**Ответы:**
| Глагол | Существительное | Артикль |
|---|---|---|
| entwickeln | Entwicklung | die |
| vorstellen | Vorstellung | die |
| verlängern | Verlängerung | die |
| beginnen | Beginn / Beginn | der |
| analysieren | Analyse | die |
| zustimmen | Zustimmung | die |
| beschleunigen | Beschleunigung | die |
| verhandeln | Verhandlung | die |
| lösen | Lösung | die |

> **Правило суффиксов:**
> -ung (die) — самый распространённый: entscheiden → Entscheidung
> -heit/-keit (die) — от прилагательных: frei → Freiheit, möglich → Möglichkeit
> -nis (das/die) — ergebnis, Kenntnis
> -schaft (die) — Gesellschaft, Freundschaft
> нулевой суффикс (der) — часто от сильных глаголов: beginnen → Beginn, schreiben → Schrift

## Раздел 3: Трансформация предложений (Verb → Nomen)

**Перепишите разговорный стиль в официальный через Nominalisierung.**

Образец:
*Разг.:* Man hat beschlossen, dass man das Programm verlängert.
*Офиц.:* Die Verlängerung des Programms wurde beschlossen.

1. Man hat erklärt, dass man das Projekt unterstützt.
   → Die _______________________

2. Man plant, dass man die Kosten reduziert.
   → Die _______________________

3. Man hat festgestellt, dass die Situation sich verbessert hat.
   → Eine _______________________

4. Man hat vereinbart, dass man sich regelmäßig trifft.
   → Die _______________________

5. Es ist wichtig, dass man die Regeln beachtet.
   → Die Beachtung _______________________

**Ответы:**
1. Die Unterstützung des Projekts wurde erklärt.
2. Die Reduzierung der Kosten ist geplant.
3. Eine Verbesserung der Situation wurde festgestellt.
4. Die regelmäßigen Treffen wurden vereinbart.
5. Die Beachtung der Regeln ist wichtig.

---

## Раздел 4: Стилистические трансформации (Nomen → Verb)

**Сделайте текст живее — переведите из официального в разговорный стиль:**

1. Die Überprüfung der Unterlagen erfolgte durch den Mitarbeiter.
   → Der Mitarbeiter _______________________

2. Die Durchführung des Projekts ist für nächsten Monat geplant.
   → Das Projekt _______________________

3. Eine Steigerung der Produktivität konnte beobachtet werden.
   → Die Produktivität _______________________

4. Die Entscheidung zur Zusammenarbeit wurde getroffen.
   → Man hat beschlossen, _______________________

**Ответы:**
1. Der Mitarbeiter überprüfte die Unterlagen.
2. Das Projekt wird nächsten Monat durchgeführt.
3. Die Produktivität stieg / wurde gesteigert.
4. Man hat beschlossen, zusammenzuarbeiten.

## Раздел 6: Деловое письмо — применение

**Напишите короткое деловое письмо (5–7 предложений) на тему «Подтверждение встречи» или «Просьба о продлении срока». Используйте минимум 4 Nominalisierungen.**

*Подсказки:* die Bestätigung (подтверждение), die Verlängerung (продление), die Bitte (просьба), die Durchführung (проведение), die Zusammenarbeit (сотрудничество), die Genehmigung (разрешение)
