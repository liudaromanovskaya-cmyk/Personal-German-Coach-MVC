# Задание 16: Weg mit den typischen Fehlern! — B2 (Лексика + Грамматика)

**Тип:** Лексика — типичные ошибки русскоговорящих
**Уровень CEFR:** B2
**Источник:** «Weg mit den typischen Fehlern!» Teil 2 (Hueber), собственная практика
**Длительность:** 25–35 минут
**Навыки:** Самокоррекция, Точность речи, Лексическая грамотность

---

## Что и зачем

Это задание — про те ошибки, которые делают почти все русскоговорящие. Они не заметны на B1, но на B2 сразу выдают «иностранца». Цель — убрать автоматизм неправильных паттернов.

---

## Раздел 1: Ложные друзья переводчика

**Соедините немецкое слово с правильным переводом (не с тем, что кажется логичным):**

| Немецкое слово | Что кажется | Что на самом деле |
|---|---|---|
| aktuell | актуальный | current, present (не actual!) |
| eventuell | эвентуально | possibly, perhaps (не eventually!) |
| sensibel | сенсибельный | sensitive (не sensible!) |
| Gymnasium | гимназиум | academic high school (не gymnasium/зал!) |
| sympathisch | симпатичный | likeable, pleasant |
| Kontrolle | контроль | check, inspection (не control!) |
| praktisch | практический | practical, virtually (почти) |
| engagiert | ангажированный | dedicated, committed |

**Составьте по одному предложению с каждым словом — правильно:**

Например: *Das ist aktuell nicht möglich.* (Сейчас это невозможно.)

---

## Раздел 2: Типичные ошибки с предлогами

**Исправьте ошибки (все предложения содержат типичную ошибку):**

1. ❌ Ich erkläre dir über dieses Thema.
2. ❌ Er hat mich angerufen für mein Geburtstag.
3. ❌ Sie interessiert sich für die deutsche Grammatik zu lernen.
4. ❌ Ich warte auf den Bus seit einer Stunde.
5. ❌ Er hat Angst von Hunden.
6. ❌ Wir diskutieren über das Problem seit gestern.
7. ❌ Ich freue mich auf deinen Besuch sehr.
8. ❌ Sie hat mir von ihrer Reise nach erzählt.

**Ответы:**
1. Ich erkläre dir dieses Thema. *(erklären — без über)*
2. Er hat mich zu meinem Geburtstag angerufen. *(zu, не für)*
3. Sie interessiert sich dafür, deutsche Grammatik zu lernen. *(dafür + Infinitivkonstruktion)*
4. ✓ верно *(warten auf + Akkusativ + seit — всё правильно)*
5. Er hat Angst vor Hunden. *(Angst vor, не von)*
6. ✓ верно *(diskutieren über + Akkusativ — но! seit gestern → правильно)*
7. ✓ верно *(freuen auf + Akkusativ)*
8. Sie hat mir von ihrer Reise erzählt. *(nach убрать)*

## Раздел 3: Falsche Freunde — глаголы

**Выберите правильный вариант:**

1. Ich möchte dir etwas (mitteilen / vermitteln), dass ich komme.
   *(mitteilen = сообщить; vermitteln = посредничать, передавать навык)*

2. Er hat das Projekt (durchgeführt / ausgeführt).
   *(durchführen = осуществить; ausführen = выполнить/экспортировать)*

3. Das hat mich sehr (beeindruckt / beeinflussen).
   *(beeindrucken = произвести впечатление; beeinflussen = влиять)*

4. Können Sie mir das (erklären / beschreiben)?
   *(erklären = объяснить; beschreiben = описать)*

5. Die Kosten haben sich (erhöht / gestiegen).
   *(sich erhöhen = быть повышенным — reflexiv; steigen — intransitiv: Die Kosten sind gestiegen)*

**Ответы:** 1-mitteilen, 2-durchgeführt, 3-beeindruckt, 4-erklären или beschreiben (оба возможны — объяснить разницу), 5-Die Kosten haben sich erhöht / Die Kosten sind gestiegen

## Раздел 4: Wortpaare — частые путаницы

**Объясните разницу и составьте примеры:**

| Пара | Разница |
|---|---|
| kennen / wissen | kennen = знать кого-то/что-то (знакомство); wissen = знать факт |
| bringen / holen | bringen = нести туда; holen = идти за чем-то и приносить |
| leihen / borgen / mieten | leihen = давать/брать бесплатно; mieten = арендовать за деньги |
| sagen / erzählen / berichten | sagen = говорить; erzählen = рассказывать историю; berichten = докладывать |
| lernen / studieren | lernen = учить (школа/самостоятельно); studieren = учиться в вузе |
| merken / bemerken | merken = замечать для себя; bemerken = заметить (+ сказать об этом) |

**Заполните пропуски правильным глаголом:**

1. Er _______ an der Universität München Medizin. *(studieren/lernen)*
2. Kannst du mir dein Fahrrad _______? *(leihen/mieten)*
3. Ich _______ nicht, wie spät es ist. *(wissen/kennen)*
4. Sie hat ihm _______, dass sie kommt. *(gesagt/erzählt)*
5. Hast du _______-, dass er sich verändert hat? *(gemerkt/bemerkt)*

**Ответы:** 1-studiert, 2-leihen, 3-weiß, 4-gesagt, 5-gemerkt / bemerkt (оба возможны)

## Раздел 5: Falsche Konnektoren

**Типичная ошибка русскоговорящих — дословный перевод союзов.**

Исправьте неверные союзы:

1. ❌ Ich bin müde, aber trotzdem ich gehe arbeiten.
   → _______________________

2. ❌ Da ich habe keine Zeit, ich kann nicht kommen.
   → _______________________

3. ❌ Er lernt Deutsch, denn er will nach Deutschland umziehen.
   → *(здесь ошибки нет — но объясните разницу denn/weil)*

4. ❌ Obwohl er ist krank, er arbeitet weiter.
   → _______________________

5. ❌ Ich habe gekauft das Buch, was du empfohlen hast.
   → _______________________

**Ответы:**
1. Ich bin müde, aber ich gehe trotzdem arbeiten. *(trotzdem — наречие, после него инверсия)*
2. Da ich keine Zeit habe, kann ich nicht kommen. *(глагол в конце придаточного)*
3. Верно — но: denn = координирующий (прямой порядок слов); weil = подчинительный (глагол в конце)
4. Obwohl er krank ist, arbeitet er weiter. *(глагол в конце в obwohl-предложении)*
5. Ich habe das Buch gekauft, das du empfohlen hast. *(das, не was — Buch конкретное)*

## Шаги выполнения

1. Раздел 1 — выучить все «ложные друзья» + составить предложения
2. Разделы 2–5 — исправить БЕЗ просмотра ответов
3. Проверить по ответам — отметить, какие ошибки были «своими»
4. Минимум 5 «своих» ошибок → Anki-карточки
5. Написать 5 предложений, намеренно используя сложные пары из раздела 4
