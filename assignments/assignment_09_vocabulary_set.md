**Тип:** Vocabulary Set

**Длительность:** 15–20 минут

## Цель задания

Освоить тематическую лексику через активное использование: не просто запомнить слово, а использовать его в предложениях и диалогах.

## Упражнения

### Упражнение 1: Заполни пропуски (выберите тему)
Составьте 5 предложений с новыми словами на вашу ситуацию. Каждое слово — в новом контексте (не копировать из таблицы).

### Упражнение 2: Коллокации
Подберите глаголы, которые сочетаются с каждым существительным:
- Beispiel: Anmeldung → **machen / beantragen / bekommen**
- Rezept → ?
- Termin → ?
- Software → ?
- Fehler → ?

### Упражнение 3: Anki-карточки
Создайте карточки для 8 слов (из новых для вас):
```
Слово;Перевод;Пример предложения;Мнемоника/ассоциация
```

### Упражнение 4: Мини-диалог
Используйте минимум 5 слов из набора в коротком диалоге (8–10 реплик) или тексте. Запишите аудио или напишите.
