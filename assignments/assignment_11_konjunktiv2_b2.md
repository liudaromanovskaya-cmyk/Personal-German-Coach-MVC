# Задание 11: Konjunktiv II — Гипотеза, вежливость, нереальное условие (B2)

**Тип:** Грамматика — Konjunktiv II
**Уровень CEFR:** B2
**Источник:** Grammatik Aktiv B2–C1 (Cornelsen), Übungsgrammatik Mittelstufe
**Длительность:** 25–35 минут
**Навыки:** Грамматика, Письмо, Речевые формулы

---

## Что и зачем

Konjunktiv II — это то, что отличает уверенного носителя от «правильного, но деревянного» немецкого.
Без него невозможны вежливые просьбы, предположения, сожаления, советы и нереальные условия.

---

## Раздел 1: Образование форм (разминка)

**Образуйте Konjunktiv II от следующих глаголов. Укажите и форму würde + Infinitiv.**

| Глагол | Konjunktiv II (ich) | würde-Form |
|---|---|---|
| sein | wäre | würde sein ✗ (не используется) |
| haben | | |
| können | | |
| müssen | | |
| dürfen | | |
| wollen | | |
| werden | | |
| gehen | | |
| kommen | | |
| wissen | | |

> **Правило:** Модальные глаголы, sein, haben, werden, wissen, bleiben — всегда в собственной форме Konjunktiv II. Остальные — через würde + Infinitiv.

**Ответы:**

| Глагол | Konjunktiv II (ich) |
|---|---|
| haben | hätte |
| können | könnte |
| müssen | müsste |
| dürfen | dürfte |
| wollen | wollte |
| werden | würde |
| gehen | würde gehen |
| kommen | würde kommen |
| wissen | wüsste |

## Раздел 2: Вежливые просьбы и вопросы

**Перефразируйте — сделайте вежливее с помощью Konjunktiv II.**

1. Können Sie mir helfen? → _______________________
2. Darf ich fragen? → _______________________
3. Schließen Sie bitte das Fenster! → _______________________
4. Haben Sie einen Moment Zeit? → _______________________
5. Ich will einen Termin vereinbaren. → _______________________
6. Geben Sie mir bitte Ihre Nummer. → _______________________

**Ответы:**
1. Könnten Sie mir helfen?
2. Dürfte ich fragen?
3. Würden Sie bitte das Fenster schließen?
4. Hätten Sie einen Moment Zeit?
5. Ich würde gern einen Termin vereinbaren.
6. Würden Sie mir bitte Ihre Nummer geben?

## Раздел 3: Нереальные условия (Irrealis)

**Дополните предложения логичным Konjunktiv II. Используйте глагол из скобок.**

1. Wenn ich mehr Zeit _______ (haben), _______ ich mehr Sport _______ (treiben).
2. Wenn er besser Deutsch _______ (sprechen), _______ er die Stelle _______ (bekommen).
3. Wenn wir früher _______ (aufstehen), _______ wir den Zug nicht _______ (verpassen).
4. Wenn das Wetter schöner _______ (sein), _______ wir einen Ausflug _______ (machen).
5. Wenn ich du _______ (sein), _______ ich das nicht _______ (akzeptieren).
6. Wenn sie mehr _______ (üben), _______ ihr Deutsch deutlich besser _______ (sein).

**Ответы:**
1. hätte / würde … treiben
2. sprechen würde / würde … bekommen
3. aufgestanden wären / hätten … verpasst *(Plusquamperfekt Konjunktiv — прошлое!)*
4. wäre / würden … machen
5. wäre / würde … akzeptieren
6. üben würde / wäre … (besser sein würde)

## Раздел 4: Konjunktiv II Vergangenheit (сожаление о прошлом)

**Это самая частая ошибка на B2. Образец:**
*Wenn ich das gewusst hätte, wäre ich nicht gegangen.*

**Переведите / трансформируйте:**

1. Жаль, что он не позвонил. (rufen an)
   → Es wäre schade gewesen, wenn er nicht ___________________________
2. Если бы я тогда больше занималась, я бы сдала экзамен.
   → Wenn ich damals mehr _________________________, hätte ich die Prüfung _________________________
3. Он мог бы сказать правду. (sagen)
   → Er hätte die Wahrheit _________________________
4. Нам не нужно было идти туда. (gehen)
   → Wir hätten dort nicht _________________________

**Ответы:**
1. angerufen hätte
2. gelernt hätte / bestanden
3. sagen können
4. hingehen müssen

## Раздел 6: Типичные ошибки (найди и исправь)

1. ❌ Wenn ich wäre reicher, würde ich reisen.
2. ❌ Er würde wissen die Antwort, wenn er studiert hätte.
3. ❌ Ich würde gern gewesen sein in Paris.
4. ❌ Könnten Sie mir sagen, wo ist der Bahnhof?
5. ❌ Wenn ich das gewusst hätte, ich wäre nicht gegangen.

**Ответы:**
1. Wenn ich reicher wäre, würde ich reisen. *(wäre — в конец придаточного)*
2. Er würde die Antwort wissen, wenn er studiert hätte. *(порядок слов)*
3. Ich wäre gern in Paris gewesen. *(nicht würde + Infinitiv Perfekt)*
4. Könnten Sie mir sagen, wo der Bahnhof ist? *(косвенный вопрос — прямой порядок слов отменяется)*
5. Wenn ich das gewusst hätte, wäre ich nicht gegangen. *(в главном — инверсия, не прямой порядок)*
