## Что и зачем

Словообразование — это ключ к немецкому словарному запасу. Зная 500 корней и принципы словообразования, можно понять 3000+ слов. Для B2 обязательны: префиксы глаголов, суффиксы существительных/прилагательных, словосложение (Komposita).

## Раздел 1: Приставки глаголов — trennbar vs. untrennbar

**Trennbare Präfixe** (всегда ударные): ab-, an-, auf-, aus-, ein-, mit-, nach-, vor-, zu-, zurück-, zusammen-

**Untrennbare Präfixe** (безударные, без ge- в Partizip II): be-, er-, ge-, miss-, ver-, zer-, ent-, emp-

**Определите тип и образуйте Partizip II:**

| Глагол | Тип | Partizip II |
|---|---|---|
| anrufen | trennbar | angerufen |
| verstehen | | |
| aufmachen | | |
| erklären | | |
| einladen | | |
| beschreiben | | |
| zurückkommen | | |
| missbrauchen | | |
| vorstellen | | |
| entscheiden | | |
| zusammenfassen | | |
| zerbrechen | | |

**Ответы:**
| Глагол | Тип | Partizip II |
|---|---|---|
| verstehen | untrennbar | verstanden |
| aufmachen | trennbar | aufgemacht |
| erklären | untrennbar | erklärt |
| einladen | trennbar | eingeladen |
| beschreiben | untrennbar | beschrieben |
| zurückkommen | trennbar | zurückgekommen |
| missbrauchen | untrennbar | missbraucht |
| vorstellen | trennbar | vorgestellt |
| entscheiden | untrennbar | entschieden |
| zusammenfassen | trennbar | zusammengefasst |
| zerbrechen | untrennbar | zerbrochen |

## Раздел 2: Значения приставок глаголов

**ver-** часто означает «ошибочно» или «изменение до конца»:
- verschreiben (выписать) / sich verschreiben (ошибиться в написании)
- verstehen (понимать) / sich verstehen (ладить)

**ent-** = начало действия или отделение:
- entstehen (возникать), entlassen (увольнять), entscheiden (решать)

**zer-** = разрушение:
- zerbrechen (разбить), zerstören (уничтожить), zerreißen (разорвать)

**mis(s)-** = неправильно:
- missverstehen (неправильно понять), missbrauchen (злоупотреблять)

**Угадайте значение по приставке:**

1. veralten → _______________________
2. entmutigen → _______________________
3. zerkleinern → _______________________
4. sich verirren → _______________________
5. enttäuschen → _______________________
6. misstrauen → _______________________

**Ответы:**
1. устаревать (ver- = до конца)
2. обескуражить, лишить смелости (ent- = лишить)
3. измельчить (zer- = разрушение)
4. заблудиться (ver- = ошибочно)
5. разочаровывать (ent- = обратное)
6. не доверять (miss- = неправильно)

## Раздел 4: Komposita — словосложение

**Немецкий строит сложные слова из нескольких корней. Последнее слово определяет артикль.**

**Расшифруйте Komposita — разбейте на части и переведите:**

1. Berufsausbildung → _______ + _______ = _______
2. Gesundheitspolitik → _______ + _______ = _______
3. Arbeitsgenehmigung → _______ + _______ = _______
4. Sprachkenntnisse → _______ + _______ = _______
5. Entscheidungsfreiheit → _______ + _______ = _______
6. Aufenthaltsgenehmigung → _______ + _______ = _______
7. Weiterbildungsmöglichkeit → _______ + _______ + _______ = _______

**Ответы:**
1. Beruf + Ausbildung = профессиональное обучение (die)
2. Gesundheit + Politik = политика в области здравоохранения (die)
3. Arbeit + Genehmigung = разрешение на работу (die)
4. Sprache + Kenntnisse = языковые знания (die, Pl.)
5. Entscheidung + Freiheit = свобода выбора/решения (die)
6. Aufenthalt + Genehmigung = вид на жительство (die)
7. Weiter + Bildung + Möglichkeit = возможность дополнительного обучения (die)

**Составьте 5 собственных Komposita, которые вы встречали в жизни (на работе, в документах, в быту).**

## Раздел 5: Суффиксы прилагательных

| Суффикс | Значение | Примеры |
|---|---|---|
| -lich | связанный с, характерный | persönlich, freundlich, täglich |
| -ig | имеющий качество | wichtig, ruhig, mutig |
| -isch | относящийся к | deutsch, europäisch, kindisch |
| -bar | возможность | machbar, lesbar, hörbar |
| -sam | медленно, постепенно | langsam, wirksam, gemeinsam |
| -los | без | arbeitslos, hoffnungslos, sprachlos |
| -voll | полный чего-то | stressvoll, hoffnungsvoll |
| -reich | богатый чем-то | erfolgreich, erfahrungsreich |

**Переведите прилагательные, используя суффикс:**

1. невозможный → _______________________
2. успешный → _______________________
3. ежедневный → _______________________
4. безработный → _______________________
5. разговорчивый → _______________________
6. понятный (можно понять) → _______________________
7. нервный (stressig) → _______________________
8. полный надежды → _______________________

**Ответы:** 1-unmöglich, 2-erfolgreich, 3-täglich, 4-arbeitslos, 5-gesprächig, 6-verständlich, 7-stressig, 8-hoffnungsvoll
