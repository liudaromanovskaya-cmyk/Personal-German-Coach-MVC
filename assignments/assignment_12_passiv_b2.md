# Задание 12: Passiv — все формы и конструкции (B2)

**Тип:** Грамматика — Passiv
**Уровень CEFR:** B2
**Источник:** Grammatik Aktiv B2–C1, Übungsgrammatik Mittelstufe
**Длительность:** 30–40 минут
**Навыки:** Грамматика, Письмо, Академический стиль

---

## Что и зачем

Passiv — обязателен для B2. Без него невозможны деловые тексты, официальные документы, новости, инструкции. На экзамене Goethe B2 он встречается в каждом разделе.

## Справочная таблица

| Форма | Структура | Пример |
|---|---|---|
| Präsens Passiv | wird + Partizip II | Das Formular wird ausgefüllt. |
| Präteritum Passiv | wurde + Partizip II | Das Formular wurde ausgefüllt. |
| Perfekt Passiv | ist + Partizip II + worden | Das Formular ist ausgefüllt worden. |
| Plusquamperfekt Passiv | war + Partizip II + worden | Das Formular war ausgefüllt worden. |
| Futur I Passiv | wird + Partizip II + werden | Das Formular wird ausgefüllt werden. |
| Zustandspassiv | ist/war + Partizip II | Das Formular ist ausgefüllt. |
| Modalverb + Passiv | muss/kann + Partizip II + werden | Das muss gemacht werden. |

## Раздел 1: Vorgangspassiv — образование форм

**Поставьте предложения в нужную форму Passiv.**

**Präsens Passiv:**
1. Man baut eine neue Brücke. → Eine neue Brücke _______________________
2. Man diskutiert das Problem. → Das Problem _______________________
3. Man untersucht den Patienten. → Der Patient _______________________

**Präteritum Passiv:**
4. Man erfand das Telefon 1876. → Das Telefon _______________________
5. Man verabschiedete das Gesetz im Parlament. → Das Gesetz _______________________

**Perfekt Passiv:**
6. Man hat die Entscheidung getroffen. → Die Entscheidung _______________________
7. Man hat das Museum renoviert. → Das Museum _______________________

**Ответы:**
1. wird gebaut
2. wird diskutiert
3. wird untersucht
4. wurde 1876 erfunden
5. wurde im Parlament verabschiedet
6. ist getroffen worden
7. ist renoviert worden

## Раздел 2: Zustandspassiv vs. Vorgangspassiv

**Zustandspassiv описывает результат, Vorgangspassiv — процесс. Определите тип и переведите.**

1. Das Büro ist geschlossen. → _______________________
2. Das Büro wird geschlossen. → _______________________
3. Die Tür war repariert. → _______________________
4. Die Tür wurde repariert. → _______________________
5. Der Vertrag ist unterschrieben. → _______________________
6. Der Vertrag wird unterschrieben. → _______________________

**Ответы:**
1. Zustandspassiv — Офис закрыт (состояние)
2. Vorgangspassiv — Офис закрывается (процесс)
3. Zustandspassiv — Дверь была отремонтирована (состояние в прошлом)
4. Vorgangspassiv — Дверь ремонтировали (действие в прошлом)
5. Zustandspassiv — Договор подписан
6. Vorgangspassiv — Договор подписывается

## Раздел 3: Passiv с модальными глаголами

**Трансформируйте.**

Образец: Man muss das Problem lösen. → Das Problem muss gelöst werden.

1. Man kann das Formular online ausfüllen. → _______________________
2. Man muss die Regeln beachten. → _______________________
3. Man sollte die Kosten reduzieren. → _______________________
4. Man darf das Gebäude nicht betreten. → _______________________
5. Man müsste die Situation verbessern. → _______________________
6. Man könnte den Termin verschieben. → _______________________

**Ответы:**
1. Das Formular kann online ausgefüllt werden.
2. Die Regeln müssen beachtet werden.
3. Die Kosten sollten reduziert werden.
4. Das Gebäude darf nicht betreten werden.
5. Die Situation müsste verbessert werden.
6. Der Termin könnte verschoben werden.

## Раздел 4: Passiv-Alternativen (важно для B2!)

На B2 нужно уметь выражать пассивное значение разными способами.

| Конструкция | Пример | Значение |
|---|---|---|
| sein + zu + Infinitiv | Das ist zu beachten. | можно/нужно сделать |
| lassen + sich + Infinitiv | Das lässt sich lösen. | можно сделать |
| man + Aktiv | Man nimmt die Tablette täglich. | нейтральное действие |
| Partizip II als Adjektiv | ein gelöstes Problem | результат действия |

**Трансформируйте, используя указанную конструкцию:**

1. Das muss beachtet werden. → Das ist _______________________ (sein + zu)
2. Das Problem kann gelöst werden. → Das Problem lässt _______________________ (lassen + sich)
3. Es wird empfohlen, täglich zu üben. → Man _______________________ (man + Aktiv)
4. Das Problem wurde gelöst. → das _______________________ Problem (Partizip als Adjektiv)

**Ответы:**
1. Das ist zu beachten.
2. Das Problem lässt sich lösen.
3. Man empfiehlt, täglich zu üben.
4. das gelöste Problem

## Раздел 5: von vs. durch в Passiv

**von** = исполнитель (живое существо, организация)
**durch** = средство, причина, посредник

**Вставьте von или durch:**

1. Das Buch wurde _______ dem bekannten Autor geschrieben.
2. Die Stadt wurde _______ einen Sturm zerstört.
3. Der Antrag wurde _______ der Behörde abgelehnt.
4. Die Nachricht wurde _______ die Medien verbreitet.
5. Er wurde _______ seinem Kollegen unterstützt.
6. Die Wunde wurde _______ eine Infektion verursacht.

**Ответы:** 1-von, 2-durch, 3-von, 4-durch, 5-von, 6-durch

## Раздел 6: Перевод на немецкий (синтез)

1. Это здание было построено в 1905 году.
2. Все документы должны быть поданы до пятницы.
3. Встреча была перенесена. (состояние)
4. Детей нельзя оставлять одних.
5. Эту проблему можно решить несколькими способами. *(lassen sich)*
6. Заявление рассматривается. *(Präsens)*

**Ответы:**
1. Dieses Gebäude wurde 1905 gebaut / erbaut.
2. Alle Unterlagen müssen bis Freitag eingereicht werden.
3. Das Treffen ist verschoben (worden).
4. Kinder dürfen nicht allein gelassen werden.
5. Dieses Problem lässt sich auf verschiedene Arten lösen.
6. Der Antrag wird bearbeitet.
