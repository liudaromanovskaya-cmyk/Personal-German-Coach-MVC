## Опросник студента — настроить и прочитать

### Настроить входящий опросник (один раз на студента)

1. Открыть панель педагога
2. Выбрать вкладку студента
3. Найти раздел **"📋 Опросник студента"**
4. Нажать **"⚙️ Настроить"**
5. Увидишь список из 28 вопросов по 7 категориям
6. Поставить галочки рядом с нужными вопросами
7. Или нажать **"Минимальный набор"** (10 ключевых вопросов) — рекомендуется для первого знакомства
8. Нажать **"Сохранить конфигурацию"**

**Когда студент зайдёт в кабинет первый раз** — он автоматически увидит визард с выбранными вопросами. Один вопрос на экран. 10-15 минут.

---

### Прочитать ответы студента

1. Панель педагога → вкладка студента → раздел "📋 Опросник"
2. Нажать **"👁 Ответы"**
3. Видишь все вопросы и ответы студента

**Что делать с ответами (перед первым занятием, 5-10 минут):**

| Блок вопросов | На что обращать внимание |
|--------------|--------------------------|
| Q1–Q4 (Мотивация) | Зачем немецкий, есть ли дедлайн, критические ситуации |
| Q9–Q12 (Время) | Сколько минут в день, можно ли говорить вслух |
| Q13–Q16 (Психология) | Страх ошибки, акцент, что стопорит говорение |
| Q17–Q19 (Ожидания) | Как исправлять, строгость, точность vs беглость |
| Q21–Q22 (Форматы) | Что нравится, что точно нет |
| Q26 (Приоритет) | Говорение / слушание / письмо / грамматика |

**Сигналы тревоги → менять подход:**
- Высокий страх ошибки (Q13: "Боюсь сделать ошибку") → начинать с Niveau 1, хвалить попытки, не перебивать
- Нет времени говорить вслух (Q12: "Только тихие форматы") → больше письменных заданий
- Дедлайн через 2 месяца (Q3) → убрать всё лишнее, только целевые ситуации
- Плохой опыт с правилами (Q7) → объяснять через примеры, не через таблицы

## Добавить нового студента (без кода!)

1. Открыть панель педагога
2. Нажать вкладку **➕ Новый** (справа в шапке)
3. Заполнить:
   - **Имя** — как зовут студента (Анна)
   - **ID** — латиницей, без пробелов (anna)
   - **Уровень** — A1 / A2 / B1 / B2 / C1
   - **Цель** — зачем учит немецкий
   - **Дедлайн** — когда нужен результат
4. Нажать **"Создать кабинет"**
5. Скопировать ссылку → отправить студенту

Кабинет готов сразу. Код трогать не нужно.

## Заполнить задание на день

1. Открыть панель педагога
2. Выбрать вкладку студента (Ольга / Артём / Юлия / другой)
3. Заполнить поля:
   - **Слова** (6 штук) — слово + подсказка + грамматика + чанки
   - **Задания Sprechen** — тема + промпт + инструкция + подсказка (3 уровня)
   - **Задания Schreiben** — то же самое
   - **Пост-сабмишн** — что закрыли / почему важно / завтра
   - **Грамматика недели** — правило + примеры
4. Нажать **"Сохранить"** (зелёная кнопка)

Студент видит задание сразу на всех устройствах.
Студенту приходит Telegram-уведомление: *"Ваше задание готово"*.

## Firebase Security Rules — когда обновлять

Обновлять нужно только когда добавляете новый тип данных (бывает редко).

**Текущие правила** (файл `database.rules.json` в корне проекта):
```json
{
  "rules": {
    "teacher":      { "$id": { ".read": true, ".write": "auth != null" } },
    "submissions":  { "$id": { ".read": "auth != null", ".write": true } },
    "progress":     { "$id": { ".read": true, ".write": true } },
    "students":     { "$id": { ".read": true, ".write": "auth != null" } }
  }
}
```

**Как обновить:**
1. Открыть ссылку Firebase выше
2. Вкладка Rules
3. Вставить новые правила
4. Нажать Publish

## Интервальное повторение слов

Система автоматически отслеживает когда слово нужно повторить — по кривой Эббингауза.

**Интервалы:**
| Оценка студента | Когда повторить |
|----------------|-----------------|
| ⬛ совсем забыла | завтра |
| 🔴 не знаю | через 2 дня |
| 🟡 частично | через 4 дня |
| 🟢 знаю | через 10 дней |

**Что видит студент:**
- В банке слов — 4 кнопки: ⬛🔴🟡🟢
- Если слово уже было раньше — бейдж `🔄 повторение`

**Что видит педагог (teacher.html):**
- Раздел "🔄 На повторение сегодня" — нажать "Загрузить"
- Слова разделены на: "⚠️ Пора повторить" и "Скоро"
- Для каждого слова: когда было, статус тогда, чанк, сколько раз использовала в речи

**Как использовать:**
1. Перед составлением нового задания — открыть "На повторение сегодня"
2. Включить нужные слова в новый спринт вручную
3. Слово получит бейдж 🔄 в кабинете студента

**Счётчик "в речи"** — показывает сколько раз слово встретилось в submissions студента. Если 3+ раз — слово освоено.

## История заданий — Lernjournal

В teacher.html раздел **📅 История — Lernjournal** — полный архив всех дней.

**Как работает:**
- Каждый раз когда нажимаешь "Сохранить" — день автоматически сохраняется в архив
- Архив содержит: тему, слова со статусами 🟢🟡🔴, работу студента, твой фидбек

**Как смотреть:**
1. Открыть teacher.html
2. Прокрутить вниз до раздела "📅 История"
3. Нажать "🔄 Загрузить"
4. Видишь все дни — от новых к старым
5. Нажать на день → раскрывается полный срез

**Что видно в каждом дне:**
- Тема дня и статус (сдано / есть фидбек)
- Слова с оценкой студента 🟢🟡🔴 на тот момент
- Текст работы студента
- Твой фидбек

**Для чего использовать:**
- Перед встречей — вспомнить что давала последние недели
- 4-недельный срез — открыть 28 дней назад и сравнить с сегодня
- Видеть паттерны: какие слова постоянно 🔴, по каким темам нет прогресса

## Установить кабинет как приложение на телефон (PWA)

Студент может добавить кабинет на рабочий стол — выглядит как обычное приложение.

**iPhone (Safari):**
1. Открыть ссылку кабинета в Safari
2. Нажать кнопку "Поделиться" (квадрат со стрелкой вверх)
3. Выбрать "На экран Домой"
4. Нажать "Добавить"

**Android (Chrome):**
1. Открыть ссылку кабинета в Chrome
2. Меню (три точки) → "Добавить на главный экран"
3. Нажать "Добавить"

После этого на рабочем столе появится иконка "Deutsch" — зелёная с буквой D.
Открывается без адресной строки браузера, как настоящее приложение.
Работает офлайн — показывает последние загруженные данные.
