## Добавить нового студента (без кода!)

1. Открыть панель педагога
2. Нажать вкладку **➕ Новый** (справа в шапке)
3. Заполнить:
   - **Имя** — как зовут студента (Анна)
   - **ID** — латиницей, без пробелов (anna)
   - **Уровень** — A1 / A2 / B1 / B2 / C1
   - **Цель** — зачем учит немецкий
   - **Дедлайн** — когда нужен результат
4. Нажать **"Создать кабинет"**
5. Скопировать ссылку → отправить студенту

Кабинет готов сразу. Код трогать не нужно.

## Заполнить задание на день

1. Открыть панель педагога
2. Выбрать вкладку студента (Ольга / Артём / Юлия / другой)
3. Заполнить поля:
   - **Слова** (6 штук) — слово + подсказка + грамматика + чанки
   - **Задания Sprechen** — тема + промпт + инструкция + подсказка (3 уровня)
   - **Задания Schreiben** — то же самое
   - **Пост-сабмишн** — что закрыли / почему важно / завтра
   - **Грамматика недели** — правило + примеры
4. Нажать **"Сохранить"** (зелёная кнопка)

Студент видит задание сразу на всех устройствах.
Студенту приходит Telegram-уведомление: *"Ваше задание готово"*.

## Посмотреть домашние задания студентов (Eingänge)

1. Открыть панель педагога
2. Раздел **📥 Eingänge** — вверху страницы
3. Нажать **🔄 Обновить** чтобы загрузить свежие работы
4. Видны все студенты, все дни, все уровни — с текстом работы

---

## Отправить фидбек студенту

1. В разделе Eingänge найти нужную работу
2. Внизу карточки — поле **"Мой ответ студенту"**
3. Написать комментарий
4. Нажать **"Отправить фидбек"**

Студент видит зелёную карточку "💬 Kommentar der Lehrerin" в своём кабинете.
Студенту приходит Telegram-уведомление: *"Лиуда ответила на ваше задание"*.

## Недельный план через Gemini

1. Панель педагога → раздел **Недельный план**
2. Ввести тему недели и API ключ Gemini

4. Отредактировать если нужно

Или: вставить готовый JSON вручную (кнопка "Вставить JSON").

## Telegram-уведомления — как настроить для нового студента

**Автоматически:** когда студент первый раз открывает кабинет через Telegram — его ID сохраняется сам. Ничего делать не нужно.

**Что нужно от студента (один раз):**
1. Открыть Telegram
2. Найти **@PersonalGermanCoachBot**
3. Нажать **Start**
4. Открыть кабинет через кнопку в боте

После этого все уведомления приходят автоматически.

## Firebase Security Rules — когда обновлять

Обновлять нужно только когда добавляете новый тип данных (бывает редко).

**Текущие правила** (файл `database.rules.json` в корне проекта):
```json
{
  "rules": {
    "teacher":      { "$id": { ".read": true, ".write": "auth != null" } },
    "submissions":  { "$id": { ".read": "auth != null", ".write": true } },
    "progress":     { "$id": { ".read": true, ".write": true } },
    "students":     { "$id": { ".read": true, ".write": "auth != null" } }
  }
}
```

**Как обновить:**
1. Открыть ссылку Firebase выше
2. Вкладка Rules
3. Вставить новые правила
4. Нажать Publish

## Установить кабинет как приложение на телефон (PWA)

Студент может добавить кабинет на рабочий стол — выглядит как обычное приложение.

**iPhone (Safari):**
1. Открыть ссылку кабинета в Safari
2. Нажать кнопку "Поделиться" (квадрат со стрелкой вверх)
3. Выбрать "На экран Домой"
4. Нажать "Добавить"

**Android (Chrome):**
1. Открыть ссылку кабинета в Chrome
2. Меню (три точки) → "Добавить на главный экран"
3. Нажать "Добавить"

После этого на рабочем столе появится иконка "Deutsch" — зелёная с буквой D.
Открывается без адресной строки браузера, как настоящее приложение.
Работает офлайн — показывает последние загруженные данные.

## Если что-то сломалось

| Проблема | Решение |
|----------|---------|
| Панель педагога не сохраняет | Проверить авторизацию — нажать F5, войти снова |
| Студент не видит задание | Попросить обновить страницу (F5) |
| Уведомления не приходят | Студент ещё не нажал Start в боте |
| Данные не загружаются | Проверить Firebase Console → нет ли ошибок в Rules |
