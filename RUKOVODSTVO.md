## Полный цикл работы со студентом — каждый день

```
УТРО
  → Заполнить задание в teacher.html → Сохранить
  → Студент получает уведомление в Telegram

ДЕНЬ
  → Студент занимается: слушает слова, записывает голос, пишет текст
  → Нажимает "Abschicken" — работа летит в Firebase

ВЕЧЕР
  → Eingänge → слушать аудио → транскрибировать → AI-черновик
  → Редактировать → Отправить фидбек
  → Студент видит в кабинете + приходит уведомление

РАЗ В НЕДЕЛЮ (по пятницам рекомендуется)
  → Eingänge → "📊 Анализ архива" → AI находит паттерны ошибок
  → Использовать для составления задания на следующую неделю
```

## Записать голос (студент) — как работает

Студент открывает кабинет → вкладка Aufgabe → кнопка **"Aufnehmen"**:
1. Записывает до 90 секунд
2. Запись загружается в Cloudinary (облако)
3. Если Cloudinary недоступен (VPN и т.п.) — автоматически сохраняется как base64 прямо в Firebase
4. Студент видит "✓ Готово к отправке" — в обоих случаях
5. Нажимает "Abschicken" — работа в Firebase

**Педагог всегда слышит аудио** — плеер отображается в Eingänge вне зависимости от способа хранения.

## Посмотреть домашние задания (Eingänge)

1. Открыть панель педагога
2. Раздел **📥 Eingänge** — вверху страницы
3. Нажать **🔄 Обновить**
4. Видны все студенты, все дни, все уровни

**В каждой карточке:**
- 🎵 Аудиоплеер — послушать запись
- **"🎙 Транскрибировать (Whisper)"** — точная расшифровка речи
- **"🤖 Черновик фидбека (AI)"** — AI пишет анализ
- Поле **"Мой ответ студенту"** — редактировать черновик
- **"✉️ Отправить фидбек"**

## Как работает AI-черновик фидбека

1. Нажать **"🤖 Черновик фидбека (AI)"**
2. AI пишет по методологии:
   - Тёплое обращение с именем студента (на "Вы")
   - Анализ конкретных ошибок + как говорит носитель ("немец скажет так")
   - Образ-якорь для запоминания
   - Redewendung (устойчивое выражение по теме)
   - Похвалу за что-то конкретное
   - Вопрос в конце (продолжение диалога)
3. Черновик появляется в поле фидбека
4. Отредактировать — AI только черновик, финал всегда за педагогом
5. Нажать **"✉️ Отправить фидбек"**

**Настройка AI (один раз):**
- Нужен API ключ OpenRouter (openrouter.ai)
- Вставить в поле "OpenRouter API Key" в teacher.html
- Ключ сохраняется в браузере

## Отправить фидбек студенту

1. В Eingänge → поле "Мой ответ студенту" → написать или использовать AI-черновик
2. Нажать **"✉️ Отправить фидбек"**

**Что происходит автоматически:**

Фидбек сохраняется в **3 места**:
- `submissions/` — история в Eingänge для педагога
- `progress/lastTeacherFeedback` — студент видит в кабинете сразу
- `feedback/{дата}` — **архив** (накапливается навсегда, используется для анализа)

Студент получает уведомление в Telegram.

**Студент видит:**
- Терракотовая карточка **"💬 Kommentar der Lehrerin"** — самый верх кабинета
- По умолчанию свёрнута (первые 55 символов как превью)
- Тапает → разворачивается полный текст

## Архив фидбека и анализ паттернов ошибок

### Что видит студент
Вкладка **Feedback** → прокрутить вниз → **"Feedback-Archiv"**
Все прошлые фидбеки по датам — аккордеон, каждый открывается по тапу.
Студент всегда может вернуться к любому фидбеку.

### Анализ архива (раз в неделю)
1. Eingänge → карточка студента → кнопка **"📊 Анализ архива"**
2. AI читает все накопленные фидбеки
3. Выдаёт структурированный отчёт:
   - **Повторяющиеся грамматические ошибки** — паттерны с примерами
   - **Рекомендуемая грамматическая тема недели** — одна, с обоснованием
   - **Лексика из фидбека → в следующий спринт** — слова, Redewendungen, конструкции
   - **Прогресс** — что улучшилось
   - **Приоритет на следующую неделю**

**Как использовать результат:**
- Слова из отчёта → добавить в следующий спринт (поле "Слова")
- Грамматика → добавить в поле "Грамматика недели"
- Фидбек не умирает — он становится основой для следующего обучения

## Заполнить задание на день

1. Панель педагога → вкладка студента
2. Заполнить:
   - **Слова** (6 штук) — слово + подсказка + грамматика + чанки
   - **Задания Sprechen** — тема + промпт + инструкция + подсказка (3 уровня)
   - **Задания Schreiben** — то же самое
   - **Пост-сабмишн** — что закрыли / почему важно / завтра
   - **Грамматика недели** — правило + примеры
3. Нажать **"Сохранить"**

## Dashboard — статистика студентов

Панель педагога → раздел **📊 Статистика студентов** → нажать **🔄 Обновить**

По каждому студенту видно:
| Показатель | Что значит |
|-----------|-----------|
| Дней в апреле | Сколько дней сдавала задание в этом месяце |
| Серия дней | Streak из дневника (🔥 если есть) |
| Фидбеков | Сколько раз педагог ответил в этом месяце |
| На повторение / слов в банке | Слов которые пора повторить сегодня |

Спарклайн 14 дней: **зелёный** = сдала задание, **синий** = педагог ответил фидбеком.

Распределение слов: горизонтальная полоска 🟢 знает / 🟡 частично / 🔴 не знает.

## Спринт из архива — AI генерация на основе ошибок

Панель педагога → кнопка **🧠 Спринт из архива** (рядом с "✨ Сгенерировать день")

**Что происходит:**
1. AI читает последние 10 фидбеков студента из архива
2. Находит главный паттерн ошибок (грамматика, лексика, кальки с русского)
3. Подбирает: грамматическую тему + 6 слов (включая слова на повторение) + 3 уровня Sprechen
4. Заполняет ВСЕ поля формы: тема дня, грамматика, слова с чанками, задания 3 уровней, пост-сабмишн

**Жёлтая плашка под кнопками** — заметка AI: что за паттерн нашёл и почему выбрал именно эти слова.

**Важно:** кнопка требует хотя бы один отправленный фидбек в архиве.
Финальное слово всегда за педагогом — проверить и отредактировать перед сохранением.

## Firebase Security Rules — текущие (обновлено 16 апреля)

```json
{
  "rules": {
    "teacher":     { "$id": { ".read": true, ".write": "auth != null" } },
    "submissions": { "$id": { ".read": "auth != null", ".write": true } },
    "progress":    { "$id": { ".read": true, ".write": true } },
    "students":    { "$id": { ".read": true, ".write": "auth != null" } },
    "archive":     { "$id": { ".read": "auth != null", ".write": "auth != null" } },
    "feedback":    { "$id": { ".read": true, ".write": "auth != null" } }
  }
}
```

Обновлять только когда добавляется новый тип данных. Как обновить: Firebase Console → Rules → вставить → Publish.

## Масштабирование — иметь в виду

Аудио хранится в Cloudinary (приоритет) или base64 в Firebase (резерв при VPN).
Firebase бесплатный план = 1 ГБ ≈ 85 часов аудио.

**При 20+ активных студентах** → Firebase Dashboard → проверить Usage → если близко к 800 МБ → подключить Blaze план (~$0.026/ГБ).

## Если что-то сломалось

| Проблема | Решение |
|----------|---------|
| Панель педагога не сохраняет | F5, войти снова |
| Студент не видит задание | Попросить Ctrl+Shift+R |
| Фидбек не показывается | Ctrl+Shift+R в кабинете студента |
| Аудио "сохранено локально" | VPN — аудио всё равно отправится через base64 |
| Архив пуст | Переотправить фидбек через "✏️ Обновить" в Eingänge |
| AI черновик не работает | Проверить OpenRouter API ключ в teacher.html |
| Уведомления не приходят | Студент ещё не нажал Start в боте |
