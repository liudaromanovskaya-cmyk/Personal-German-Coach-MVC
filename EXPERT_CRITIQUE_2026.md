## ЧАСТЬ 1 — РЫНОК: ЧТО ДЕЛАЮТ КОНКУРЕНТЫ

### Где Personal German Coach находится на рынке

Система занимает нишу которую **ни одна платформа не закрывает полностью**: непрерывный цикл педагог–студент с AI-поддержкой, прозрачностью прогресса и низким трением.

| Платформа | Сильная сторона | Главная слабость |
|-----------|----------------|-----------------|
| Duolingo | Привычка через streak | Нет говорения; наградная система обходится зубрёжкой |
| Preply | Инфраструктура маркетплейса | Комиссия 33%; фидбек-петля сломана; AI-резюме обезличены |
| Khan Academy | "Next best action" логика экрана | Не для языков; нет живого человека |
| iTalki | Непрерывность 1-на-1 | Нет трекинга прогресса; педагог не мотивирован вести историю |
| Anki | Spaced repetition без трений | Геймификация отталкивает взрослых B2+ |
| Lingoda | Профессиональная структура | Разные педагоги = нет непрерывности; материал, не студент |
| Notion/Obsidian (DIY) | Гибкость | 2 часа/неделю на обслуживание; нет автоматизации |

**Главный вывод**: конкуренты выбирают между масштабом (Duolingo) или личным коучингом (iTalki). Никто не оптимизирует оба — личный + системный + низкое трение для педагога. Это ниша Personal German Coach.

---

### 10 UX-паттернов с рынка которые стоит взять

**1. "Next Best Action First" (Khan Academy)**
Студент открывает приложение → видит ОДНО задание (не 6 карточек). Ноль когнитивной нагрузки.
```
[ СЕГОДНЯШНЕЕ ЗАДАНИЕ ]
Тема: Dativ после предлогов (ваша слабая зона)
Время: 12 минут
[ Начать ]
```
Как применить: первый экран = только фидбек если есть + одна кнопка "Начать задание".

**2. Streak — взрослая версия (Duolingo insight, переосмыслен)**
Duolingo считает дни. Для B2 это детская игра. Лучше: "Dativ: 15 дней практики → точность с 60% до 85%".
Прогресс реальный, видимый, личный — не гамификация.

**3. Микро-фидбек с цитатами ошибок (Preply "Lesson Insights")**
Не "Молодец!". А: "Вы написали 'ich bin abhängig VON meinen Eltern' — точно! Аккузатив здесь был вашей слабостью месяц назад."
Педагог читал внимательно. Студент это чувствует. Это доверие.

**4. Spaced Repetition как список дел, не флеш-карточки**
```
Слова на повторение (3):
1. der Konjunktiv II — "Wenn ich mehr Zeit hätte..."
2. die Nominalisierung — "Das Lernen ist wichtig..."
[ Записать произношение ] или [ Написать предложение ]
```
Анки — для запоминания. Ваш формат — для применения.

**5. Заметки педагога скрыты от студента**
Педагог пишет "боится ошибок", "медленно с номинализацией" — для себя.
Студент видит только отполированный финальный комментарий.
Preply это провалил: студент видит сырой AI-черновик.

**6. Push с конкретикой, не с шаблоном**
Не: "Новое задание!" (Preply, iTalki).
А: "Лиуда добавила правило про Dativ — посмотрите, это про вашу ошибку на прошлой неделе."
Студент чувствует: это сделали именно для меня.

**7. Прогресс как радар навыков (не одна цифра)**
```
Слушание  ●●●○○
Говорение ●●○○○  ← растёт
Письмо    ●●●●○
Грамматика●●●●●
Лексика   ●●●●●
```
Многомерный прогресс реален для B2 (не фейковый "уровень").

**8. "Следующий урок" — психологическая непрерывность**
После отправки задания: "Сделано! Следующая тема: Passiv (почему это важно для резюме). Дата: пятница."
Студент знает что план есть. Создаёт предвкушение, не тревогу.

**9. AI как черновик, педагог как голос**
Кнопка: "✅ Использовать AI-предложение, я проверю ключевые места"
Не: "Напишите всё с нуля". Preply даёт сырой AI-ответ — слишком обезличено. Ваш подход: AI экономит время, педагог добавляет человеческое.

**10. Педагог видит своё время и его ценность**
```
Апрель: €180 заработано (4 студента × €45/мес)
Проверено заданий: 32
Часов вложено: 12
Доход/час: €15
```
iTalki и Preply это прячут. Ваша система говорит: "Ваш труд имеет ценность."

## ЧАСТЬ 2 — КРИТИКА КОДА: 6 ПЕРСПЕКТИВ

### 1. РАЗРАБОТЧИК / АРХИТЕКТОР

**Главная тайм-бомба: глобальный state + два источника истины**

- `app.js` использует 5+ глобальных переменных (`_student`, `_studentId`, `_firebaseTeacherData`, `_wordSchedule`, `_studentLevel`) без единого state-контейнера. При добавлении второго педагога или реал-тайм синхронизации — сломается.
- `students.js` + Firebase — два источника истины. При редеплое новые данные педагога могут перезаписаться дефолтами. Педагог потратил час на план — он пропал.
- localStorage/Firebase синхронизация хаотична: иногда localStorage приоритет, иногда Firebase. Студент переходит с iPhone на ноутбук — теряет прогресс.
- `fbSetPublic()` и `fbGet()` вызываются в 17+ местах без абстракции. Смена структуры Firebase = переписывать весь app.js.

**Что хорошо**: функции `renderGrammarScreen()`, `renderGapsScreen()`, `renderKulturScreen()` чётко разделены. Правильная архитектура для отрисовки. Если вынести state-management — система станет чистой.

---

### 2. МЕТОДОЛОГ (SLA — Second Language Acquisition)

**Теория лежит в docs, в код не дошла**

- **Nation** (выборочное обучение): слова выдаются одинаково всем. Нет анализа какие слова нужны именно этому студенту сейчас.
- **Swain** (Output Hypothesis): задание = записать голос, но нет механизма целевого внимания к ошибке. Студент говорит — педагог замечает — но система не помогает студенту заметить самому.
- **Schmidt Noticing**: студент не замечает форму сам — форма даётся готовой в таблице. Нет "найдите ошибку", нет "выведите правило из примеров".
- **Krashen Input Hypothesis**: в Kultur есть пословицы и слова, но ноль аутентичных текстов уровня i+1, ноль видео/аудио. Кабинет стерилен от живого языка.
- **Spaced Repetition** обещан, но SM-2 не реализован. Педагог выбирает слова на повторение в голове. Это не масштабируется.
- **Аффективный фильтр** (Krashen): мудсельектор есть, но при 😰 "устала" ничего не меняется. Тревожность блокирует усвоение — это знает каждый SLA-методолог. Система это игнорирует.

**Главная дыра**: methodology_library содержит 8 техник (shadowing, picture description, retelling, Error Noticing). В интерфейсе студента — ни одной. Студент платит за методологию, но не получает её.

---

### 3. ПЕДАГОГ

**Цикл 1.5–2.5 часа при 5 студентах — стена масштабирования**

- Заполнить задание: 20–30 минут (6 слов + чанки + 3 уровня + грамматика)
- Eingänge: прослушать 5 студентов + Whisper: ~10 минут
- AI черновик + редакция фидбека: 15–20 минут на студента
- При 10 студентах: 3–4 часа в день. Неподъёмно.

Что педагог держит в голове (опасно):
- Статус каждого студента, что уже изучено, паттерны ошибок, plan развития
- При 10 студентах без аналитики это невозможно

Что работает хорошо: структура Eingänge (плеер + Whisper + AI черновик + архив) — эффективная цепочка. Единственное: нет live-обновления, нужно нажимать "Обновить".

---

### 4. СТУДЕНТ

**Первое открытие: паралич выбора**

Студент видит одновременно: фидбек + review + 6 карт слов + 3 уровня Sprechen + 3 уровня Schreiben + дневник + mood. Нет явного "начни отсюда".

- **Мотивация спрятана**: streak (🔥) находится внизу в дневнике — не на главном экране. Аудио-архив ("Meine Reise") не реализован. Это самый мощный инструмент мотивации — студент слышит себя в феврале и апреле.
- **Мудсельектор → тишина**: выбрала 😰 — ничего не изменилось. Должен был появиться лёгкий вариант и ободрение.
- **Непонятно без педагога**: зачем Niveau 1→2→3, что означают теги на словах, как Kultur связан с заданием. Интерфейс не самообъясняющий.
- **Что студент хочет**: "Мои главные 3 ошибки за последние 2 недели." "Этот паттерн улучшился на X%." Аналитика для студента отсутствует.

---

### 5. ДИЗАЙНЕР

**Заявлен premium adult expert cabinet — реализован edtech toy**

- Цветовая система: `#4A8C6E` (green) + `#D97706` (amber) + `#2D3748` (dark) — стандартный Tailwind-набор, не премиум. Нет характера.
- Раздел Kultur выглядит как черновик: таблица с пословицами без изображений, без контекста, без дизайна.
- Эмодзи как иконки: 🎧 🗣️ 📖 ✍️ 🔧 — хаотично, нет системного набора. Это быстрое решение, не дизайн.
- Иерархия провалена: на главном экране все карточки одного размера и одной важности. Глаз не знает куда смотреть.

**Что работает**: терракотовая карточка фидбека "💬 Kommentar der Lehrerin" — правильное решение. Цвет, тень, аккордеон. Если весь интерфейс был бы на этом уровне — это был бы premium product.

**Мобильный (главная боль)**: грамматические таблицы не скроллятся горизонтально, кнопки маленькие, фидбек нечитаемо узкий. Это должно быть PWA — тестирования на реальном телефоне не было.

---

### 6. ВИЗИОНЕР (горизонт 5–10 лет, AI-native мир)

**Что сломается при AI-интеграции без подготовки**

- Нет unified student profile: данные разбросаны между students.js, Firebase и localStorage.
- Нет вектор-базы ошибок: AI не может найти "похожие ошибки у других студентов".
- Нет версионирования планов: педагог изменил — старое пропало.
- Глобальный state создаст deadlock при параллельном AI-ассистенте.

**Что AI возьмёт на себя первым**:
1. Извлечение ошибок из фидбека → автоматически в следующий спринт
2. Spaced repetition — SM-2 без педагога
3. Mood-response — персонализированный ответ на 😰
4. Черновик задания из архива — уже сделано, но сырое

**Что останется ценным всегда**:
Живой человек который знает Ольгу лично: её страхи, её работу, её жизнь в Германии. Это нельзя масштабировать алгоритмом. Педагог как куратор качества — 20 мин/день на студента вместо 2 часов.

**Уникальность через 10 лет**: большинство приложений будут полностью AI. Personal German Coach выживет если останется "человеческим в AI-мире" — система знает историю каждого студента, AI делает черновики, педагог добавляет живое слово.

## ТРИ САМЫХ СРОЧНЫХ ИСПРАВЛЕНИЯ

*(без которых система не готова к следующему набору студентов)*

### 1. Последовательный UX — убрать паралич выбора
**Как есть**: студент видит всё сразу.
**Как должно быть**: первый экран = только фидбек (если есть) + одна кнопка "Начать задание". После нажатия: Niveau 1 → выполнил → Niveau 2 открывается → и т.д.

### 2. Firebase как единственный источник истины
**Как есть**: students.js + Firebase + localStorage — три источника.
**Как должно быть**: students.js = только дефолты для новых студентов. Все живые данные — только из Firebase. localStorage = кэш, не источник.

### 3. Мудсельектор с реальным действием
**Как есть**: студент выбирает 😰 — ничего не меняется.
**Как должно быть**: 😰 → показать только Niveau 1 + ободряющее сообщение от педагога. 😊 → открыть бонусный уровень или сложный вариант.

## ПЯТЬ ВЕЩЕЙ КОТОРЫЕ РАБОТАЮТ ХОРОШО

1. **Eingänge → Whisper → AI черновик → архив** — полная цепочка фидбека. Правильное сердце системы.
2. **Терракотовая карточка фидбека** — аккордеон, позиция сверху, цвет. Правильное решение для важного контента.
3. **Архив фидбека для студента** — все прошлые фидбеки доступны по датам. Студент может вернуться к любому моменту.
4. **Три уровня Sprechen** — методология правильная: разогрев → ситуация → личная история. TBLT-структура хорошая.
5. **Новый "Спринт из архива"** — читает паттерны ошибок и генерирует задание. Это инновативно. Ни у кого нет.

## ЧТО ИННОВАТИВНО (нет у конкурентов)

- **Персонализированный фидбек-цикл через Telegram** — не email, не отдельное приложение, а там где студент уже есть
- **Whisper + AI черновик + архив** — педагог тратит 5 минут вместо 45 на один фидбек
- **Анализ архива** — AI читает историю ошибок → находит паттерн → рекомендует тему недели
- **Спринт из архива** — задание генерируется не из воздуха, а из реальных ошибок этого студента
- **Русско-немецкий контекст** — понимание интерференции (Nominativ/Dativ путаница для русских) — никто из конкурентов это не учитывает
