## Что мы строим

**Personal German Coach** — платформа-трекер для репетитора немецкого языка.

Не SaaS, не массовый продукт. Мой персональный инструмент для работы с конкретными студентами.

**Два интерфейса:**
1. **Кабинет студента** (`tg-app/index.html?student=olga`) — студент видит задание, выполняет, отправляет
2. **Панель педагога** (`tg-app/teacher.html`) — я заполняю задания, вижу домашние работы, отправляю фидбек

## Стек и архитектура

- **Один HTML-файл** на интерфейс. Никаких фреймворков, никаких библиотек.

## Что умеет система (всё реализовано)

### Кабинет студента
- 5 вкладок: Aufgabe / Grammatik / Fortschritt / Lücken / Kultur
- Aufgabe: задание дня — слова с чанками, 3 уровня Sprechen, 3 уровня Schreiben, Tagebuch
- Банк слов: оценка ⬛🔴🟡🟢 (интервальное повторение по Эббингаузу)
- Бейдж 🔄 когда слово возвращается на повторение
- Отправка работ → сохраняется в Firebase (submissions)
- Фидбек педагога: зелёная карточка "💬 Kommentar der Lehrerin"
- Прогресс не теряется при смене устройства (Firebase sync)
- PWA — можно установить на рабочий стол как приложение
- Telegram chat ID захватывается автоматически при первом входе

### Панель педагога
- Авторизация: email + пароль (Firebase Auth)
- Заполнение задания: 6 слов (слово + подсказка + грамматика + чанки), 3 Sprechen + 3 Schreiben
- Панель "Слова дня" — показывает слова рядом с промптами во время заполнения
- Gemini: генерация чанков + генерация полного дня + недельный план
- Eingänge (входящие): все домашние работы всех студентов
- Отправка фидбека → студент видит сразу + Telegram-уведомление
- Новый студент без кода — форма → профиль в Firebase → кабинет готов
- "На повторение сегодня" — слова по расписанию интервального повторения
  - Бейджи стадий: 🆕 Закрепить / 🔄 Повторение / ⚡ Активизировать / ✅ В речи
  - Подсказка что делать с каждым словом (Nation + Laufer & Hulstijn)
- Lernjournal — архив всех дней (тема, слова, работа студента, фидбек)

## Методология (основа продукта)

**Speaking Sprint** — система Лиуды:
- 3 уровня говорения: Aufwärmen (разогрев) → Situation (реальный контекст) → Ihre Geschichte (своя история)
- 3 уровня письма: параллельно Speaking уровням
- 6 слов дня (Niveau 1) + 6 углубляющих (Niveau 2) + коллокации B2 (Niveau 3)

**Методология встречи со словом** (Nation, Laufer & Hulstijn):
- Встреча засчитывается если студент обработал слово: Need + Search + Evaluation
- 4 стадии: Unknown → Recognized → Recalled → Productive (active)
- 8-12 встреч → пассивный словарь; 10-20+ → активный
- Счётчик timesUsed: сколько раз слово встретилось в работах студента

**Ключевые принципы:**
1. AI — только черновик. Студент никогда не видит сырой AI-ответ.
2. Студент видит минимум — одно задание на экране.
3. Подсказки — по запросу, не сразу.
4. Прогресс — словами, не цифрами.
5. Фидбек — аккордеон (студент разворачивает сам).

## Что делаем дальше (приоритеты)
