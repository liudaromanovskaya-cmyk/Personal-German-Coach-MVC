# Personal German Coach — Спецификация системы

**Дата:** 2026-03-28
**Статус:** Утверждено

---

## Executive Summary

Система управления обучением для репетитора немецкого языка. Студент получает задания через свою именную веб-страницу (доступную через Telegram Mini App или прямую ссылку), сдаёт работы, получает AI-фидбек. Преподаватель управляет всем из одного кабинета.

---

## Проблема

Репетитор ведёт 4–15 студентов одновременно. Сейчас:
- Задания отправляются вручную в Telegram
- Домашние работы теряются в переписке
- Нет автоматического анализа ошибок
- Нет сводного отчёта по прогрессу
- Подготовка к живой встрече занимает много времени

---

## Пользователи

### Преподаватель (Людмила)
- Ведёт 4–15 студентов
- Работает на компьютере и телефоне
- Нужна максимальная автоматизация рутины

### Студенты (Артём, Ольга, Юлия, Михаил + новые)
- Русскоязычные взрослые в Германии
- Telegram есть у всех
- Разный уровень технической грамотности

## Архитектура

```
Telegram Bot
    ├── Присылает студенту ссылку на его кабинет
    ├── Уведомляет преподавателя о сдаче работы
    └── (опционально) принимает аудио напрямую

Студент: personalgermancoachmvc.vercel.app/tg-app/?student=artem
    ├── Видит задания дня (3 уровня)
    ├── Сдаёт работу (текст / скриншот / аудио)
    └── Получает AI-фидбек (после проверки преподавателем)

Преподаватель: /tg-app/teacher.html
    ├── Управляет заданиями всех студентов
    ├── Видит входящие работы
    ├── Редактирует/утверждает AI-фидбек
    └── Видит расписание, оплату, срезы

Supabase (БД + Storage)
    ├── Студенты, задания, сдачи, фидбек
    ├── Файлы (скриншоты, аудио)
    └── История срезов

AI Pipeline
    ├── Claude API — анализ текста, грамматика, критерии
    ├── Whisper — транскрипция аудио
    └── OCR — распознавание скриншотов и рукописного текста
```

## Студенческий кабинет — функции

### Задания дня (3 уровня)
- **Basis** — обязательное, всегда одно
- **Vertiefung** — углубление
- **Eintauchen** — погружение

**UX:** Задания открываются по одному. Сделал первое → свернулось → открывается второе. Прогресс виден как "ступенька". Не перегружено.

### Типы заданий
| Тип | Как сдаётся | Как анализируется |
|-----|-------------|-------------------|
| Грамматическое упражнение (ссылка) | Скриншот результата | OCR → проверка правильности |
| Письменная работа | Текст напрямую или фото от руки | Claude API → грамматика + % использования заданного каркаса |
| Аудио / говорение | Голосовое сообщение | Whisper → транскрипция → Claude → грамматика + естественность |
| Чтение / слушание | Ответы на вопросы текстом | Claude → проверка понимания |

### После сдачи
1. Студент видит: "Работа отправлена. Фидбек появится после проверки."
2. Преподаватель получает уведомление в Telegram
3. AI генерирует черновик фидбека (DRAFT — только для преподавателя)
4. Преподаватель редактирует/утверждает → студент видит фидбек

## Кабинет преподавателя — функции

### Входящие работы
- Список сданных работ с красной точкой (новые)
- Просмотр: текст / скриншот / аудио (с транскрипцией)
- AI-черновик фидбека рядом — редактировать и утвердить
- Кнопка "Отправить фидбек студенту"

### Управление заданиями
- Создать задание на день (Basis / Vertiefung / Eintauchen)
- Добавить ссылку на внешний сайт
- Указать критерии проверки (каркас для письма/диалога)
- Шаблоны заданий — повторяющиеся упражнения

### Расписание
- Месячный абонемент = N часов
- Живые встречи: дата/время, тема
- Перенос занятия (часы не сгорают — переносятся)
- Подготовка к встрече: автосводка домашних работ за период

### Оплата (MVP)
- Галочка "Оплачено" + дата
- История оплат
- Предупреждение если подходит срок

### Пробелы (Lücken)
- Темы которые нужно повторить
- Добавляются автоматически из AI-анализа или вручную
- Учитываются при генерации следующих заданий

## Ежемесячный срез

**Триггер:** Преподаватель нажимает "Сгенерировать срез" (обычно перед продлением абонемента)

**AI собирает за месяц:**
- Все сданные работы и их оценки
- Все фидбеки преподавателя
- Пройденные грамматические темы
- Слова/выражения из заданий

**Генерирует:**
1. **Отчёт:** что пройдено, что хорошо, что повторить, чего не хватает
2. **Тест:** на темы месяца (студент проходит, результат идёт в отчёт)
3. **Сравнение:** с предыдущим срезом + прогресс к цели (CEFR уровень)

**Формат:** PDF или страница — отправляется студенту и сохраняется в истории.

## Стек

| Слой | Технология | Причина |
|------|-----------|---------|
| Frontend | HTML + CSS + vanilla JS | Уже есть, работает |
| Хостинг | Vercel | Уже подключён |
| База данных | Supabase (Postgres) | Бесплатно, готовый API |
| Файлы | Supabase Storage | Там же, просто |
| Telegram бот | python-telegram-bot или node-telegram-bot-api | Простой webhook |
| AI анализ | Claude API (claude-sonnet-4-6) | Лучший для немецкого текста |
| Аудио | OpenAI Whisper API | Лучшая транскрипция |
| OCR | Google Vision API или Tesseract | Распознавание скриншотов |
| Деплой бота | Railway или Render (бесплатно) | Простой хостинг для webhook |
