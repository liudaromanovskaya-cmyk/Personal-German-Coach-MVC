# Speaking Sprint — Спецификация системы для Ольги

**Дата:** 2026-03-31  
**Статус:** Утверждено (Discovery Interview)  
**Для кого:** Ольга, B1→B2, апрель 2026  
**Цель:** Автоматизм речи — думать на немецком, не переводить

---

## Executive Summary

Speaking Sprint — ежедневная практика говорения (и письма) для Ольги. Слова берутся с живых занятий, Claude генерирует задания 3 уровней с чанками и коллокациями. Ольга отвечает голосом (или текстом). Преподаватель слушает, готовит фидбек с "Немецким двойником" + образом-якорем. Из фидбека автоматически берутся слова для следующего Sprint'а. В воскресенье — аудио-история из всех слов недели.

---

## Цель — что значит успех

**Не:** правильная грамматика, выученные правила  
**Да:** язык ушёл в долгосрочную память — Ольга думает о смысле, а не о правиле

**Признаки успеха:**
- Отвечает без 5-секундной паузы на поиск слова
- Глагол встаёт на место интуитивно (не через правило)
- Слышит свою ошибку → спокойно исправляет сама, с интересом
- Меньше ощущения "этого недостижимого валуна"
- Говорит дольше — не замолкает после первых двух предложений

---

## Проблема Ольги (контекст)

У Ольги **много INPUT, мало OUTPUT:**
- 8 источников input (Mittelpunkt, подкасты, shadowing, Karlsson, тесты B1...)
- Она перегружена и теряется
- На занятиях хочет что-то сказать — не находит слово быстро → нервничает
- Считает: нужно 3–4 часа концентрированной работы, чтобы что-то сделать
- **Решение:** убрать домашние задания из учебника, дать маленький ежедневный Sprint

**Главная грамматическая проблема:**  
Позиция глагола плавает, Perfekt нестабилен — не правило, а калька с русского.  
→ Решается не объяснением, а многократным повторением чанков.

## Архитектура — полный цикл

```
ПОСЛЕ ЗАНЯТИЯ (преподаватель)
  ↓
/words olga слово1, слово2, ... → боту
  ↓
Claude генерирует:
  - Для каждого слова: 3+ коллокации/чанка + как немец скажет
  - Задания уровней 1, 2, 3 (говорение)
  - Задания уровней 1, 2, 3 (письмо — отдельные)
Преподаватель просматривает → сохраняет в Sprint недели
  ↓
ЕЖЕДНЕВНО (Ольга, 5–25 минут — по силам)
  ↓
Видит на экране: вопрос-триггер + чанки на выбор (мин. 3 варианта)
  → Записывает голосовое сообщение
  → ИЛИ если на работе — пишет текстом (отдельное задание)
  ↓
ПРЕПОДАВАТЕЛЬ (до следующей встречи, ~5 минут)
  ↓
Слушает аудио → готовит фидбек:
  ✨ Она сказала X → Немец скажет Y (Двойник)
  ✅ Похвала за конкретное слово/выражение
  🎯 Образ-якорь: метафора чтобы Y запомнилось навсегда
  ❓ Вопрос-активация: "А когда у тебя последний раз Akku закончился?"
     → Ольга отвечает СРАЗУ, используя новый чанк
  ↓
Преподаватель → отправляет Ольге список "Слова из фидбека"
  → эти слова идут в следующий Sprint автоматически
  ↓
ВОСКРЕСЕНЬЕ — Воскресная история
  ↓
Все слова недели (Sprint + фидбек) → аудио-история/мини-подкаст
Ольга слушает с юмором, эмоцией, удовольствием
→ Максимальное эмоциональное закрепление в долгосрочной памяти
  ↓
ВСЕ СЛОВА → Карточки в библиотеке лексики (для интервального повторения)
```

## Ежедневный Sprint — детальная структура

### Что Ольга видит в кабинете

**Шаг 1 — Настроение (5 секунд)**
```
Как вы себя сейчас чувствуете?
😰 Напряжённо    😐 Нормально    😊 Хорошо
```
→ При 😰 система показывает только Уровень 1

---

**Шаг 2 — Чанки дня (перед каждым уровнем)**

Перед тем как говорить, Ольга видит слова с вариантами чанков:

```
auf Anhieb — как немец скажет:
○ "Das hat auf Anhieb geklappt"
○ "Ich habe es auf Anhieb verstanden"  
○ "Nicht immer klappt alles auf Anhieb"
```
Минимум 3 варианта на каждое слово. Она выбирает глазами — это уже спaced repetition.

---

**Уровень 1 — Разогрев (5 минут)**
- Вопрос простой, из жизни
- Ответ любой засчитывается — нет "неправильно"
- Пример: *"Was haben Sie heute Morgen gemacht?"*

**60 секунд тишины**  
*"Подумайте что скажете. Не пишите — просто думайте."*  
(Ellis, 2005: pre-task planning → речь беглее и точнее)

**Уровень 2 — Ситуация с чанками (8–10 минут)**
- Коммуникативная задача с целевыми словами
- Вопрос-ситуация: не "составь предложение", а "реши задачу"

**Уровень 3 — Своя история (5–7 минут)**
- Реальное воспоминание из жизни Ольги
- Все слова видны, использует сколько хочет
- Преподаватель НЕ исправляет во время — только слушает

---

### Гибкость (главное — убрать валун)

- Ольга делает по силам: хоть один уровень — уже победа
- Если не сделала вчера → *"Есть незаконченные задания. Продолжим?"*
- Может зайти несколько раз в день — утром один уровень, вечером другой
- Хочет повторить Уровень 1? Придёт другой чанк, другой вопрос
- Нет галочки "провалила" — есть только движение вперёд

---

## Задания письма — параллельный трек

**Отдельные задания** (не тот же вопрос текстом, а другая задача):
- Те же слова — другой формат
- Уровень 1 (письмо): 5 предложений
- Уровень 2 (письмо): текст подруге — 7–8 предложений
- Уровень 3 (письмо): своя история — 8–10 предложений

**Когда:** когда на работе и нельзя говорить  
**Зачем:** Speaking + Writing усиливают друг друга → слово закрепляется в обоих навыках

---

## Фидбек — структура и пример

**Готовит:** преподаватель вручную, до следующей встречи  
**Где:** Ольга видит в кабинете (Mini App) + уведомление

**Структура одного блока фидбека:**
```
✨ Вы сказали:
   "Ich war sehr müde nach der Arbeit"

🇩🇪 Немец скажет:
   "Ich war total am Ende"
   — живо, точно, именно так говорят коллеги

✅ Вы молодец:
   "eingespannt" — использовали точно в нужный момент

🎯 Образ-якорь:
   "am Ende sein" — лампочка мигает и гаснет.
   Заряд кончился. Вот так немец чувствует усталость —
   она заканчивается, как батарейка.

❓ Теперь вы:
   А когда у вас последний раз Akku закончился?
   Ответьте голосом — используйте "total am Ende".
```

**После фидбека:**
- Ольга сразу отвечает на вопрос-активацию (голосом или текстом)
- Это закрепляет чанк в активной памяти
- Преподаватель фиксирует "выражения из фидбека" → идут в следующий Sprint

---

## Воскресная история — еженедельная традиция

**Когда:** воскресенье (или конец учебной недели)  
**Что:** аудио-история или мини-подкаст из ВСЕХ слов и чанков недели

**Формат:**
- Берутся все слова Sprint'а + все выражения из фидбеков недели
- Claude генерирует смешную/живую историю с этими словами
- Ольга слушает — с юмором, эмоцией, узнаванием
- Опционально: она записывает свою версию этой истории

**Зачем:** Эмоциональная память — самая долгосрочная. Если она смеётся над историей где использовано "total am Ende" — это слово останется навсегда.

---

## Поток слов — ничего не теряется

```
Урок → /words → Sprint (коллокации + задания)
                    ↓
              Ольга говорит/пишет
                    ↓
         Фидбек: Двойник + якорь + вопрос-активация
                    ↓
      "Слова из фидбека" → следующий Sprint
                    ↓
         Все слова недели → Воскресная история
                    ↓
      Все слова → Библиотека лексики → Карточки
```

---

## Уведомления

**Формат уведомления о фидбеке:**
- На немецком, с немецкой шуточкой/теплотой
- Атмосфера: "мы двигаемся, это реальный прогресс, это интересно"
- Не "ваш фидбек готов" — а что-то живое и наполняющее
- Пример: *"Olga, Ihr Feedback ist da! 🎯 Heute lernen wir, wie ein echter Berliner Müdigkeit beschreibt..."*

## Что НЕ делает преподаватель

| Задача | Раньше | Теперь |
|--------|--------|--------|
| Домашнее задание из Mittelpunkt | 15–20 мин | 0 — учебник только на живых встречах |
| Придумать задания | 15 мин | 0 — Claude генерирует |
| Написать коллокации | 10 мин | 0 — Claude находит |
| Фидбек с нуля | 10–15 мин | ~5 мин — структура готова, добавить образ |
| Помнить что было | Память/заметки | 0 — всё в кабинете |

---

## Правило для преподавателя — НЕ ПЕРЕБИВАТЬ

Во время говорения: слушать до конца.  
Исправления — только в фидбеке, письменно, в форме Двойника.  
Причина: перебивание поднимает аффективный фильтр (Krashen) → студент теряет мысль → нервничает → замолкает.
