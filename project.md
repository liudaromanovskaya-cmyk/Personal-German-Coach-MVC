## Что это · Was ist das

**Personal German Coach** — платформа персонального репетитора немецкого языка для русскоязычных взрослых в Германии и Швейцарии.

Студент получает одно короткое задание в день (15–20 мин) по своей профессии и уровню, загружает ответ, а преподаватель присылает живой фидбек — проверенный, не сгенерированный AI напрямую.

**Главный принцип:** AI готовит черновик → преподаватель проверяет и редактирует → студент видит только финальный верифицированный ответ.

## Для кого · Für wen

### Студент (основная аудитория)
Русскоязычный взрослый, 25–45 лет, переехавший в DE или CH. Работает. Нужен немецкий для карьеры, интеграции или экзамена.

| Имя | Кто | Уровень | Цель |
|---|---|---|---|
| Анна | IT, Мюнхен | B1→B2 | Говорить на митингах без ступора |
| Дмитрий | Врач, Берлин | A2→B2 | Сдать Fachsprachprüfung |
| Елена | Менеджер, Цюрих | B2→C1 | Уверенные переговоры |
| Сергей | Инженер, Гамбург | A1→A2 | Бытовой немецкий для жизни |

**Что объединяет:** мало времени, профессиональный контекст важнее учебников, страх ошибок.

### Преподаватель (я)
Использует платформу чтобы вести студентов: видит задания, правит AI-черновики, управляет треком каждого студента, готовится к месячным сессиям.

## Дизайн · Designstil

Стиль: **тёплый минимализм** — профессионально, спокойно, без лишнего.

### Цвета · Farben
| Роль | Hex | Где |
|---|---|---|
| Фон страницы | `#FAF9F6` | Тёплый кремовый — основной фон |
| Навигация / сайдбар | `#2D3748` | Тёмный сланец — нейтральный, не давит |
| Основной акцент | `#4A8C6E` | Шалфей — кнопки, активные элементы |
| Светлый акцент | `#EDF7F1` | Бледно-зелёный — фон карточек-успехов |

| Граница | `#E2E8F0` | Светлая рамка карточек |

### Шрифт · Schrift
`'Segoe UI', system-ui, sans-serif` — системный, читабельный, без загрузки

### Принципы · Prinzipien
- **Студент видит минимум:** одно задание, один следующий шаг
- **Без процентов и KPI** на главном экране студента — только слова
- **Подсказки по запросу** — не навязываются, нажимает сам
- **Win-баннер** появляется когда преподаватель отметил улучшение
- **Мало эмодзи** — только где реально помогает, не для украшения
- **Фидбек — аккордеон** — не висит сразу, студент разворачивает сам
