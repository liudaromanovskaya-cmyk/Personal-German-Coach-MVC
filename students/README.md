# Студенты — Personal German Coach

## Как пользоваться этой папкой

### Когда открываешь Claude — скажи:
> "Прочитай профиль Артёма и составь задание на эту неделю.
> Тема: [тема]. Мы на неделе [номер]."

Claude прочитает файл и сделает задание правильно — без лишних объяснений.

---

## Структура каждого студента

```
students/
└── имя/
    ├── profil.md       ← кто он, уровень, проблемы, стратегия
    ├── diagnostik.md   ← диагностическое задание + анализ
    ├── track.md        ← личный трек на 3 месяца (создаётся после диагностики)
    └── aufgaben/
        ├── woche_01.md ← задания недели 1
        ├── woche_02.md
        └── ...
```
