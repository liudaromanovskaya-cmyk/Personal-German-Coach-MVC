# Методологическая библиотека — Навык: Чтение (Leseverstehen)

**Файл:** methodology_library/skill_reading.md
**Evidence-based:** SLA research, CEFR descriptors, PISA reading framework

---

## Цель развития навыка

Научить студента **извлекать информацию** из аутентичных немецких текстов разных жанров (административные, профессиональные, публицистические, бытовые) на уровне, необходимом для жизни и работы в Германии.

---

## Прогрессия по уровням CEFR

| Уровень | Что должен уметь |
|---|---|
| A1 | Понимать короткие простые тексты: объявления, ценники, расписание |
| A2 | Понимать простые письма, объявления, короткие статьи с поддержкой словаря |
| B1 | Понимать тексты о знакомых темах, находить нужную информацию |
| B2 | Читать аутентичные тексты (газеты, инструкции), понимать имплицитный смысл |
| C1 | Критически анализировать сложные тексты, понимать иронию и нюансы |

## 8–10 Микро-упражнений

### 1. Skimming — Быстрый просмотр (5 мин)
**Цель:** Понять общую тему без детального чтения
**Инструкция:** Прочитайте заголовок, первый и последний абзац. Запишите: о чём текст? 2 предложения.
**Уровень:** A2–C1

### 2. Scanning — Поиск конкретного факта (5 мин)
**Цель:** Найти конкретное число, имя, дату без чтения всего текста
**Инструкция:** "Найдите: 1) когда открывается учреждение 2) сколько стоит услуга 3) кто подписал документ"
**Уровень:** A2–B2

### 3. Vokabular-Bridge — Незнакомые слова из контекста (7 мин)
**Цель:** Угадывать значение незнакомых слов по контексту (без словаря)
**Инструкция:** Подчеркните 3–5 незнакомых слов. Запишите свою версию перевода до проверки. Затем проверьте словарём. Процент угадывания?
**Research:** Nation (2001) — 95% слов должны быть известны для понимания. Угадывание из контекста — ключевой навык.

### 4. Text-Typ-Analyse — Жанр и структура (5 мин)
**Цель:** Идентифицировать тип текста → активировать нужные читательские стратегии
**Инструкция:** Это? (Behördenbrief / Zeitungsartikel / Anleitung / E-Mail). Откуда знаете? Что ожидать от структуры?
**Уровень:** B1–C1

### 5. True/False/Not mentioned (5–7 мин)
**Цель:** Детальное понимание + различение "не сказано" vs "сказано"
**Инструкция:** 5–7 утверждений к тексту. Студент отмечает: Richtig / Falsch / Nicht im Text. Сложность — третья категория.
**Research:** Ключевой тип задания на Goethe, TestDaF, telc.

### 6. Summary — Краткий пересказ (7–10 мин)
**Цель:** Активная обработка текста, связь с письмом
**Инструкция:** Перескажите текст своими словами: 4–6 предложений. Не копировать фразы дословно.
**Уровень:** B1–C1

### 7. Lückensatz — Восстановить пропущенное предложение (5 мин)
**Цель:** Понимание связности текста (Kohärenz)
**Инструкция:** В тексте убраны 3–4 предложения. Из набора вариантов выбрать, куда они вставляются.
**Research:** Данный тип задания тренирует discourse competence (Celce-Murcia, 2007).

### 8. Reading + Speaking — Устный ответ на текст (7–10 мин)
**Цель:** Интеграция навыков; чтение → говорение
**Инструкция:** Прочитайте текст → запишите 60-секундное аудио: "Что вы думаете об этом? Согласны или нет?"
**Уровень:** B1–C1

### 9. Professional Text Анализ — Рабочий документ (10 мин)
**Цель:** Понимание документов по профессиональной теме
**Инструкция:** Статья / инструкция / договор по профессии студента (IT/Medizin/Management). 3 вопроса на понимание + 2 слова для Anki.
**Примеры текстов:** Datenschutzerklärung, Arbeitsvertrag, Beipackzettel

### 10. Kritisches Lesen — Критическое чтение (10 мин, B2–C1)
**Цель:** Понять цель автора, аргументы, ограничения
**Инструкция:** Прочитайте статью. Ответьте: Каков тезис автора? Какие аргументы? С чем вы согласны/не согласны? Что не учтено?
**Research:** Anderson & Pearson (1984) — критическое чтение как высший уровень comprehension.

## Checklist для преподавателя (одно занятие по чтению)

- [ ] Выбран текст соответствующего уровня (≤5% незнакомых слов для беглого чтения)
- [ ] Определена цель: глобальное / детальное / критическое понимание
- [ ] Добавлен pre-reading task (активация фоновых знаний)
- [ ] Есть задания на разные уровни понимания (факты → связи → оценка)
- [ ] Студент работает со стратегиями, а не угадывает
- [ ] Незнакомые слова добавлены в Anki по итогам
- [ ] Связь с говорением или письмом (integrated skills)

## Психологические техники для чтения

### Для студентов с тревожностью перед длинными текстами
- **Chunking**: разбить текст визуально на блоки по 3–4 предложения
- **Goal-setting**: до чтения дать конкретную задачу ("найди только одно число") — это снижает тревогу

### Для аналитических студентов
- Дайте структурированный гайд: сначала заголовок → подзаголовки → первые предложения абзацев → детали

### Для аудиальных студентов
- Разрешите (или порекомендуйте) читать вслух — это помогает закрепить понимание через слуховой канал

## Evidence-Based Research

1. **Krashen (1982)** — "Comprehensible Input": чтение на чуть более высоком уровне (i+1) — ключ к прогрессу
2. **Nation (2001)** — 95% известных слов необходимы для беглого понимания. 98% — для удовольствия.
3. **Grabe (2009)** — *Reading in a Second Language*: стратегическое чтение (не слово за словом) — критически важно
4. **CEFR (2020 Companion Volume)** — descriptors for Mediation and Plurilingual reading skills
5. **Anderson & Pearson (1984)** — Schema Theory: фоновые знания критически влияют на понимание текста
