# Критика системы «Ошибка → Автоматизация»
*5 экспертных перспектив. Апрель 2026.*

---

## НЕЙРОУЧЁНЫЙ / КОГНИТИВНЫЙ ПСИХОЛОГ

### Сильное
- Декларативное → процедурное знание (теория ACT-R Андерсона) — правильная основа
- Таймер как индикатор автоматизации — психологически обоснован
- Stress Transfer как отдельная стадия — редкая и правильная идея

### Критические пробелы
- **Нет interleaving** — только блочная практика (одна тема за раз). Исследования Rohrer/Taylor: перемешанная практика даёт лучшее долгосрочное запоминание. Студент учится «это задание на Verbzweit», а не «здесь нужен Verbzweit»
- **Спейсд репетишн не адаптивный** — фиксированные 2/7/14 дней не работают одинаково для всех. Нужен SM-2: ошибся → интервал сбрасывается, быстро ответил → интервал растёт
- **Сон игнорируется** — процедурные навыки консолидируются во сне (Walker/Stickgold). Drill перед сном эффективнее утреннего на ~40%

### Добавить
1. Раз в неделю «смешанный drill» из 3-5 уже изученных тем вместе
2. Адаптивные интервалы: <3 сек → +7 дней, 3-8 сек → +3 дня, ошибся → +1 день
3. Подсказка «лучшее время для закрепления — перед сном»

## ИССЛЕДОВАТЕЛЬ SLA (усвоение второго языка)

### Сильное
- Noticing hypothesis (Шмидт) — «Почему я ошибся?» форсирует noticing
- Output hypothesis (Свейн) — стадия 5 с диалогом/голосовым правильная
- Различение explicit knowledge vs implicit knowledge (Ellis 2009)

### Критические пробелы
- **Нет работы с фоссилизацией** — если ошибка повторяется 3+ недели, drill не поможет. Нужен другой подход: контрастный анализ русский/немецкий, намеренное замедление именно в этом месте
- **Перекос в accuracy** — нет дискурсивной компетенции (как связать текст), социолингвистической (уместность), стратегической (как компенсировать пробел)
- **Нет input-компонента** — студент, который только дриллит без живого немецкого, говорит правильно но неживо

### Добавить
1. Метка «Hartnäckiger Fehler» если ошибка повторилась 3+ раза — особый режим работы
2. Упражнения на связность для B1+: denn/weil/deshalb/obwohl как дискурсивные коннекторы
3. Micro-input: 2-3 мин живого немецкого по теме урока (аудио/цитата)

## ОПЫТНЫЙ ПЕДАГОГ (немецкий для русских)

### Сильное
- «Русская ловушка» как отдельный блок — нет ни в одном немецком учебнике
- 5 секунд — реалистичный педагогический критерий, видно физически на уроке
- Типология ошибок делает интуицию опытного учителя явной

### Критические пробелы
- **Аффективный фильтр игнорируется** — для тревожного студента timed drill = паника, а не тренировка. После ошибки → «назад на стадию 3» → тревожный студент закроет приложение
- **Индивидуальные различия не предусмотрены** — врач Ольга и студент для переезда — разные психологические профили реакции на ошибку и таймер
- **Учитель как актор не описан** — что он делает с метриками? Интерпретация требует контекста который алгоритм не видит

### Добавить
1. Таймер «невидимый» — считает, студент не видит, учитель видит
2. Учительский комментарий к типу ошибки: «Мы разбирали это — вот ваша запись»
3. Еженедельный дайджест педагогу: «Verbzweit улучшился, warten auf — повторилось 3 раза, рекомендую разобрать»

## UX / РАЗРАБОТЧИК

### Сильное
- Список из 7 конкретных функций — это спецификация, не пожелание
- Метрики реализуемы в Firebase без сложной архитектуры
- Мини-дриллы 2-3 мин — правильный UX-формат для взрослых

### Критические пробелы
- **Таймер + текстовый ввод на мобильном = катастрофа** — клавиатура открывается 0.5-1 сек, автокоррекция мешает. 80% пользователей не успеют напечатать правильный ответ за 5 сек
- **State machine 5 стадий = сложный код** — для одного HTML-файла трудно поддерживать без фреймворка
- **Учительский UI для метрик не описан** — система собирает данные, но педагог не знает как их читать

### Добавить
1. Только tap-based drill на мобильном: 3 кнопки выбора, не текстовый ввод
2. MVP = только стадии 2, 3, 5 (применение + drill + реальная речь)
3. Traffic light в панели педагога: 🟢🟡🔴 по 5-7 темам — читается за 10 сек

## СТУДЕНТ (русскоязычный взрослый, B1, занятой, тревожный)

### Сильное
- «Почему я ошибся?» — уважение к интеллекту взрослого, это удерживает
- 2-3 минуты — честный формат для занятого человека
- «Знаете, просто не автоматизировали» — снимает стыд, не обвиняет

### Критические пробелы
- **Таймер = тревога для многих взрослых** — после провала не хочется попробовать ещё раз, хочется закрыть приложение
- **Нет ощущения победы** — система показывает ошибки и возвраты. Где «я сделал это»?
- **Непонятно когда «достаточно»** — тревожный перфекционист не знает когда можно остановить Akkusativ и просто говорить

### Добавить
1. «Режим уверенности» — без таймера и без возврата назад, просто практика
2. Micro-win после сессии: «Сегодня Verbzweit быстрее чем неделю назад»
3. Критерий закрытия темы: «5 быстрых правильных ответов в разные дни = тема автоматизирована»

## СИНТЕЗ — ВЕРДИКТ И ПРИОРИТЕТЫ

### Главные слабости системы
1. Оптимизирована под идеального студента — мотивированного, нетревожного, регулярного
2. Полная реализация в коде сложнее, чем кажется (state machine + мобильный таймер)
3. Роль учителя недооформлена — данные есть, что с ними делать — нет

### Порядок реализации

| Этап | Что | Сложность | Ценность |
|------|-----|-----------|---------|
| 1 | Кнопка «Почему ошибся?» с 3 вариантами + метка в Firebase | Низкая | Высокая |
| 2 | Tap-drill (3 кнопки) с таймером только для педагога | Средняя | Высокая |
| 3 | Критерий «тема закрыта» + сообщение студенту | Низкая | Высокая |
| 4 | Traffic light в панели педагога по темам | Средняя | Высокая |
| 5 | Смешанный drill раз в неделю (interleaving) | Средняя | Очень высокая |

**Не строить в MVP:** полную автоматическую state machine 5 стадий. Это делает учитель на уроке.

### Один инсайт который изменит систему больше всего

**Interleaved practice бьёт blocked practice в долгосрочном запоминании — всегда.**

Сейчас система строит drill по одной теме. В реальной речи нет подсказок — всё перемешано. Если каждый третий drill будет смешанным (3 разные темы без объявления) — перенос навыка из платформы в жизнь станет значительно устойчивее.
