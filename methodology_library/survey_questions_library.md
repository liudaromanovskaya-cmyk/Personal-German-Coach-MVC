# Библиотека вопросов для профиля студента
*28 вопросов по 7 категориям. Педагог выбирает какие отправить каждому студенту.*

---

## Категория 1: Мотивация и цели

### Q1: Зачем вам немецкий?
**Тип:** выбор одного
**Варианты:**
- Работа в Германии/Австрии/Швейцарии
- Переезд / интеграция
- Экзамен (Goethe, TestDaF, telc)
- Учёба в вузе
- Семья / партнёр
- Хочу понять культуру
- Поддержать уровень

---

### Q2: Что конкретно хотите уметь через 3 месяца?
**Тип:** свободный текст
**Подсказка:** "Опишите одну конкретную ситуацию: что вы делаете на немецком?"

---

### Q3: Есть ли дедлайн?
**Тип:** выбор одного + дата
**Варианты:**
- Экзамен → когда?
- Собеседование на работу → когда?
- Переезд → когда?
- Нет конкретного дедлайна

---

### Q4: Какая ситуация на немецком для вас самая важная?
**Тип:** выбор нескольких
**Варианты:**
- Разговор с коллегами
- Совещания / презентации
- Общение с врачами / чиновниками
- Smalltalk с соседями / знакомыми
- Письма / emails
- Понимать на слух (радио, подкасты)
- Читать (новости, документы)

## Как использовать

**В teacher.html:**
1. Открыть вкладку нового студента
2. Нажать "Настроить опросник"
3. Отметить галочками нужные вопросы (можно по категориям или по одному)
4. Нажать "Отправить" — студенту приходит ссылка
5. После заполнения — ответы видны в профиле студента

**Рекомендуемый минимум (10 вопросов):**
- Q1 (зачем), Q3 (дедлайн), Q8 (уровень)
- Q9 (время), Q12 (можно говорить)
- Q13 (барьеры), Q15 (комфорт с ошибками)
- Q17 (как исправлять), Q19 (точность vs беглость)
- Q26 (приоритетный навык)
