## Как это работает технически

**В teacher.html:**
1. Педагог создаёт нового студента
2. Видит список всех 28 вопросов с галочками
3. Отмечает нужные (по умолчанию — минимальный набор из 10)
4. Нажимает "Отправить опросник"
5. Студент при первом входе видит только выбранные вопросы

**У студента в app.js:**
1. При первом входе — проверка: есть ли survey в Firebase?
2. Если нет — показать опросник (те вопросы что выбрал педагог)
3. Студент отвечает, может пропустить необязательные
4. После завершения — ответы сохраняются в Firebase
5. Педагог видит заполненный профиль

**Минимальный набор (10 вопросов):**
Q1, Q3, Q8, Q9, Q12, Q13, Q15, Q17, Q19, Q26
