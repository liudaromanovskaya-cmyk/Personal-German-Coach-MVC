# Методологическая библиотека — Навык: Аудирование (Hörverstehen)

**Файл:** methodology_library/skill_listening.md
**Evidence-based:** Listening Strategy Research, CEFR Listening Descriptors, Anderson (1985) Two-Phase Model

---

## Цель развития навыка

Научить студента **понимать реальную немецкую речь** в разных ситуациях: диалоги, новости, подкасты, профессиональные встречи, объявления. Особый акцент — на беглую естественную речь (не "Langsam gesprochene Nachrichten").

---

## Прогрессия по CEFR

| Уровень | Что должен уметь |
|---|---|
| A1 | Понимать медленную, чёткую речь о знакомых темах |
| A2 | Понимать простые указания, описания, знакомые темы |
| B1 | Понимать суть и детали разговоров / новостей на знакомые темы |
| B2 | Понимать сложные разговоры, лекции, интервью — даже на абстрактные темы |
| C1 | Понимать всё, включая идиомы, иронию, диалекты |

---

## Почему аудирование сложно для русскоязычных

| Проблема | Причина |
|---|---|
| Непонимание слитной речи | Elision: "hast du" → "hassu", "ich habe" → "ich hab'" |
| Диалекты | Баварское, берлинское, швейцарское — сильно отличаются от Hochdeutsch |
| Темп носителей | Значительно быстрее "учебного" немецкого |
| Новая лексика | Даже знакомое слово в беглой речи не распознаётся |
| Cognitive load | Одновременно декодировать звуки + понимать смысл |

## 8–10 Микро-упражнений

### 1. Bottom-Up Decoding — Фонетическое декодирование (5 мин)
**Цель:** Тренировать распознавание отдельных звуков и слов в беглой речи
**Инструкция:** Слушайте 30 секунд аудио без паузы. Запишите ТОЛЬКО слова, которые чётко расслышали (даже если не понимаете смысл). Повторите 3 раза — список растёт.
**Уровень:** A1–B1

### 2. Top-Down Prediction — Активация фоновых знаний (3 мин)
**Цель:** Использовать контекст для понимания
**Инструкция:** ПЕРЕД прослушиванием: прочитайте заголовок / посмотрите иллюстрацию. Запишите: о чём, по-вашему, будет аудио? Какие слова ожидаете услышать?
**Research:** Underwood (1989) — pre-listening tasks значительно повышают comprehension

### 3. Selective Listening — Слушать с целью (5 мин)
**Цель:** Не пытаться понять всё — фокус на конкретной задаче
**Примеры задач:**
- "Найдите только: имя, место, время"
- "Сколько человек говорит? Мужчина или женщина?"
- "Какие числа упомянуты?"
- "Как называется проблема, о которой говорят?"
**Research:** Rost (2002) — task-based listening снижает anxiety

### 4. Dictogloss — Диктоглосс (10 мин)
**Цель:** Аудирование + реконструкция → грамматика в контексте
**Инструкция:**
1. Преподаватель/аудио читает короткий текст (2–3 предложения) в нормальном темпе
2. Студент слушает и делает заметки (НЕ дословно)
3. Пытается восстановить текст своими словами
4. Сравнивает с оригиналом
**Research:** Wajnryb (1990) — Dictogloss формирует внимание к грамматической форме

### 5. Tiered Listening — Прослушивание по уровням (7 мин)
**Цель:** Постепенное повышение понимания от общего к детальному
**Шаги:**
1. 1-е прослушивание: о чём? (globa comprehension)
2. 2-е прослушивание: ключевые детали (кто? что? когда?)
3. 3-е прослушивание: детали + паузы (какое слово не расслышали?)
4. Текст: проверить пропущенное

### 6. Extensive Listening — "Лёгкое" аудирование для удовольствия (5–10 мин)
**Цель:** Привыкание к немецкой речи без стресса; увеличение input
**Инструкция:** Слушайте что-то приятное по теме: короткий подкаст, аудиокнига, YouTube-видео. Не нужно понимать всё. Главное — слушать.
**Ресурсы:** DW Podcast / Slow German / Coffee Break German / Easy German
**Research:** Nation & Newton (2009) — extensive listening даёт progress без explicit study

### 7. Gap-Fill Listening — Заполнение пропусков (5–7 мин)
**Цель:** Внимание к конкретным словам; часто повторяется в экзаменах
**Инструкция:** Текст с пропусками → слушаете аудио → вставляете услышанные слова. Сначала: пропуски = только ключевые слова. Потом — артикли, предлоги.
**Связь:** Задание гатовит к экзаменам Goethe (Hörverstehen Teil 1)

### 8. Note-Taking — Конспект с аудио (7–10 мин, B1+)
**Цель:** Профессиональный навык: записывать ключевые пункты во время прослушивания (meeting, lecture, phone call)
**Инструкция:** Слушаете подкаст / лекцию 3–5 мин. Делаете конспект: ключевые идеи, факты, цифры. Потом — пересказываете письменно или устно.
**Профконтекст:** IT-Meeting / медицинский брифинг / вебинар

### 9. Accent Exposure — Знакомство с диалектами (5 мин)
**Цель:** Не пугаться регионального немецкого
**Инструкция:** Слушайте 1–2 мин диалекта (Bairisch / Berlinerisch / Schweizerdeutsch). Отметьте: что поняли, что не поняли. Ключевые разница от Hochdeutsch.
**Ресурсы:** YouTube: "Bayerisch lernen" / "Berliner Dialekt"
**Важно:** Не нужно учить диалект — достаточно слышать и узнавать!

### 10. Listening Journal — Дневник аудирования (5 мин)
**Цель:** Рефлексия и прогресс-трекинг
**Инструкция:** После каждого listening-задания запишите 3 пункта:
1. Что было сложно?
2. Какое слово/фразу хотите запомнить?
3. Как вы справились по сравнению с прошлым разом?

## Checklist для преподавателя

- [ ] Аудио соответствует уровню + 1 (i+1 по Krashen)
- [ ] Есть pre-listening task (активация знаний)
- [ ] Задача чёткая ДО прослушивания (студент знает, что искать)
- [ ] Первое прослушивание — глобальное понимание
- [ ] Второе прослушивание — детали
- [ ] Третье (при необходимости) — проверка с текстом
- [ ] Post-listening: speaking ИЛИ writing задание
- [ ] Новые слова добавлены в Anki

## Психологические техники для аудирования

### Для студентов с "listening anxiety"
- **Задача снижает тревогу:** дайте конкретную цель ("найти только 1 число") — студент не пытается понять всё
- **Разрешите переслушивать:** в реальной жизни можно сказать "Können Sie das wiederholen?"
- **Валидация:** "Профессиональные переводчики тоже пропускают слова — это нормально"

### Техника "Good Enough Understanding"
- Объясните студенту: цель не 100% понимание, а достаточное для коммуникации (good enough)
- 70% понимания → уже можно вести разговор, решать задачи

### Для аналитических студентов
- Дайте схему ДО прослушивания: "Слушайте → заполните эту таблицу"
- Текстовая поддержка: разрешите читать транскрипт после прослушивания

## Evidence-Based Research

1. **Anderson (1985)** — Two-Phase Model: bottom-up (звуки → слова) + top-down (схема → смысл) — оба процесса одновременно
2. **Rost (2002)** — Listening in Language Learning: цель задания снижает тревогу и повышает comprehension
3. **Underwood (1989)** — pre-listening tasks критически важны для понимания
4. **Nation & Newton (2009)** — extensive listening: вовлечённость важнее сложности
5. **Wajnryb (1990)** — Dictogloss: интегрирует listening + grammar без эксплицитного преподавания
6. **Krashen (1982)** — Comprehensible Input: аудио на уровне i+1 — оптимально для приобретения языка
