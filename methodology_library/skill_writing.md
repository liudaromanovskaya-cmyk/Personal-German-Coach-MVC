# Методологическая библиотека — Навык: Письмо (Schreiben)

**Файл:** methodology_library/skill_writing.md
**Evidence-based:** CEFR Writing Descriptors, Process Writing Approach, Genre-Based Pedagogy

---

## Цель развития навыка

Научить студента **создавать функциональные тексты** для реальных ситуаций: деловая переписка, официальные документы, краткие описания, аргументированные ответы. Акцент — на письмо, которое работает в Германии (Behördenbriefe, Bewerbungen, E-Mails).

---

## Прогрессия по CEFR

| Уровень | Что должен уметь |
|---|---|
| A1 | Заполнить анкету, написать постcard, простое SMS |
| A2 | Написать простое личное письмо / email о знакомых вещах |
| B1 | Написать связный текст о знакомых темах, выразить точку зрения |
| B2 | Написать чёткие аргументированные тексты, отчёты, мнение |
| C1 | Писать сложные, хорошо структурированные тексты в профессиональном стиле |

## Специфика русскоязычных студентов (типичные проблемы)

| Проблема | Пример | Причина |
|---|---|---|
| Калька с русского | "Ich bin wünschen..." | Дословный перевод |
| Порядок слов | "Ich habe gestern gegessen Mittag" | Нет привычки verb-second |
| Падежи в письменном тексте | "mit mein Team" | Недостаточно времени на проверку |
| Регистр (formal/informal) | "Hallo Chef!" в деловом письме | Незнание норм немецкой переписки |
| Отсутствие Textorganisation | Одно длинное предложение на абзац | Различие в нарративных конвенциях |

## 8–10 Микро-упражнений

### 1. Sentence Combining — Слияние предложений (5–7 мин)
**Цель:** Связная речь через Konnektoren; избежать choppy writing
**Инструкция:** 5 коротких предложений → объедините в 2–3 развёрнутых, используя: weil, obwohl, da, jedoch, außerdem, deshalb, trotzdem.
**Пример:**
```
Входные: "Es regnet. Ich gehe spazieren. Das macht mir Spaß."
Результат: "Obwohl es regnet, gehe ich spazieren, weil mir das trotzdem Spaß macht."
```
**Уровень:** A2–B2

### 2. Genre Imitation — Имитация жанра (10 мин)
**Цель:** Усвоить конвенции немецких текстовых жанров
**Инструкция:** Получите образцовый текст нужного жанра (email, Beschwerde, Bewerbungsschreiben). Изучите структуру → напишите аналогичный на другую тему.
**Жанры:** Формальный email / Entschuldigung / Bitte / Beschwerde / Kurzbewerbung
**Research:** Genre-Based Pedagogy (Martin, 1985) — изучение жанра через анализ образца

### 3. Error Correction Writing (5 мин)
**Цель:** Осознанная работа с собственными типичными ошибками
**Инструкция:** Возьмите предыдущий текст с отмеченными ошибками. Перепишите только ошибочные предложения — правильно. Объясните, что именно изменили.
**Tip:** Не переписывать весь текст — только проблемные места.

### 4. Timed Writing — Письмо на время (7–10 мин)
**Цель:** Беглость в письме; преодоление блокировки "подожду идеальную фразу"
**Инструкция:** Таймер на 7 минут. Пишите без остановки на заданную тему. Не исправляйте, не останавливайтесь. Потом — 3 мин на чтение и 1–2 исправления.
**Research:** Krashen (1984) — free writing снижает monitor overuse

### 5. Textstruktur-Training — Структура текста (5 мин)
**Цель:** Логичный план → логичный текст
**Инструкция:** Перед написанием составьте мини-план (Einleitung → Hauptteil 1 → Hauptteil 2 → Schluss). Каждый пункт — 1 ключевое слово. Затем пишите по плану.
**Шаблон для email:**
```
1. Betreff: [суть]
2. Anrede: [форма обращения]
3. Bezug/Grund: [зачем пишу]
4. Hauptanliegen: [суть в 2–3 предложениях]
5. Bitte/Frage: [что жду от адресата]
6. Grußformel: [закрытие]
```

### 6. Peer Review Simulation — Самопроверка по чеклисту (5 мин)
**Цель:** Развить навык самокоррекции
**Чеклист для самопроверки:**
- [ ] Есть ли все части структуры (Einleitung, Hauptteil, Schluss)?
- [ ] Все существительные с большой буквы?
- [ ] Глагол на 2-й позиции в главном предложении?
- [ ] В Nebensatz глагол в конце?
- [ ] Правильные артикли в Akkusativ/Dativ?
- [ ] Подходящий стиль (formal/informal)?

### 7. Reformulation — Перефразирование (7 мин)
**Цель:** Лексическая гибкость; не использовать одно слово 5 раз
**Инструкция:** Напишите 2–3 предложения → найдите синонимы или перефразируйте каждое слово, которое повторяется. Используйте leo.org / Synonymwörterbuch.
**Пример:** "gut" → ausgezeichnet / hervorragend / gelungen / zufriedenstellend

### 8. Register Switch — Смена регистра (5–7 мин)
**Цель:** Понять разницу formal/informal/neutral
**Инструкция:** Один и тот же текст напишите в 2 версиях: одна — формальная (Sehr geehrte...), другая — неформальная (Hallo...). Что изменилось?
**Фокус:** обращение, лексика, тон, структура завершения

### 9. Professional Writing — Деловой текст по профессии (10 мин)
**Цель:** Интеграция профессиональной лексики в письменный контекст
**Инструкция:** Напишите текст для вашей рабочей ситуации: email коллеге / краткий отчёт / описание проекта / запись о пациенте (для медиков). 6–8 предложений.
**IT:** Status update email / Fehlerprotokoll
**Medizin:** Kurzer Arztbrief / Pflegebericht

### 10. Anki-Text Integration — Письмо с новыми словами (7 мин)
**Цель:** Перевести пассивный словарь (из Anki) в активный (использовать в письме)
**Инструкция:** Возьмите 5 слов из Anki (изученные на этой неделе). Напишите текст, в котором все 5 использованы правильно и в контексте.

## Checklist для преподавателя

- [ ] Задание имеет коммуникативную цель (реальная ситуация)
- [ ] Жанр чётко определён (email / Bericht / Essay...)
- [ ] Студент получил образцовый текст (model text) для анализа
- [ ] Оценка по критериям (не "хорошо/плохо")
- [ ] Ошибки классифицированы (грамматика / лексика / структура / стиль)
- [ ] Приоритет: критические ошибки (мешают пониманию) > стилистические
- [ ] Новые слова добавлены в Anki
- [ ] Студент переписывает ошибочные фрагменты (rewrite, не просто исправить)

## Психологические техники для письма

### Для студентов с perfectionism / writer's block
- **Техника "Грязного черновика":** "Первая версия ДОЛЖНА быть плохой. Это нормально. Цель — написать, а не сразу написать хорошо."
- **Таймер-подход:** жёсткий тайм-лимит → нет времени бояться

### Для аналитических студентов
- Дайте схему ПЕРЕД написанием → снижает когнитивную нагрузку
- "Пишете по шаблону — это не слабость, это стратегия"

### Для визуальных студентов
- Mindmap перед написанием → текст из mindmap

### Для кинестетических студентов
- Писать от руки → потом набрать на компьютере → процесс укрепляет память

## Evidence-Based Research

1. **Flower & Hayes (1981)** — Cognitive Model of Writing: писатель одновременно планирует, пишет и проверяет → важно разделять эти фазы
2. **Krashen (1984)** — Free Writing reduces monitor overuse: для беглости — важен timed writing без самоцензуры
3. **Martin (1985)** — Genre-Based Pedagogy: изучение жанра через образцы эффективнее свободного письма
4. **Ferris (2004)** — Error Feedback in L2 Writing: ошибки нужно исправлять, но только критические — для fluency vs accuracy баланса
5. **CEFR Companion Volume (2020)** — Writing descriptors at B1–C1

## Шаблоны немецких письменных жанров

### Формальный Email
```
Betreff: [конкретный]

Sehr geehrte/r Frau/Herr [Nachname],

[Bezug/Anlass]: Ich schreibe Ihnen bezüglich...
[Hauptanliegen]: [2–3 предложения]
[Bitte/Frage]: Ich bitte Sie, ... / Könnten Sie bitte...?

Mit freundlichen Grüßen
[Vollständiger Name]
[Funktion, falls relevant]
```

### Beschwerde (официальная жалоба)
```
Betreff: Reklamation / Beschwerde — [Produkt/Service] vom [Datum]

Sehr geehrte Damen und Herren,

am [Datum] habe ich [Produkt/Dienstleistung] erworben/genutzt. Leider muss
ich Ihnen mitteilen, dass [Problem].

[Konsequenz/Erwartung]: Ich bitte Sie daher, [Erstattung / Austausch /
Erklärung] bis zum [Datum] zu veranlassen.

Ich erwarte Ihre baldige Rückmeldung.
Mit freundlichen Grüßen
[Name]
```

### Kurzbewerbung per Email
```
Betreff: Bewerbung als [Stelle] — [Ihr Name]

Sehr geehrte/r Frau/Herr [Name],

mit großem Interesse habe ich Ihre Stellenausschreibung gelesen.
Als [Berufsbezeichnung] mit [X] Jahren Erfahrung in [Bereich] möchte ich mich
für diese Position bewerben.

[1 Satz: Warum diese Firma?]
[1 Satz: Was bringe ich Besonderes mit?]

Meine vollständigen Bewerbungsunterlagen sende ich Ihnen gerne zu.
Über ein persönliches Gespräch würde ich mich sehr freuen.

Mit freundlichen Grüßen
[Name] | [Tel] | [Email]
```
