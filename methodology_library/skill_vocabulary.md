# Методологическая библиотека — Навык: Лексика (Wortschatz)

**Файл:** methodology_library/skill_vocabulary.md
**Evidence-based:** Nation (2001), Spaced Repetition (Ebbinghaus), Word Knowledge Depth Model

---

## Цель развития навыка

Сформировать активный словарный запас, достаточный для свободного общения в профессиональной и бытовой среде. **Цель не в количестве слов, а в глубине знания** — понимать слово в контексте, использовать правильно, знать сочетаемость.

---

## Модель знания слова (Nation, 2001)

Знать слово — значит знать:
1. **Форму:** как пишется и произносится
2. **Артикль:** der/die/das (для существительных)
3. **Грамматику:** управление глагола, падеж, множественное число
4. **Значение:** основное + переносное
5. **Коллокации:** с чем сочетается (Fehler MACHEN, не "Fehler haben")
6. **Регистр:** формальное/разговорное
7. **Словообразование:** однокоренные слова

---

## Приоритет лексики по уровням

| Уровень | Объём активного словаря | Что учить |
|---|---|---|
| A1 | ~500 слов | Базовые: Familie, Essen, Zahlen, Farben, Verben |
| A2 | ~1000 слов | Повседневные ситуации: Wohnung, Arbeit, Gesundheit |
| B1 | ~2000 слов | Знакомые темы, простая абстракция |
| B2 | ~4000 слов | Профессиональные темы, СМИ, мнения |
| C1 | ~8000+ слов | Нюансы, идиомы, специализация |

**Правило:** Учить не изолированные слова, а тематические гнёзда + коллокации.

## 8–10 Микро-упражнений

### 1. Spaced Repetition с Anki (5–10 мин/день)
**Цель:** Долгосрочное запоминание через оптимальные интервалы
**Инструкция:** Используйте Anki (или Quizlet). Ежедневно: 5 новых карточек + повторение старых (алгоритм сам выбирает что повторить).
**Формат карточки:**
```
Передняя: слово + артикль
Задняя: перевод + пример + коллокация + мнемоника (если есть)
```
**Research:** Ebbinghaus (1885) — Forgetting Curve; SRS подавляет забывание

### 2. Semantic Mapping — Семантическая карта (7 мин)
**Цель:** Связать слова в сеть (помогает вспомнить)
**Инструкция:** Центральное слово → рисуете mind map: синонимы / антонимы / однокоренные / коллокации / контексты использования.
**Пример для ARBEIT:**
```
ARBEIT
├── Синонимы: Beruf, Tätigkeit, Job, Stelle
├── Verben: arbeiten, anfangen, kündigen, eingestellt werden
├── Adjektive: anspruchsvoll, kreativ, befristet
├── Komposita: Arbeitszeit, Arbeitgeber, Arbeitserlaubnis
└── Kontexte: Büro, Homeoffice, Teilzeit, Vollzeit
```

### 3. Collocation Mining — Поиск коллокаций (5 мин)
**Цель:** Учить слова в парах/группах, а не изолированно
**Инструкция:** Для нового слова найдите 5 коллокаций: какие глаголы/прилагательные с ним употребляются?
**Ресурс:** DWDS (Digitales Wörterbuch der deutschen Sprache) — раздел "Kollokationen"
**Примеры:**
- Fehler → machen / begehen / korrigieren / entdecken (NOT "haben")
- Termin → vereinbaren / verschieben / absagen / wahrnehmen
- Entscheidung → treffen / revidieren / beeinflussen

### 4. Word-Mapping in Context — Слово в контексте (5 мин)
**Цель:** Понимать слово не как перевод, а как элемент ситуации
**Инструкция:** Новое слово → найдите 3 аутентичных предложения с ним (DWDS / Linguee / Google). Запишите их. Потом составьте своё предложение о вашей реальной ситуации.
**Запрещено:** перевод нового слова без примера

### 5. Keyword Method — Мнемоника (3–5 мин)
**Цель:** Связать новое слово с чем-то уже известным для быстрого запоминания
**Метод:** Найдите созвучие в русском → создайте абсурдный образ
**Примеры:**
- **Schlange** (очередь/змея) → "Я стою в очереди и вижу ШЛАНГу (трубку) — как змею"
- **Schmetterling** (бабочка) → "ШМЕТterling = ШМЕТАЕТ крыльями"
- **überwältigen** (overwhelm) → "УБЕР-вальцует = настоящее перегрузка"
**Research:** Atkinson & Raugh (1975) — Keyword Method значительно повышает retention

### 6. Input Flooding — Насыщение контекстом (7 мин)
**Цель:** Встретить слово многократно в разных контекстах → автоматизация
**Инструкция:** Возьмите 5 целевых слов. Прочитайте текст, где они часто встречаются (или создайте такой текст). Потом — использовать слова в письме или говорении.
**Research:** Nation (2001) — для прочного запоминания нужно 10–20 встреч со словом

### 7. Semantic Field Expansion — Расширение семантического поля (5–7 мин)
**Цель:** Учить слова тематическими группами (эффективнее, чем случайно)
**Тематические наборы для B1:**
- Arbeitsleben: Gehalt, Urlaubsanspruch, Überstunden, kündigen, einstellen...
- Gesundheit: Symptome, verschreiben, einweisen, Blutdruck, Befund...
- Wohnen: Miete, Nebenkosten, Kaution, Vermieter, kündigen (контракт)...
- IT: implementieren, debuggen, Deployment, Sprint, Release...

### 8. Production vs Recognition — Активное vs пассивное знание (5 мин)
**Цель:** Перевести пассивный словарь в активный
**Инструкция:** Список из 10 слов, которые вы "знаете" (узнаёте). Для каждого:
- Можете произнести вслух без паузы?
- Можете использовать в предложении на собственную тему?
- Знаете 2 слова, которые с ним сочетаются?
Если "нет" на любой вопрос → слово всё ещё пассивное → нужна active practice

### 9. Vocabulary in Professional Context — Профлексика (7–10 мин)
**Цель:** Прямая применимость в работе
**Инструкция:** Найдите аутентичный текст/документ по вашей профессии на немецком (IT-статья / медицинский журнал / бизнес-кейс). Выпишите 8–10 незнакомых слов. Добавьте в Anki + используйте в предложении о вашей работе.
**Ресурсы по профессиям:**
- IT: heise.de / golem.de / t3n.de
- Медицина: aerzteblatt.de
- Бизнес: manager-magazin.de / wirtschaftswoche.de

### 10. Active Retrieval Practice — Активное извлечение (3–5 мин)
**Цель:** Проверка без подсказок (retrieval > review)
**Инструкция:** Закройте словарь/Anki. Напишите по памяти:
- 10 слов на тему "Wohnen" (без словаря)
- 5 глаголов, которые управляют Dativ
- 3 синонима к слову "wichtig"
**Research:** Roediger & Karpicke (2006) — testing effect: active retrieval > repeated reading

## Checklist для преподавателя

- [ ] Слова вводятся в тематических группах (не случайный список)
- [ ] Артикль всегда вместе с существительным (der/die/das)
- [ ] Изучаются коллокации (не просто перевод)
- [ ] Студент делает Anki-карточку с примером, не просто переводом
- [ ] Слово встречается в разных контекстах (reading → speaking → writing)
- [ ] Профессиональная лексика включена в план
- [ ] Anki deck регулярно пополняется и повторяется

## Evidence-Based Research

1. **Nation (2001)** — Learning Vocabulary in Another Language: классический труд о вокабуляр-обучении; модель знания слова; spaced repetition
2. **Atkinson & Raugh (1975)** — Keyword Method: до 50% лучше retention при использовании мнемоники
3. **Ebbinghaus (1885)** — Забывание и spaced repetition: база Anki-алгоритма
4. **Roediger & Karpicke (2006)** — Testing Effect: retrieval practice > review
5. **Schmitt (2000)** — Vocabulary in Language Teaching: глубина знания слова важнее количества
6. **Webb (2007)** — Incidental vocabulary acquisition: 10–20 встреч с словом для прочного запоминания
