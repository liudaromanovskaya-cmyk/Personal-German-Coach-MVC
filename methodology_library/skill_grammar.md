## Цель развития навыка

Сформировать **точные автоматизированные грамматические навыки**, необходимые для свободного общения. Не зазубривание правил, а прочная интеграция грамматики в реальный коммуникативный контекст.

## Топ-10 ошибок русскоязычных (для prioritization)

| # | Ошибка | Пример | Правило |
|---|---|---|---|
| 1 | Verb-Second нарушение | "Heute ich arbeite" | Глагол всегда на позиции 2 |
| 2 | Akkusativ maskulin | "Ich sehe ein Mann" | der/ein → den/einen |
| 3 | Dativ nach Präpositionen | "mit mein Team" | mit/bei/nach/von/zu → Dativ |
| 4 | Nebensatz Wortfolge | "weil ich bin müde" | В придаточном: глагол в конец |
| 5 | Perfekt vs Präteritum | "Ich war gestern dort" | В разговоре: чаще Perfekt |
| 6 | Trennbare Verben | "Ich anrufe dich" | Aufrufen → ich rufe ... an |
| 7 | Reflexivverben | "Ich freue die Arbeit" | sich freuen über → mich freuen |
| 8 | Konjunktiv II fehlt | "Ich will das machen" | В просьбе: "Ich würde das machen" |
| 9 | Genitivus fehlt | "Das Auto von mein Vater" | ...meines Vaters (высокий регистр) |
| 10 | Adjektivdeklination | "Das schön Haus" | Schwache/starke Flexion по артиклю |

## 8–10 Микро-упражнений

### 1. Error Noticing — "Заметь ошибку" (5 мин)
**Цель:** Сенситизировать внимание к конкретной грамматической структуре
**Инструкция:** Получите текст с 5–7 выделенными ошибками. Каждую подчеркните и напишите: почему это ошибка + правильный вариант + правило.
**Research:** Doughty (2001) — noticing как первый шаг к acquisition

### 2. Substitution Drills — Замена (3–5 мин)
**Цель:** Механическое закрепление формы (Patterson practice)
**Инструкция:** Базовое предложение → заменяйте одно слово по сигналу:
```
"Ich helfe dem Mann." → (Frau) → "Ich helfe der Frau."
                       → (Kind) → "Ich helfe dem Kind."
```
**Примечание:** Только для начального этапа; переходить к коммуникативной практике

### 3. Consciousness-Raising — Вывод правила (5–7 мин)
**Цель:** Студент сам выводит правило из примеров (лучше запоминается)
**Инструкция:** Дайте 6–8 примеров с новой структурой. Студент формулирует правило сам. Потом — сравните с официальным правилом.
**Research:** Schmidt (1990) — самостоятельно выведенные правила лучше усваиваются

### 4. Reconstruction Task — Реконструкция (5 мин)
**Цель:** Активная работа с нужной структурой
**Инструкция:** Разрезанные слова предложения → соберите правильный порядок.
**Пример:** `[gegessen] [habe] [Pizza] [Ich] [gestern]` → "Gestern habe ich Pizza gegessen."
**Вариации:** с Nebensatz, с Passiv, с trennbaren Verben

### 5. Focused Communication — Задание с мишенной структурой (7–10 мин)
**Цель:** Коммуникативное использование конкретной структуры
**Принцип:** Задание создаёт необходимость использовать нужную структуру
**Примеры:**
- Kausale Sätze (weil/da): "Почему вы не пришли на работу?" → студент ОБЯЗАН использовать weil
- Komparativ: "Сравните два телефона/лечения/проекта"
- Passiv: "Опишите процесс (производство/операция) — без называния субъекта"

### 6. Text Rebuilding — Восстановление текста (5 мин)
**Цель:** Понимание структуры в контексте, не в изоляции
**Инструкция:** Текст, из которого убраны только слова нужной категории (артикли / глаголы в Nebensatz / предлоги). Восстановите.
**Пример (Dativ после Präpositionen):**
"Er wohnt in ___ Stadt und fährt mit ___ Bus zu ___ Arbeit."

### 7. Self-Monitoring Exercise — Осознанный мониторинг (7–10 мин)
**Цель:** Студент учится сам замечать ошибки в своей речи
**Инструкция:**
1. Говорите / пишите свободно (2–3 мин)
2. Прочитайте/прослушайте своё производство
3. Отметьте: где я не уверен? Где возможная ошибка?
4. Проверьте эти места в словаре/грамматике
**Research:** Bialystok (1994) — explicit knowledge → monitoring → implicit use

### 8. Grammar Journal — Грамматический дневник (3–5 мин/день)
**Цель:** Персонализированная работа с ошибками
**Инструкция:** Заведите файл/блокнот. Каждый раз когда получаете фидбек:
1. Запишите ошибку + контекст (ваш пример)
2. Напишите правильный вариант
3. Напишите правило 1 предложением
4. Придумайте ещё 2 примера (разных)
**Format:** | Ошибка | Правильно | Правило | Мой пример 1 | Мой пример 2 |

### 9. Comparative Grammar — Сравнение немецкого с русским (5 мин)
**Цель:** Использовать L1 для понимания (не избегать — применять стратегически)
**Инструкция:** Для сложной структуры найдите: Есть ли аналог в русском? В чём разница?
**Примеры сравнений:**
- Verb-Second: в русском свободный порядок → в немецком V2 — фиксированный
- Падежи: оба языка имеют падежи, но маркируются артиклем (DE) vs окончанием (RU)
- Перфект: в немецком Perfekt ≈ русское прошедшее совершенного вида

### 10. Communication-First Drill — Сначала смысл, потом форма (7 мин)
**Цель:** Не учить грамматику ради грамматики — использовать в реальном контексте
**Инструкция:** Задача: объясните коллеге, что произошло на работе вчера (рассказ). После — исправляем только критические ошибки (те, что мешают пониманию), не все.
**Research:** Long (1991) — Focus on Form в контексте коммуникации эффективнее изолированной грамматики

## Грамматическая прогрессия для русскоязычного B1-студента

### Месяц 1: Укрепление основ
- Verb-Second (с примерами)
- Kasus: Nom / Akk / Dat артикли
- Perfekt vs Präteritum (когда что)
- trennbare Verben: aufrufen, einladen...

### Месяц 2: Предложения
- Nebensatz: weil, dass, wenn, obwohl
- Relativsatz: Der Mann, der...
- Konjunktiv II: würde, wäre, hätte, könnte

### Месяц 3: Профессиональный уровень
- Passiv (Präsens + Perfekt)
- Futur I: werden + Infinitiv
- Konjunktiv I (косвенная речь в отчётах)
- Partizip I / II как прилагательное

## Checklist для преподавателя

- [ ] Грамматика вводится В КОНТЕКСТЕ, не как изолированное правило
- [ ] Студент вывел правило сам (до объяснения)
- [ ] Порядок: noticing → understanding → controlled practice → free use
- [ ] Нет "grammar drilling" более 10 мин подряд → переход к коммуникации
- [ ] Критические ошибки исправляются; стилистические — опционально
- [ ] Ошибки зафиксированы в Grammar Journal студента
- [ ] Новые структуры закреплены Anki-примерами (предложение, не просто правило)

## Evidence-Based Research

1. **Schmidt (1990)** — Noticing Hypothesis: нельзя приобрести то, что не замечаешь
2. **Long (1991)** — Focus on Form: внимание на форму В коммуникативном контексте > Form-focused instruction
3. **DeKeyser (2007)** — Skill Acquisition Theory: от explicit → автоматизированный implicit (нужна practice)
4. **Lightbown & Spada (2013)** — How Languages Are Learned: оптимально — сочетание формального обучения + коммуникативной практики
5. **Doughty (2001)** — Cognitive-Interactional Approach: noticing → restructuring → output
