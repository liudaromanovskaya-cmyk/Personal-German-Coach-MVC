# Speaking Sprint System — Ежедневная практика говорения

**Файл:** methodology_library/speaking_sprint_system.md
**Для кого:** Студенты B1→B2, особенно с психологическим барьером говорения
**Время:** 20–25 минут в день
**Evidence-based:** Krashen (Affective Filter), Swain (Output Hypothesis), Ellis (Pre-task Planning), Lyster & Ranta (Recast), Nation (Vocabulary Repetition), Conway (Autobiographical Memory)

---

## Проблема, которую решает система

Студент знает слова пассивно, но не использует их в речи. Барьеры:
1. **Страх ошибки** — особенно если преподаватель исправляет сразу
2. **Слова с урока пропадают** — нет системы активации
3. **Нет видимого прогресса** — непонятно, растёт ли
4. **Говорение = стресс** — аффективный фильтр заблокирован

Система снимает каждый барьер структурно, не увещеваниями.

---

## Как работает — полная архитектура

### Шаг 0 — Загрузка слов (преподаватель, после урока)

Преподаватель пишет боту:
```
/words olga
auf Anhieb, sich abrackern, eingespannt sein, überwältigt sein, das Missverständnis
```

Claude автоматически:
- Находит устойчивые выражения для каждого слова
- Показывает как немец скажет это в реальном контексте
- Генерирует задания для уровней 1, 2, 3

---

### Шаг 1 — Самооценка (5 секунд)

Перед стартом студент нажимает одну кнопку:
```
Как вы себя сейчас чувствуете?
😰 Напряжённо   😐 Нормально   😊 Хорошо
```

**Зачем:**
- Студент осознаёт своё состояние → метакогниция
- Преподаватель видит паттерн: когда барьер высокий
- При 😰 — система предлагает более лёгкий вариант уровня 1

**Research:** Krashen (1982) — при высоком аффективном фильтре input не усваивается. Знать состояние студента — это знать, работает ли урок.

---

### Уровень 1 — Разогрев (5 минут)

**Цель:** Включиться. Снять страх. Первые слова — самые трудные.

**Структура:**
- 2–3 знакомых слова (из прошлых уроков, не новые)
- Простая ситуация, близкая к студенту
- Любой ответ засчитывается — нет неправильного

**Пример задания:**
> *Коллега спрашивает вас в конце смены: "Na, wie war's heute?"*
> *Скажите 3 предложения. Используйте: `irgendwie`, `endlich`, `eingespannt`*

**Принцип:** Студент не может ответить "неправильно". Задание устроено так, что любые 3 предложения — успех.

**Психологический эффект:** Первые слова произнесены. Тело расслабляется. Дальше легче.

---

### Пауза — 60 секунд подготовки

Перед уровнем 2 — таймер.

```
⏱ Подумайте 60 секунд
Что вы скажете? Какие слова используете?
Не пишите — просто думайте.
```

**Research:** Ellis (2005) — pre-task planning значительно увеличивает сложность и беглость речи. Даже 60 секунд дают измеримый эффект. Студент говорит более точно и использует больше целевых структур.

---

### Уровень 2 — Ситуация с целевыми словами (8–10 минут)

**Цель:** Активировать слова урока в реальном коммуникативном контексте.

**Что Claude генерирует автоматически:**

Для каждого слова:
```
Слово: überwältigt sein
→ Устойчивое выражение: "von etwas überwältigt werden"
→ Коллокации: "total überwältigt", "emotional überwältigt"
→ Как немец скажет: "Das hat mich echt überwältigt" / "Ich war völlig überwältigt"
→ Ситуация: коллега спрашивает про первую неделю на новом месте
```

**Принцип TBLT (Task-Based Language Teaching):**
Не "составьте предложение со словом" — а "реши коммуникативную задачу, где без этого слова не обойтись."

**Пример задания:**
> *Ваша подруга спрашивает: "Wie läuft die neue Stelle?" Расскажите честно о первой неделе.*
> *Используйте: `eingespannt sein`, `auf Anhieb`, `überwältigt sein`, `das Missverständnis`*

**Формат фидбека — "Немецкий двойник":**

Не коррекция — сравнение с носителем:

| Вы сказали | Немец в вашей ситуации скажет |
|---|---|
| "Ich war sehr müde" | "Ich war total am Ende" |
| "Ich habe einen Fehler" | "Mir ist ein Fehler unterlaufen" |
| "Die Arbeit ist viel" | "Ich bin momentan ziemlich eingespannt" |

**Research:** Lyster & Ranta (1997) — recast (показать правильный вариант рядом) эффективнее прямой коррекции. Нет стыда. Нет "неправильно". Есть сравнение с носителем.

---

### Уровень 3 — Своя история (5–7 минут)

**Цель:** Свободное говорение. Студент чувствует — она может.

**Принцип:** Студент уже разогрет. Уже использовал слова. Уже получил маленький успех. Теперь — свобода.

**Ключевое отличие от уровня 2:** Не ситуация-сценарий, а **реальное воспоминание из жизни студента**.

**Пример:**
> *Расскажите о моменте, когда вы чувствовали себя действительно überwältigt.*
> *Что случилось? Где вы были? Что вы сделали? Как это разрешилось?*
> *Все слова этой недели — перед вами. Используйте сколько хотите.*

**Research:** Conway & Pleydell-Pearce (2000) — autobiographical memory (личные воспоминания) воспроизводятся легче и запоминаются глубже, чем придуманные ситуации. Ольга рассказывает о своей ночной смене, о разговоре с врачом — это не упражнение, это её жизнь на немецком.

**Что НЕ делает преподаватель на уровне 3:**
Не исправляет во время говорения. Только слушает. Фидбек — потом, письменно.

---

## Спиральный повтор слов

Слова с прошлых уроков не исчезают. Они возвращаются в новых ситуациях.

```
Неделя 1: слова A (5–7 слов)
Неделя 2: слова B (5–7 новых) + 3 слова из A в новом контексте
Неделя 3: слова C (5–7 новых) + 3 из B + 1 ключевое из A
Неделя 4: свободная практика — все слова месяца
```

**Research:** Nation (2001) — для автоматизации слова нужно встретить 10–20 раз в разных контекстах. Без спирального повтора слова остаются пассивными.

## Мотивационная механика

### Счётчик активированных слов
Каждый раз когда студент использовал слово в свободной речи (уровень 3) — оно отмечается как **активировано**.

```
📝 Активный словарь апреля
auf Anhieb ✅  eingespannt ✅  überwältigt ✅
das Missverständnis 🔄  sich abrackern ○

✅ активировано  🔄 в процессе  ○ ещё не использовала
```

Студент видит конкретные слова, которые она теперь умеет говорить. Не проценты — живые слова.

### Серия дней
Счётчик дней подряд. **Важно:** если пропустила день — серия не обнуляется до нуля, а "замораживается" на один день.

Дизайн-решение: shame streak (Duolingo) → против психологии. При пропуске показываем: *"Вчера пауза — сегодня продолжаем с того же места. Это нормально."*

### Настроение в динамике
Через 2–3 недели преподаватель видит график: когда 😰, когда 😊. Паттерн показывает — в какие дни недели барьер выше, после каких тем студент чувствует себя лучше.

## Итоговая схема — полный цикл

```
ПОСЛЕ УРОКА (преподаватель, 2 минуты)
  ↓
/words olga + список слов → боту
  ↓
Claude генерирует: коллокации + ситуации уровней 1/2/3
Преподаватель просматривает → отправляет
  ↓
ЕЖЕДНЕВНО (студент, 20–25 минут)
  ↓
[Настроение] → [Уровень 1] → [60 сек подготовка] → [Уровень 2] → [Уровень 3]
  ↓
Голосовое сообщение → Telegram бот
  ↓
Транскрипция (Whisper) → Анализ (Claude) → Черновик фидбека
  ↓
Преподаватель просматривает (2–3 минуты) → отправляет
  ↓
Студент видит фидбек в кабинете: "Немецкий двойник" + активированные слова
  ↓
СЛЕДУЮЩИЙ УРОК
Преподаватель видит: какие слова активированы, где пробелы, настроение в динамике
```

## Что преподаватель НЕ делает (экономия времени)

| Задача | Раньше | Теперь |
|---|---|---|
| Придумать домашнее задание | 15–20 минут | 0 — Claude генерирует |
| Написать коллокации | 10 минут | 0 — Claude находит |
| Транскрибировать аудио | — | 0 — Whisper |
| Написать фидбек с нуля | 10–15 минут | 2–3 минуты — правит черновик Claude |
| Помнить что студент делал | Память / заметки | 0 — кабинет хранит всё |

**Итого:** с 3 студентами — экономия 1–1.5 часа в неделю после настройки.

## Психологические принципы (сводка)

| Принцип | Как реализован |
|---|---|
| Аффективный фильтр (Krashen) | Самооценка настроения + уровень 1 всегда лёгкий |
| Scaffolding (Выготский, ZPD) | 3 уровня: поддержка убирается постепенно |
| Output Hypothesis (Swain) | Студент производит речь, не только слушает |
| Pre-task Planning (Ellis) | 60 секунд подготовки перед уровнем 2 |
| Recast (Lyster & Ranta) | Немецкий двойник — без стыда и коррекции |
| Spaced Repetition (Ebbinghaus) | Спиральный повтор слов через недели |
| Autobiographical Memory (Conway) | Уровень 3 — реальные истории из жизни |
| Visible Progress | Счётчик активированных слов |

## Три типа ситуаций (банк для Claude)

**Работа (приоритет для Ольги)**
- Разговор с коллегой в конце смены
- Объяснить шефу почему опоздала / задержалась
- Ответить на замечание коллеги
- Попросить о помощи / объяснить задачу

**Жизнь в Германии**
- Разговор с врачом (симптомы, назначения)
- Объяснить ситуацию в Behörde
- Разговор с Vermieter
- Аптека, Supermarkt, Elternabend

**Личное**
- Рассказать подруге о трудном дне
- Объяснить семье (в России) как живётся в Германии
- Описать момент, которым гордишься
- Рассказать о чём-то, что удивило или расстроило
