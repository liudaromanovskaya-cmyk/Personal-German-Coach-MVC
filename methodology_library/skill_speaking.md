# Методологическая библиотека — Навык: Говорение (Sprechen)

**Файл:** methodology_library/skill_speaking.md

---

## Цель развития навыка

Развить **беглость, точность и уверенность** в устной немецкой речи для реальных ситуаций: работа, интеграция, экзамен. Преодолеть психологические барьеры (страх ошибки, акцент, спонтанность).

---

## Прогрессия по CEFR

| Уровень | Что должен уметь |
|---|---|
| A1 | Представиться, назвать числа, сказать простые фразы |
| A2 | Вести простой диалог, задавать вопросы, рассказать о себе |
| B1 | Описывать события, выражать мнение, общаться в большинстве ситуаций |
| B2 | Спонтанно говорить, аргументировать, вести переговоры |
| C1 | Говорить свободно, точно, с нюансами, в профессиональном контексте |

## 8–10 Микро-упражнений

### 1. Shadowing — Повторение за носителем (5–7 мин)
**Цель:** Интонация, ритм, произношение — на уровне рефлекса
**Инструкция:** Выберите аудио (DW, YouTube) 1–2 мин. Повторяйте ВСЛУХ одновременно или с задержкой 1–2 сек. Запишите себя.
**Research:** Hamada (2014) — shadowing значительно улучшает pronunciation и fluency

### 2. 30-Second Monologue (5 мин)
**Цель:** Преодолеть страх пустого молчания, развить speech momentum
**Инструкция:** Поставьте таймер 30 секунд. Говорите без остановки на любую тему. Не думайте о правильности — просто говорите.
**Tip:** Начните со знакомых тем (что вы видите вокруг, что ели, где были)

### 3. Rollenspiel — Ролевая игра (10–15 мин)
**Цель:** Практика в реалистичных коммуникативных ситуациях
**Ситуации:** Arztbesuch / Bewerbungsgespräch / Telefonat / Supermarkt / Behörde
**Инструкция:** Студент записывает аудио: играет оба голоса (пауза между репликами) ИЛИ диалог с преподавателем
**Research:** Ellis (2003) — task-based learning с реальным коммуникативным смыслом

### 4. Picture Description — Описание картинки (5 мин)
**Цель:** Расширить лексику описания, тренировать спонтанность
**Инструкция:** Возьмите любое фото (из новостей, Flickr). Опишите: Wer? Was? Wo? Wie? Warum (vermutlich)?
**Format:** 60–90 секунд аудио

### 5. Opinion-Drill — Выражение мнения (7 мин)
**Цель:** Клише для выражения позиции (важно на Goethe, telc)
**Инструкция:** Карточки с тезисами (Homeoffice / Klimawandel / Digitalisierung). Для каждого: "Ich finde, dass...", "Meiner Meinung nach...", "Einerseits... andererseits..."
**Клише-набор:** выдать студенту список 15 фраз для мнений

### 6. Retelling — Пересказ (7–10 мин)
**Цель:** Интеграция listening + speaking; активная лексика
**Инструкция:** Прослушайте 2-мин аудио → запишите пересказ своими словами (60–90 сек). Без паузы.
**Tip:** Разрешите использовать ключевые слова из аудио

### 7. Error Correction Awareness (5 мин)
**Цель:** Научить студента слышать свои ошибки — самокоррекция
**Инструкция:** Студент слушает свою прошлую запись и выписывает 3 момента, которые хочет улучшить. Затем перезаписывает эти фрагменты.
**Research:** Boud (1995) — рефлексия над собственной речью как ключевой навык автономного обучения

### 8. Speed Drill — Скорость и реакция (5 мин)
**Цель:** Сократить время поиска слова (retrieval speed)
**Инструкция:** Преподаватель/студент называет тему → 20 секунд на говорение. Тренировка ассоциативных цепей.
**Примеры:** "Что вы делали вчера?" / "Назовите 5 вещей в вашем офисе" / "Опишите коллегу"

### 9. Professional Pitch — Профессиональная презентация (10–15 мин)
**Цель:** Уверенная речь в рабочем контексте
**Инструкция:** 2-минутный питч: "Расскажите о вашем проекте / должности / методике" — по профессии студента
**Оценка:** структура + профлексика + беглость

### 10. Fake Interview — Симуляция интервью (10 мин, B1+)
**Цель:** Собеседование, экзаменационное говорение
**Инструкция:** 5 вопросов (от простых к сложным). Ответ минимум 3–4 предложения. Студент записывает — затем анализирует себя.

## Checklist для преподавателя

- [ ] Задача коммуникативная (не просто повторить за преподавателем)
- [ ] Есть safe space — студент знает, что ошибки ожидаемы
- [ ] Баланс fluency vs accuracy (не прерывать каждую ошибку)
- [ ] Обратная связь — после, не во время говорения
- [ ] Студент записывает себя — для самоанализа
- [ ] Профессиональный контекст использован (если применимо)
- [ ] Anki: выписаны фразы, которые студент искал, но не нашёл

## Психологические техники для говорения

### Техника "Дружественный свидетель" (для страха ошибки)
Скажите студенту: "Представьте, что вы говорите с другом, который рад любой попытке. Немцы ценят попытку говорить на их языке — даже с ошибками."

### Техника "Принятие несовершенства" (Koichi Tohei method)
Разрешите себе 5 ошибок на каждую минуту речи как норму уровня B1. Посчитайте ошибки — увидите, что их меньше, чем вы думали.

### Техника "Якорь" (для аудиальных студентов)
Перед записью: глубокий вдох + вспомните последний успешный разговор по-немецки. Начинайте из этого состояния.

### Техника "Chunking" (для аналитических студентов)
Разбейте ответ на модули: "Представление + Пояснение + Пример + Вывод". Готовьте не весь текст, а структуру.

## Evidence-Based Research

1. **Swain (1985)** — Output Hypothesis: говорение не просто применение — оно само по себе помогает приобрести язык
2. **Long (1996)** — Interaction Hypothesis: интерактивная речь → negotiation of meaning → SLA
3. **MacIntyre et al. (1998)** — Willingness to Communicate (WTC): уверенность важнее компетентности для прогресса
4. **Hamada (2014)** — Shadowing эффективнее традиционного повторения для prosody и fluency
5. **Levelt (1989)** — Speaking Model: понимание как студент "производит" речь помогает правильно тренировать fluency vs accuracy
