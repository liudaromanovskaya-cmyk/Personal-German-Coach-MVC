# Гайд: что делать с ответами опросника

*Как читать входящий профиль студента и превращать его в учебный план.*

---

## Шаг 1 — Прочитать ответы (до первого занятия)

Открыть teacher.html → студент → "👁 Ответы".
Потратить 5-10 минут. Не анализировать — просто читать как письмо.

**Что искать:**
- Что студент хочет на самом деле (не всегда то что написал)
- Где страх или напряжение между строк
- Какую одну ситуацию он хочет решить прежде всего

---

## Шаг 2 — Определить профиль по 5 осям

### Ось 1: ЗАЧЕМ (Q1, Q2, Q3, Q4)

| Ответ | Что это значит для плана |
|-------|--------------------------|
| Работа / карьера | Деловой немецкий: совещания, переписка, разговор с коллегами |
| Интеграция / жизнь в Германии | Бытовые ситуации: врач, Behörde, соседи, магазин |
| Экзамен (Goethe, TestDaF, DSH) | Форматы экзамена: аудирование, письмо, говорение по структуре |
| Семья / партнёр | Личное общение, эмоции, неформальный язык |
| Путешествия | Туристический немецкий, понимание на слух |
| Дедлайн < 3 месяцев (Q3) | Убрать всё лишнее, только целевые ситуации |

**→ Записать в профиле студента:** главная ситуация + дедлайн если есть.

---

### Ось 2: ВРЕМЯ (Q9, Q10, Q11, Q12)

| Ответ | Что это значит |
|-------|----------------|
| 10-15 минут в день | Только микро-задания: одно слово глубоко, один вопрос |
| 20-30 минут | Стандартный формат: слова + задание говорения или письма |
| Час и больше | Можно добавить уровни, дневник, активное повторение |
| Только в транспорте (Q11) | Аудио-форматы, чтение, карточки — ничего что требует писать |
| Нельзя говорить вслух (Q12) | Больше письменных заданий, меньше монологов |
| Только выходные | Задание на всю неделю, не ежедневное |

**→ Настроить:** количество слов в спринте, количество уровней задания.

---

### Ось 3: ПСИХОЛОГИЯ (Q13, Q14, Q15, Q16)

| Ответ | Что это значит |
|-------|----------------|
| Q13: "Боюсь сделать ошибку" | Начать с Niveau 1 (очень мягко), хвалить попытки, не исправлять сразу |
| Q13: "Боюсь показаться глупым" | Первые задания — закрытые (только ты видишь), строить уверенность |
| Q14: "Замолкаю когда не нахожу слово" | Учить стратегии обхода: описать другими словами, спросить |
| Q15 = 1-2 (дискомфорт с ошибками) | Меньше исправлений в момент речи, больше письменных разборов после |
| Q15 = 4-5 (спокойно к ошибкам) | Можно исправлять сразу, давать сложные задания с вызовом |
| Q16: "Стесняюсь акцента" | Объяснить что акцент = не ошибка, дать слушать носителей с разными акцентами |
| Q16: "Нормально отношусь" | Фокус на смысл и беглость, не на произношение |

**→ Настроить:** тон фидбека, момент исправления, первые темы (безопасные vs вызов).

---

### Ось 4: ОЖИДАНИЯ (Q17, Q18, Q19)

| Ответ | Что это значит |
|-------|----------------|
| Q17: "Исправляй сразу" | Пометки прямо в тексте работы, конкретно |
| Q17: "После того как договорю" | В фидбеке после задания, не в промпте |
| Q17: "Только критичные ошибки" | Один-два момента в фидбеке, не список всего |
| Q18: "Нужен контроль" | Дедлайны в задании, конкретные числа ("сдать до среды") |
| Q18: "Сам организую" | Мягкие формулировки, нет дедлайнов в тексте |
| Q19: "Точность важнее" | Больше грамматики, разбор ошибок, правила |
| Q19: "Беглость важнее" | Больше говорить, меньше правил, поощрять попытки |

**→ Настроить:** стиль фидбека, строгость, соотношение грамматика/говорение.

---

### Ось 5: ФОРМАТЫ (Q21, Q22, Q23, Q26)

| Ответ | Что это значит |
|-------|----------------|
| Q21: любит аудио | Включать Hörverständnis, подкасты в рекомендации |
| Q21: любит читать | Тексты как контекст для слов |
| Q22: не любит грамматические таблицы | Объяснять через примеры, не через правила |
| Q22: не любит зубрёжку | Слова только в контексте, не список |
| Q23: запоминает через контекст | Каждое слово — в чанке, в предложении |
| Q23: запоминает через использование | Сразу использовать в задании говорения |
| Q26: приоритет — говорение | Больше Sprechen-заданий, слова через разговор |
| Q26: приоритет — письмо | Больше Schreiben, деловые тексты, emails |

**→ Настроить:** соотношение Sprechen/Schreiben, как подавать слова, рекомендации для самостоятельной работы.

## Шаг 3 — Составить первое задание по профилю

После чтения ответов — открыть teacher.html и заполнить первый день с учётом профиля.

**Чеклист первого задания:**

- [ ] Тема из реального контекста студента (работа / бытовая ситуация / его жизнь)
- [ ] Слова связаны с его целевой ситуацией (Q4)
- [ ] Niveau 1 — мягкое, с поддержкой (особенно если Q15 ≤ 2)
- [ ] Объём задания соответствует времени студента (Q9)
- [ ] Формат учитывает где он занимается (Q11, Q12)
- [ ] Первый фидбек — поддерживающий, без длинного списка ошибок

## Шаг 4 — Зафиксировать ключевые наблюдения

После первого занятия — дописать в профиль студента (поле "Цель" или заметки):

```
Главный страх: ___
Приоритетная ситуация: ___
Стиль фидбека: ___
Особенности: ___
```

## Красные флаги — реагировать сразу

| Сигнал | Действие |
|--------|----------|
| Q3: дедлайн < 6 недель | Написать студенту: обсудить реальные ожидания |
| Q13: несколько страхов сразу | Первые 2-3 занятия — только безопасные задания, строить доверие |
| Q7: "всё пробовала, ничего не работало" | Спросить на первой встрече: что именно не работало и почему |
| Q9: "нерегулярно — когда получится" | Обсудить: без регулярности прогресс будет медленным |
| Q2: "хочу говорить как носитель" | Мягко скорректировать ожидания: цель — понятность, не акцент |

## Как использовать ежемесячный чек-ин

После получения ответов ежемесячного чек-ина (M1-M8):

1. **Прочитать M8 первым** — там самое личное и важное
2. **M1 = 1-2** → написать студенту до нового месяца, не ждать
3. **M5 + M6** → что-то менять в следующем месяце конкретно
4. **Сравнить M3 с прошлым месяцем** — если та же проблема → подход не работает, менять
5. **Написать студенту ответ** — даже короткое "спасибо, учту" создаёт ощущение что его слышат

**Шаблон ответа на чек-ин:**
> "Спасибо что написала — очень полезно. [Конкретно что учла]. В следующем месяце [конкретно что изменю]."
